## 第一章：简单实用的操作系统

### 核心概念
- **走势必完美**：任何级别走势可分解为上涨、下跌、盘整（上/下/平）的连接；任一走势类型必结束，结束后只能变为另两种之一；完成的走势至少由**连续三段次级别走势**构成。**“完成”≠“结束时刻”**——完美是结构必然，结束涉及时段动力（背驰等）。
- **几何 vs 能量**：笔线段几何最严，实操中常配合均线/MACD 与操作级别，避免无限递归。
- **中枢关键词**：三个连续、次级别、完成的走势类型、连接；走势类型须建立在走势必完美上。
- **背驰**：价格与力度反向；下跌中常比较**第三段与第一段**；K 线层面可看斜率、时间、反复程度。
- **第一类买点**：下跌走势背驰段在次级别上的第一类买点；其后演化盘整或上涨，盘整需按规则退出。
- **第二类买点**：某级别下跌完成后，在次级别上涨或盘整中，**长短均线第一次黏合/交叉的结束点**；或次级别下跌的第一买点。

### 操作规则
- **简易一买系统（五步法）**：（1）操作级别上识别清晰的三段下跌；（2）第三段与第一段背驰时关注，盯背驰段次级别一买；（3）次级别出现一买介入；（4）若第一段次级别上涨不能触及前盘整区最低，退出；（5）若突破前盘整并在次级别一卖退出，继续关注二买。
- **级别**：实操建议操作级别**不宜低于 30 分钟**（避免利润仅够手续费）。
- **中线（周线）**：周线下跌完成 → 上涨中横盘 → 横盘区低买 → **日线上涨背驰**卖。
- **纪律**：买谨慎、卖积极；走势超出认知则退出；可专注**30 分钟二买**，找不到则空仓或降一级；流通盘过小易“小级别背驰引发大级别”，可提级或选大盘子。

### 关键要点
- 本章均线系统是**缠论思路的应用**，与后文严格“中枢定义下的盘整/趋势”**名词易混须分清**。
- 背驰段经**两次**交叉/缠绕出一买时，后续同级别上涨概率更高。

## 第二章：中枢理论完解

### 核心概念
- **严格中枢系统**（与第一章均线“盘整/上涨/下跌”区分）：中枢有级别；某级中枢由**次级别三段完成走势的重叠区间**构成；走势类型级别由中枢级别确定；走势必完美 ⇔ 任意走势必能形成该级中枢。
- **盘整/趋势（中枢意义）**：**盘整**＝仅一个该级中枢；**趋势**＝至少两个**同向、互不重叠**的同级别中枢（上涨/下跌）。
- **最低级别处理**：定操作级别后，可把次级别当“最低可视级别”，例如 5 分钟图三根 K 线横盘区作次次级别中枢等**实用约定**。
- **盘整构成**：如 30 分钟盘整可由 5 分钟上+下+上，或上+盘整+上，或“上+30 分中枢+上”等；**上盘上与上下上结构同构**，易混点在级别。
- **原文级别歧义**：作者说明缠师原文前后级别表述可差一级；本书理论叙述取一种，实操可另取更实用划分。

### 操作规则
- **A、B、C 段与背驰四分类**：C 相对 A 高低 + 是否背驰 → 对应盘整延续、回跌中枢、扩展、趋势等（第五节完全分类）。
- **二买（中枢视角）**：前势为日线下跌结束时，第一段 30 分上后，第二段 30 分盘整或下，其结束点为日线二买；MACD 常见：**拉回零轴后双回抽、绿柱缩小**等配合图形。

### 关键要点
- **驰宏锌锗、茅台**：解读教你炒股票 16 等案例，强调“同级别”指**走势类型级别**，非中枢视觉大小；**背驰式下跌**与周线盘整未完成的关系。
- **530、531 上证 1 分钟经典图**：5 分钟中枢由 1 分盘整+下跌+上涨构成；**9 点二买**与走势必完美的绑定；不理解此图则“未入门”。
- **走势级别**：a+A+b+B+c 中 A、B 为日线中枢时，a、b、c 为次级别或以下；为分析方便可把杂段**统一看成次级别**。
- **预测无意义、分类有意义**：段结束后下一段类型不可预知，但必满足走势必完美与背驰判别。

## 第三章：围绕中枢的走势变化

### 核心概念
- **中枢确立**：a、b、c 三段次级别完成后，若 c 与 a 背驰则 d 回重叠区，形成 **a+A**；d 与 b 高低点四分类对应不同中枢形态。
- **延续 vs 破坏**：次级别波动与中枢区间有重叠 → 延续；次级别离开后经反向段**不回中枢区间** → 破坏，并形成**第三类买卖点**。
- **第三类买卖点**：离开 + 次级别回抽确认；e、f 段形态有 **9 种组合**，其中双横盘叠加可能仍是中枢震荡而非三买。
- **扩展与扩张**：两同级别中枢**震荡区间重叠** → 扩展升级；先突破再以该级别走势返回触及原区间 → 扩张（形态不同，本质常归扩展讨论）。
- **趋势背驰后反弹三类**：最后中枢级别扩展、更大级别盘整、≥原级别的反趋势（教你炒股票 29）。

### 操作规则
- **三买操作**：牛市好用；须**次级别离开+次级别返回**；防“假突破”；回抽分下跌 / N 形盘整 / 窄幅盘整（后者难判，可突破跟进）。
- **二买与三买重合**：周线下跌后，日线强升破前周线中枢且回抽不破 → 力度常大（创业板案例）。
- **最弱扩展**：一买后反弹不及最后中枢 DD，易走扩展；**c1 盘背先出**避险。

### 关键要点
- **云内动力、东华软件、上证季线**：周线/日线三买划分须满足**走势类型完成**（次级别三段），离开段起点划分影响当下结论。
- **九段升级、更大中枢**：三买后若 g 与 e 盘背失败、结构跌入原中枢下沿等 → 可能 **9 段扩展为日线中枢**。

## 第四章：细节问题分解

### 核心概念
- **背驰本质**：股票筹码有限，主动买卖力量消长 → 走势力度衰竭；与测度论、期货延伸性对比为直观解释。
- **复权**：大级别背驰、送股影响筹码比例 → **大级别用不复权**更贴作者逻辑；小级别前复权图面连贯。
- **走势分解**：日线下跌结束后，后续 30 分三段；a 后二买；c 与 a 力度/形态 **6 种组合** → 导出 a+A、五段涨、盘背等七种演化（强度排序）。
- **中阴身**：前走势已可判结束、新走势未确立；多对应**前走势最后中枢的震荡**；操作宜谨慎或仅次级别二买。
- **多义性**：同一走势不同分解均可能有效；选**当下最清晰**之中枢视角；非随意性。
- **同级别分解**：走势拆成同级别上/下/盘连接；用**盘背+一卖一买**节奏操作；注意小转大、盘整时间拉长等。

### 操作规则
- 中阴区：**不参与或**等均线+MACD 明确；中枢震荡严格模式只用**次级别二买**。
- 云内动力 30 分案例：**两种退出策略**（分段避窄盘踏空 vs 不背驰持有）；5 分钟细拆 **二卖**与区间套。

### 关键要点
- **背驰是走势段比较**，MACD 仅辅助；“背了又背”多因**级别与中枢归属错**。
- 同级别与多义性均以**走势必完美**为根基。

## 第五章：辅助的指标与其他

### 核心概念
- **指标定位**：K 线结构为本，均线“果泥”，MACD“果汁”；一切指标须在**结构确定**后使用。
- **均线**：支撑压力；参数宜与当前走势“贴合”；年线/半年线、**5 周线**持筹；多周期均线对应关系辅助短差。
- **板块强弱（均线八档）**：0.1～0.8 加权平均得**板块强弱指标**（牛市初期有效，中后期失效可换周线月线）。
- **MACD**：黄白线/红绿柱与背驰；**回抽零轴两次**；双头；扩张/收敛三角；多空（零轴上/下/缠绕）；**a+A+b 与 a+b+c 比较对象不同**；参数可加倍平滑；**三级别联立**（日-30-5）。
- **布林**：二卖辅助（最后一波无力靠上轨）；**中枢震荡结束**常伴高一级收口。
- **时间窗口**：斐波那契 K 线数、**360° 与 1/8～4/8 速率线**；强调**与形态共振**，非迷信。

### 操作规则
- 多头习惯者：MACD 跌破零轴并回抽确认 → **空头主导**，应降仓或离场等零轴上再玩。
- 速率线 + 时间窗（如 6124 后第 90 月、3/8 线）作**变盘预警**，仍须回到走势结构。

### 关键要点
- 黄白线新高、柱缩短 → 多为**次级别背驰**，勿轻易判本级别结束。

## 第六章：板块轮动

### 核心概念
- 均线板块指标仅适**牛市初期**；普适方法基于**各级别一二三买出现先后**反映“涨跌快慢”。

## 附录 B：定理 / 公式汇总

1. **走势必完美**：任意级别走势可分解为上/下/盘；必完成；完成后仅转另两种之一；至少三段次级别构成。  
2. **中枢（价格）**：次级别三段完成走势类型的**重叠区间**为本级中枢区间。  
3. **盘整**：仅含一个该级别中枢的走势类型。  
4. **趋势**：两个以上同向且不重叠的同级别中枢。  
5. **背驰（实用）**：同向两段比较力度（K 线/均线面积/MACD 黄白线与柱）。  
6. **第一类买卖点**：趋势背驰后的顶/底；扩展为盘背中的一买/一卖结构。  
7. **第二类买卖点**：一买/一卖后，次级别回试不创新低/不创新高的结构点（均线表述：第一次黏合/交叉结束点）。  
8. **第三类买卖点**：离开中枢后次级别回抽**不进**中枢区间。  
9. **趋势背驰后反弹分类**（29 课）：最后中枢扩展、更大级别盘整、≥原级别反趋势。  
10. **九段升级**：中枢内次级别走势延伸至 **9 段**可构成更高级别中枢（三段式叠加）。  
11. **两中枢波动重叠**：可构成更高级别走势类型。  
12. **a+b+c 盘背**：若 c 与 a 盘背，后续 d 至少触及 a 的极值；**a+A+b** 中 b 与 a 盘背时 c **未必**回 A（与三买转化相关）。  
13. **板块强弱指标**：\( \frac{0.1a+0.2b+\cdots+0.8h}{N} \)（分档计数后加权平均）。  
14. **区间套**：在背驰段内逐级向下找背驰点，直至操作可见最低级别；与走势必完美同构。  
15. **盘整背驰**：围绕同一中枢（或 a+b+c 单中枢结构）的同向两段力度比较；常用于震荡操作。  
16. **趋势背驰**：至少两个同向中枢后的趋势段间力度比较（书中亦区分形态称呼）。  
17. **奔走型中枢**：回抽段低点略破前高附近，显示强势，仍属中枢震荡一种形态特征。  
18. **小级别转大级别**：本级别未见标准背驰而反向走势已破坏原结构，常需次次级别或盘口确认。  
19. **结合律**：走势段可按不失真原则重新组合，使中枢位置更利于当下分析（与多义性配合）。  
20. **DD（震荡最低点）**：29 课中最后中枢区间下沿相关极值，用于判定最弱反弹是否触及。  

### 常见结构记号（书中习惯）

| 记号 | 含义 |
|------|------|
| `a+A+b` | 进入段 + 中枢 + 离开/再进入类段 |
| `a+b+c` | 三段次级别连接常构成单中枢盘整或高一级一段 |
| `a+A+b+B+c` | 趋势典型表达式，A、B 为同级别中枢 |

## 使用建议

1. **先第一章 + 第九章第六节**，建立“完美—背驰—一二买—中枢”链条，再读第二章严格定义。
