## 整体定位

本系列从**实战出发**重新编排缠论，核心思路：

1. 先教「怎么买」，再讲「为什么」
2. 先用模糊概念建立整体感，再逐步精确化
3. 动力学是树干，形态学是树枝——理解动力学后可推导形态

与缠论原文 108 课相比，本系列的独特价值在于：
- 打破了从笔线段学起的传统路径（避免 abandon 式放弃）
- 从买卖点倒推出整个理论体系的必要性
- 强调"由道御术"——先理解思想再学方法

## 第一讲：关于什么是缠论？（概论）

**核心要点**：

1. **缠论的来源**：禅师（缠中说禅）的博客文章，108 篇构成，立足基本面/技术面/比较轮动三大系统
2. **难学的两个原因**：
   - 语言晦涩：禅师文学/数学功底深，术语多
   - 行文结构：博客文随心而作，缺乏系统排版
3. **学习方法论**：不能只背公式，要理解实战意义——"知其然"才不容易出错
4. **缠论的体系结构**（从实战倒推）：
   - 交易核心 → 买卖点（三类）
   - 第二类/第三类买卖点 → 形态学（中枢、走势类型、笔、线段）
   - 第一类买卖点 → 动力学（背驰、区间套、能量结构）
5. **动力学 vs 形态学**：
   - 动力学 = 树干/结构，理解后可推导形态
   - 形态学 = 公式/树枝，是最终的应用层
   - 理解动力学后，可自由运用 MACD/均线/其他指标
6. **"通论"定位**：缠论用最原始的方式解析市场，是所有方法的基础

## 第二讲：广义的第一类买卖点

**核心要点**：

1. **教学路径反思**：传统从笔/线段学起容易放弃（背单词背到 abandon），本课先教买入
2. **术语处理**：先用通俗表达，后期再给精确定义（级别、中枢、背驰）
3. **走势的三种基本类型**：上涨、下跌、盘整
4. **级别的两种理解**：
   - 递归级别（缠论严格定义，需学中枢后理解）
   - 时间级别（软件时间周期图，如 30 分钟/日线，先用此简化）
5. **六种走势组合分类**：

   | 组合 | 图形 | 分类 |
   |------|------|------|
   | 上涨→下跌 | 倒 V | 多头陷阱 |
   | 下跌→上涨 | V | 空头陷阱 |
   | 上涨→盘整→下跌 | — | 反转 |
   | 下跌→盘整→上涨 | — | 反转 |
   | 上涨→盘整→上涨 | 闪电 | 中继 |
   | 下跌→盘整→下跌 | 闪电 | 中继 |

6. **买入的两大风险**：
   - **风险一：跌势未尽**（下跌→继续下跌，抄底抄早了）
   - **风险二：盘整后再跌**（下跌→盘整→下跌，中继走势）
7. **第一类买点 = 背驰买点**：
   - 在「下跌→盘整→下跌」结构中，比较前后两段下跌力度
   - 第二段下跌力度弱于第一段 → 背驰 → 跌势已尽 → 一买形成
   - 类似 MACD 背离，可先用 MACD 辅助判断
8. **实战操作法（第一种买卖方法）**：
   - 确认操作级别（如 30 分钟）
   - 等待「下跌→盘整→下跌」结构出现
   - 判断出背驰 → 买入
   - 买入后若形成「下跌→盘整」而非「下跌→上涨」→ 马上退出
9. **中继买入**：上涨→盘整→上涨时买入，需用中枢概念解决盘整后方向问题（后续讲解）

## 第三讲：三种背驰的判断方法

**核心要点**：

1. **背驰的本质**：两段同级别走势的力度比较，判断动力衰竭
   - 比喻：一帮人顶重物往高处走，越来越慢，最终力量衰竭
2. **三个关键词**：
   - **同级别**：30 分钟与 30 分钟比，不跨级别比较
   - **走势**：同向比较（上涨比上涨，下跌比下跌）
   - **力度**：核心判断依据
3. **三种力度比较方法**：

   | 方法 | 指标 | 判断标准 | 优缺点 |
   |------|------|---------|--------|
   | K线斜率法 | K线图 | 同等时间内斜率越小 → 力度越弱 | 直观但模糊，新手难判断 |
   | 均线交叉面积法 | 双均线（如5日+10日） | B段金叉/死叉闭合面积 < A段 → 背驰 | 较精确，交叉点即背驰点 |
   | MACD柱面积法 | MACD | C段绿柱面积 < A段 → 背驰 | 最直观，DIF/DEA位置+柱子面积 |

4. **背驰的局限性**：
   - **滞后性**：大级别（周线以上）确认背驰时位置离底部已远
   - **多次背驰**：背驰后可能二次、三次背驰，成功率非100%
5. **解决方案预告**：
   - 精确化 → 下讲（切换级别+趋势平均力度）
   - 提高胜率 → 标准背驰（趋势背驰，附加条件更严格）

## 第四讲：缠论的精确化（解决背驰滞后性）

**核心要点**：

1. **背驰 vs 背离的区分**：
   - 背驰（缠论）：强调**面**的概念，是一个交易区间
   - 背离（常规）：强调**点**的概念，某个具体点位
   - 区间难以量化 → 有主观性 → 需要精确化
2. **精确化方法一：切换级别**
   - 大级别确认背驰后，切换到次级别找买点
   - 次级别中按原办法找转折点 → 距离真正低点不远
   - 实战中最常用，但观测不直观，需处理级别服从关系
3. **精确化方法二：趋势平均力度**
   - 定义：均线交叉面积 ÷ 时间 = 平均力度（实时计算）
   - 当前平均力度 < 上一段 → 背驰即将形成
   - 再看短期/长期均线距离缩短 → 底部即将形成
   - 风险：预判性强，准确率略低，需要盘感
4. **MACD精确化应用**：
   - 不必等柱子面积全部走完（否则同样滞后）
   - 柱子伸长力度变慢或缩短时，预估面积 < 前段 → 判断背驰
   - 同样有预判风险
5. **最佳实战策略（两者结合）**：
   - 用方法二（平均力度）筛选将要背驰的品种（行情还在低点附近）
   - 切到小级别（方法一）确认交叉点 → 解决延迟
6. **解决多次背驰问题**：
   - 背驰必然制造某级别买卖点 → 逆转必然，但不永远
   - 方法A：量化逆转时间，在时间结束前撤退
   - 方法B：标准背驰 = 趋势背驰（条件更苛刻 → 成功率更高）

## 第五讲：缠论中标准的第一类买卖点

**核心要点**：

1. **广义 vs 标准第一类买点**：
   - 广义一买：不区分趋势/盘整，只要背驰即成立
   - 标准一买：特指**趋势背驰**买点（附加条件）
2. **趋势与盘整的区分**：
   - **趋势**：拥有两个以上同方向、同级别中枢的走势
   - **盘整**：只有一个中枢的走势
3. **标准一买（趋势背驰买点）**：
   - 结构：A + [中枢A] + B + [中枢B] + C
   - C段与B段形成背驰 → 趋势背驰 → 标准一买
4. **盘整背驰**：
   - 结构：A + [中枢] + B
   - B段与A段形成背驰 → 盘整背驰 → 广义一买
5. **为什么标准一买更优**：
   - **成功率更高**：条件苛刻，连续下跌动力衰竭可能性更大
   - **涨幅可预计**：趋势背驰后反弹**必然回到前一个中枢区间**（至少下沿）
   - 三种反弹情况：①触及中枢下沿后下跌 ②触及后横盘 ③触及后继续上涨
6. **盘整背驰的价值**：
   - 转折必然，但幅度/力度无法预计
   - 大级别（周线/月线）盘整背驰在日线涨幅很可观
   - 是第三类买卖点的关键构成
7. **完整交易法**：
   - 30分钟趋势背驰出现 → 买入
   - 上涨从1分钟演化到5分钟...
   - 触及前一个中枢下沿时 → 卖出
   - 或根据次级别上涨背驰判断卖点

## 第六讲：什么是缠论中枢

**核心要点**：

1. **庖丁解牛类比**：
   - 初学者看到整头牛（无规律的 K 线图）
   - 了解缠论分解后，看到肌理筋骨（上涨/下跌/横盘的组合）
   - 中枢 = 识别每根骨头的关键节点
2. **中枢为何必然存在**：
   - 资金不可能永远一致 → 走势不可能一直单向
   - N 字型结构（反复）是任何级别走势的必然特征
   - 任何走势的完成都至少形成一个这样的结构
3. **中枢的定义**：
   - 连续三段同级别走势类型的**价格重叠区间** = 高一级别的中枢
   - 结构示例：A + B + C + D + E，其中 BCD 构成中枢
   - 区间高点 = 两高点中较低者
   - 区间低点 = 两低点中较高者
4. **中枢的边界**：
   - 中枢前的上涨/下跌**不属于**中枢区间（进入段）
   - 中枢区间不限于三段，可延伸（至少三段）→ 中枢延伸
5. **中枢的作用**：
   - 定义走势类型
   - 划分级别

## 第七讲：缠论第一类买点的精确化定义

**核心要点**：

1. **中枢确定的两个基础**：
   - 中枢区间的确定（已讲）
   - 中枢级别的确定（本讲重点）
2. **级别递归关系**：
   - 30分钟中枢 = 由5分钟级别走势构成
   - 5分钟中枢 = 由1分钟级别走势构成
   - 理论可无限向下递归，实战最小看1分钟
3. **级别 vs 时间周期**：
   - 中枢级别**不等于**时间周期
   - 水平高可在1分钟图上分辨出年线级别中枢（繁琐但理论可行）
   - 实战中切换时间周期图简化分析完全可行
4. **走势类型精确定义**：
   - 盘整 = 有一个该级别中枢的走势
   - 趋势 = 有两个以上同方向该级别中枢的走势
   - 任何走势必须形成该级别中枢才算完成
5. **第一类买点精确化**：
   - 比较中枢前后走势的背驰与否 → 背驰就买入
   - 标准一买 = 趋势走势中，比较中枢前后走势背驰
   - 第一目标 = 前一个中枢区间的下沿
6. **庖丁境界**：
   - 所有走势 = N个不同级别走势类型的连接
   - 眼中看到N个关节点 → 顺着关节点操作
7. **遗留难点**：中枢的演化（扩展/延续/小转大）→ 下讲

## 第八讲：中枢的演化——行情如何从短线升级为中线

**核心要点**：

1. **中枢的形态**（补充）：
   - 重心定义 = 构成中枢的次级别走势中间点连线
   - **平移**（重心水平）：标准形态、收敛形态、扩散形态
   - **斜移**（重心倾斜）：顺方向、反方向
2. **中枢的三种演化**：

   | 类型 | 定义 | 含义 |
   |------|------|------|
   | 延续（延伸） | 走势始终围绕中枢震荡，超过三段 | 中枢未被打破 |
   | 破坏 | 次级别走势突破中枢后回抽不返回 | = 第三类买卖点 |
   | 级别升级 | 小级别中枢变大级别中枢 | 行情从短线升为中线 |

3. **延伸的特殊情况**：
   - 延伸达到9段时 → 形成三个同级别中枢重叠 → 级别升一级
4. **中枢的破坏 = 第三类买点**：
   - 某级别中枢的次级别走势突破中枢区间
   - 随后的次级别回抽低点不返回中枢以内
   - 即最安全的第三类买点
5. **级别升级的两种方式**：
   - **扩展**：三买失败回落进入第一个中枢区间 → 中枢延伸变种 → 升级
   - **扩张**：第二个中枢的震荡与第一个中枢最高点发生重叠（但不进入区间）→ 升级
6. **实战灵活性（走势的多义性）**：
   - 出现扩张时理论上要升级到更高级别分析
   - 实战中可以继续当做原级别中枢处理
   - 选择标准：让分解更简单、更有利于当下操作

## 第九讲：什么是缠论当中的第二类第三类买卖点

**核心要点**：

1. **为什么先讲一买**：二买/三买都建立在一买之上，地基不牢则漏洞多
2. **第二类买卖点**：
   - 定义：一买后行情反弹 → 第一次次级别下跌 → 下跌结束段 = 二买
   - 本质：次级别的第一类买卖点判定 → 二买最终演化为一买判断
   - **位置三种情况**（决定力度）：
     - 二买在一买之下 → 力度最弱，可能是大级别盘整
     - 二买在前一段下跌中间 → 力度中等
     - 二买在前一段下跌的中枢之上 → 力度最强，V型反转
3. **第三类买卖点**：
   - 定义：反弹形成中枢 → 次级别走势突破中枢 → 回抽不回中枢内 = 三买
   - 本质：中枢的破坏
   - 出现时机：第一个中枢形成后，盘整背驰后次级别不回中枢区间
4. **二买与三买可能重合**：
   - 二买在前走势最后一个中枢上形成 → 二买 = 三买
   - 通常对应V型反转，凌厉上涨
5. **涨幅预计**：
   - 一买后涨幅 = 至少回到第一个中枢区间
   - 二买/三买后涨幅 → 下讲

## 第十讲：实战中三种买卖点的综合使用

**核心要点**：

1. **缠论交易的三种股票分类**：
   - 在买点上的 → 买入
   - 在卖点上的 → 卖出
   - 正在构造买卖点的 → 等待
   - 克服恐惧（大阴线不敢买）和贪婪（大阳线不愿卖）
2. **三类买点的涨幅比较**：

   | 买点类型 | 涨幅速度 | 特点 |
   |---------|---------|------|
   | 一买 | 较慢 | 安全性最高 |
   | 二买 | 中等 | 50%概率主升浪 + 50%缓慢推高 |
   | 三买 | 最快 | 日线20%+，但辨别难度大、变数大 |

3. **三买的风险**：
   - 次级别回抽后可能形成次次级别中枢跌回原中枢 → 失败
   - 不好判断是否成功/强势
   - 上涨接近完成时（次级别将形成背驰）→ 不介入
4. **综合操作策略**：
   - **大资金/稳健型**：用一买持有零风险底仓（大周期）+ 1/2~1/3 资金用 30 分钟二买/一买做波段降低成本
   - **小资金/激进型**：只操作设定级别的三买 → 避开盘整 → 买入后要么大涨要么大跌，速度最快
5. **盘整背驰的实战用法**：
   - 大级别趋势背驰难出现 → 盘整背驰也有操作价值
   - 大级别向上无背驰 + 小级别下跌盘整背驰 → 可参与超短线
   - 大级别已将形成背驰 → 小级别盘整背驰不参与
6. **级别分析**：
   - 实战用三个级别同步分析（操作级别 + 上一级 + 下一级）
   - 小周期与大周期相悖时不参与
   - 寻求共振 → 胜率提高
7. **中枢的力学本质**：
   - 中枢 = 多空争夺的阵地
   - 级别越大吸引力越大
   - 整个行情 = N个中枢的合力方向
   - 大的阵地占领比小的更具战略意义

## 第十一讲：学缠三境界

**核心要点**：

1. **全系列回顾**：
   - 从走势三分类（上涨/下跌/盘整）→ 三类买卖点 → 全部基于精确严谨的逻辑推导
2. **学习失败的根本原因**：
   - 没有真正理解缠论的必然性 → 因失败而怀疑 → 放弃
   - 初期判断不准确很正常
   - 传统分析方法的旧习惯会干扰
3. **缠论的哲学基础**：
   - 行情图 = 各种情绪通过买卖在图表中留下的痕迹
   - 人性相通、情绪不变 → 华尔街没有新鲜事
   - 消息/政策/利好利空 → 经过人心预期 → 落实到买卖
4. **笔线段 vs 中枢（两种分析体系）**：
   - 笔线段 = 几何系统（精确但繁琐）
   - 中枢 = 动力系统（更适合实战）
   - 两者可独立存在，最终都回归中枢理论
   - 实战建议：直接用中枢分析，将明显高低点视为次级别走势即可
5. **学缠三境界**：
   - **第一境界**（见山是山）：一脸茫然，看不懂
   - **第二境界**（见山不是山）：理论熟悉 + 实战经验 → 打开任何图1分钟内决定买卖/等待/放弃 → 稳定盈利
   - **第三境界**（见山只是山）：心态+资金管理到位 → 信手拈来 → 不执着于技术/中枢/背驰/短线中线
