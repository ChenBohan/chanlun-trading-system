## 背驰

| 概念 | 讲次 | 说明 |
|------|------|------|
| 背驰的定义 | P02 | 下跌→盘整→下跌，第二段力度弱于第一段 |
| 背驰的本质 | P03 | 两段同级别走势的力度比较，判断动力衰竭 |
| 背驰三要素 | P03 | 同级别 + 同向走势 + 力度比较 |
| K线斜率法 | P03 | 同等时间内斜率越小=力度越弱，直观但模糊 |
| 均线交叉面积法 | P03 | 双均线闭合面积比较，交叉点=背驰点 |
| MACD柱面积法 | P03 | 柱面积比较+DIF/DEA位置，最直观 |
| 背驰 vs 背离 | P04 | 背驰=面/区间（缠论）；背离=点（常规） |
| 背驰的滞后性 | P03 | 大级别确认背驰时位置离底部已远 |
| 多次背驰问题 | P03 | 背驰后可能二次三次背驰，成功率非100% |
| 趋势背驰 | P05 | 趋势走势（两中枢以上）中的背驰，成功率高 |
| 盘整背驰 | P05 | 盘整走势（一个中枢）中的背驰，幅度不确定 |
| 趋势背驰涨幅 | P05 | 必然回到前一个中枢区间（至少下沿） |
| MACD 辅助判断 | P02 | 背驰类似 MACD 背离，初期可用 MACD 辅助 |
| 追涨条件 | P02 | 未形成背驰/未出现可能背驰时可追涨 |
