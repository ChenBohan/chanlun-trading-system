## 序言（全书框架）

- **核心概念**
  - 多数传统技术分析属**经验归纳+预测**；缠论从“上涨/下跌/盘整必结束且只转两类之一”出发，属**公理化分类**，强调当下条件而非猜未来。
  - **体用**：利润与风险同在；技术可控、爆雷与政策偏被动→**降成本、下跌结束介入、可执行退出**为风控核心。
  - **立体**：技术须叠加**基本面（行情性质）**与**比价（板块内梯队）**；操作级要联合**上级别与次级别**。
  - **脉络**：四部分——（1）笔线段中枢背驰买卖点等理论；（2）走势能量；（3）基本面与比价与周期；（4）操作细节与《论语》思维应用。
  - **人**：操作系统无法复制；“知识→能力”需大量实盘；反对把缠论当信仰或秘籍。
- **操作规则（买入前自检清单，原文列举）**
  - 行情性质与阶段；活跃板块及先后顺序；板块阶段；个股在板块中地位；指数阶段；个股买点级别与大级别；买点后不应出现的情形；必须退出的情形。
- **关键要点**
  - 短线受容量限制不可无限放大；大资金更适合**固定品种+基本面**长持配合技术做波段。

## 1 笔和线段

- **核心概念**
  - 笔、线段、走势类型、均线、指标均为**分解走势的工具**，各有适用范围；不存在放之四海皆准的工具。
  - 线段定义明确但**滞后**（须被破坏才确认）；最小级别用走势类型划分有时更贴近原貌。
  - 标准学习/实操程序：**包含 → 分型 → 旧笔/新笔 → 特征序列 → 特征序列分型 → 线段第一/二种破坏**。
  - **包含**：相邻 K 线高低点包含则合并；阴阳统一处理；以最高最低为区间；**不可跨 K 跳**；方向随前两 K 为上升/下降处理（向上取高高低、向下取低低高）；连续包含逐根合并至无包含。
  - **分型**：经包含处理后的三根 K 线；顶/底分型区间；中继分型与“顶底成立”条件（顶/底分型 + 第四根跌破/突破分型区间才具方向性）。
  - **分型力度**：底分型第三元素远高于第一元素→反转意味强；顶分型第三元素强覆盖第一元素→警示强（仍未必是顶）。
  - **定理**：任何级别任何走势的顶（底），在顶（底）分型出现前均不成立——持仓可等顶分型、空仓可等底分型再细判。
  - **笔**：仅向上/向下；至少七根无包含 K（旧笔路径）；顶分型整体高于底分型整体且区间不能互相包含；中继顶/底分型不改变笔方向。
  - **旧笔与新笔**：旧笔要求顶底分型间 K 与分型元素无包含；**新笔**放宽：顶分型最高与底分型最低之间（不含这两根）**至少三根 K 线，中间可与分型元素包含**。
  - **线段**：至少三笔，奇数笔同向延伸；**特征序列**为反向笔序列；向上线段中特征序列包含按**向上**处理，向下线段反之。
  - **破坏**：**第一种**——特征序列无缺口，反向延伸成段则前段结束；**第二种**——有缺口，须从假设转折起取特征序列直至出现分型确认；**同一线段内**特征序列包含必处理，**分属两假设线段**时有时不合并（图 1-25 类）。
  - **能量与包含**：第一种破坏能量足，乱合并会模糊力度；第二种破坏能量弱，包含体现原趋势延续。
  - **跳空**：逆原线段方向的跳空可划为**独立线段**；顺向跳空并入原段。
- **操作规则**
  - 实操建议：**画笔公式自动画线** → 再人工划线段；小级别人工笔划成本高。
  - 底分型后要延伸向上笔，通常需**突破底分型区间上沿**；顶分型类推。
  - 练习目标：**任意分笔图可快速眼分线段**，再谈最小中枢。

## 2 走势中枢

- **核心概念**
  - 中枢是**再组合**的最小构件；无中枢则无走势类型、区间套与买卖点（在标准递归路径下）。
  - **最小级别中枢**：至少三条**连续、完成、有重叠**的线段；区间取前三段 **\[最高低点, 最低高点\]**。
  - **中枢延伸**：离开中枢的次级别走势**回到中枢区间**（触及即可），中枢“未破坏”，可反复震荡；延伸越久，多空换手与共识越充分。
  - **中枢延续**：离开段结束后必有同级别段**带回中枢区间**（部分触及即可）。
  - **中枢破坏**：离开后反向段**不能回到**中枢区间。
  - **扩张**（本书用法）：围绕震荡**满九段**同级别线段 → 级别上升；**扩展**：破坏后更大级别三段返回，构成更高级中枢（与原文“扩张/扩展”混用作了区分说明）。
  - **盘整**：一个中枢；**趋势**：多个中枢且震荡区间**互不重叠**；连接相邻中枢的走势级别 **低于** 中枢级别（极端可为缺口）。
  - **走势必完美**：任意级别完成走势至少含**一个**该级别中枢 → 至少三段次级别；方向有上涨、下跌、横盘（盘整可有三种方向表现）。
  - **第三类买卖点**：以中枢为参照——三卖为向下离开且回抽**不入**中枢下沿；三买为向上离开且回抽**不入**中枢上沿；本质是“破坏中枢引力”后的确认。
  - **级别递归**：在选定图上“一笔/一段”对应的最小构件一旦约定，**全程不得偷换**；升级来自九段、扩展或更大周期图的等价映射。
- **操作规则**
  - 在选定周期图上划线段即设定了“当前最小可观察级别”；可主观定为 5 分钟、日线等，**递归一致即可**。
  - 三类买卖点依附中枢与走势完成；背驰比较需同级别、有中枢或反向段间隔。
  - 震荡市中：**中枢上沿压力、下沿支撑**常反复测试；突破后回抽确认再动，避免把第一次假突破当趋势。
  - 读图顺序建议：**先标中枢区间** → 再判当前是延续、破坏还是升级途中 → 最后才落到买卖点。

- **关键要点**
  - “客观重叠”先于定义；定义是为精确描述。
  - 走势类型与**线段**本质不同：线段仅几何，走势类型含完成与背驰。
  - 中枢不是“箱体画线游戏”，而是**已完成次级别走势的重叠区**；随意画框易与理论脱节。

## 3 背驰

- **核心概念**
  - **背驰**：走势方向与**力度**背离；比较须**同级别**，且通常中间有中枢或反向走势隔开。
  - **盘整背驰**：a+A+b 中 b 与 a；**趋势背驰**：趋势最后一背驰段。
  - **力度**：可粗用空间/时间（平均速率）；**均线**看相交**面积**；**MACD** 看黄白线高低、红绿柱面积与高度——但**背驰是走势本身的背驰**，指标只是尺。
  - **区间套**：背驰段内再背驰；多级别共振时转折概率高。
  - **走势必完美（梳理）**：可分解为上下平；任向走势必结束；结束后只转另两种之一；连续三段次级别构成高一级形态。
  - **级别**：中枢级别即走势级别；九段升级；原文前后级别“名相”差异被解释为**同一走势不同命名体系**。
  - **多义性**：划分起点、结束点与背驰点选取可导致合理解释不唯一，须结合当下最利分类。
  - **背了又背**：小级别不断延伸、中枢不断新生时，上一背驰判断可被“走势未完成”推翻；对策是**升级视角**或等待**走势类型完成**再定夺。
  - **第一类买点与背驰**：下跌趋势最后一个中枢下方的背驰段终点，是理论上一买位置；实盘常配合**区间套**在更小级别精确定位。
- **操作规则**
  - 有中枢即可对震荡段做力度比较；V 反若后段弱于前段，要回前起点往往需**更大级别**走势。
  - 比较两段力度时：**起点与终点都要落在“完成的走势”上**，勿拿未走完的段与已走完的段比。
  - MACD 用法：**回抽零轴**后再起的柱堆，与上一柱堆比面积/高度，常比单纯“金叉死叉”更贴近背驰逻辑。
  - 区间套实操：从大级别确认“可能在背驰段”→ 逐级缩小到可操作周期找**次次级别背驰**共振。

  - 图 3-5 及演化实例：`img_052.jpg`～`img_062.jpg`
- **关键要点**
  - 指标背离 ≠ 走势背驰（小级别延伸常骗指标）。
  - 航天火箭与三类速度的类比说明：**离开中枢后须更大力度**否则拉回。
  - 背驰是**概率优势**而非水晶球；须配套止损与级别升级规则。

## 4 买点辨微

- **核心概念**
  - **广义一类买点**：**背驰段结束点**；严格一类：下跌趋势末 + 区间套 + 最后中枢常需**三卖**确认（实盘中变种多）。
  - 四类基础结构：**横盘 a+b+c**、**下跌 a+b+c**、**a+A+b**、**趋势 a+A+b+B+c**；常互相嵌套。
  - **二类买点**：一类后新走势**第二段次级别结束**；本质是**次级别一类**；与**是否创新低**无必然关系；勿与**第一个中枢内低点**混淆（茅台周线例）。
  - **三类买点**：次级别**离开** + 次级别**返回不入**中枢；离开/返回均须**走完的走势类型**；离开段必先走出 **a+A**；与“盘整+盘整”扩展细辨。
  - **小转大**：突发分力打破平衡 → 可能**无本级别一类**，依赖二类或后续确认。
  - **中阴**：走势将变未变、多义性高的一段。
  - **同级别分解**：按固定规则把走势拆成可操作的同级别段。
  - **类二买 / 强势二买**：回抽浅、快速重新离开中枢，常对应更强合力；可与三买在表现上接近，划分上仍宜回到次级别完成度。
  - **盘整中的“假突破”**：离开中枢后无力、迅速跌回，易形成**三卖未成**或中枢延伸；辨微重在次级别是否走出**新的完成结构**。
- **操作规则**
  - 一类易遇**延伸与背了又背**，宜叠加**大级别二、三类**共振。
  - 二类偏**右侧**，条件更多；横盘类二买要防**第三段再横后下跌**。
  - 三类：能划分**两段次级别**往往够用；实盘不必穷尽所有理论分支。
  - 中阴阶段：**缩小仓位或观望**，待次级别走出明确三类之一再动；忌在中阴里频繁追涨杀跌。
  - 同级别分解用于**固定规则复盘**：例如始终按“线段级”或“走势类型级”切分，避免同一图上来回换标准。

  - 买点不是“一个点”，而是**满足几何与完成条件的一段区间**；精细入场靠次级别区间套。

## 5 走势能量概述

- **核心概念**
  - 走势即**多空能量**轨迹；理论是几何化度量能量；操作者宜**零向量**（不把自己的情绪当分力）。
  - **分型能量**：三元素力度、一半位置、是否破第一元素低/高、包含与跳空含义。
  - **笔/线段**：笔为单次释放的规范单位；线段为更大单次释放；**中枢**为多空纠缠空间，段数越多**共识越“重”**。
  - **背驰成因**：空方衰竭、多方相对增强；一类后回升快慢与**最后中枢位置**三类强弱划分。
  - **二类能量**：趋势+盘整最强；回升+弱势回抽常更适合实操；二与三可重叠（强势）。
  - **三类能量**：离开/返回段的**复杂程度**反映合力犹豫；最强为趋势离开 + 轻回抽；**好三买常缩量**（抛压轻）。
  - **小转大 / 双回抽**：消息与大户分力导致非线性；一类不必然存在，**二类必然存在**（在相应定义下）。
  - **能量与 K 线实体**：连续大阳/大阴常对应强分力释放；缩量横盘常对应**筹码锁定或观望**，突破时需补量确认（书中多处与实盘案例呼应）。
  - **线段第一种破坏 vs 第二种**：前者多空一方仍占优、转折利落；后者反复纠缠，能量上更偏**原趋势余温**，与包含处理规则相呼应。
- **操作规则**
  - 短差与判断都要回到**能量是否打断、是否延续**的直觉，最终仍须落回几何与背驰。
  - 看能量是为**快速过滤**：例如暴量长阴破坏关键位，即使小级别有买点也宜降级处理或观望。
  - 一类买后若反弹**无力、黏滞**，能量上多为弱势修复，二类确认前不宜重仓押注 V 反。
- **图片引用**
  - 图 5-1～5-5：`img_083.jpg`～`img_087.jpg`
- **关键要点**
  - 级别“差一级”有时是**递归起点不同**，非走势本身变了。
  - 能量解读是**辅助层**：不能替代中枢、走势类型与背驰的硬条件。

## 6 交易的艺术

- **核心概念**
  - 四动作：**买、卖、持股、持币**；理论价值在**完全分类**后对接动作。
  - **立体分析**：操作级 + 上级别 + 次级别（常为三级别联立）。
  - **分型操作**：无顶分型不止盈、无底分型不抄底；站稳分型上沿 ≈ 小级别二买或首中枢。
  - **表里关系**：表 6-1，30 分笔状态 × 5 分笔状态共 16 类；可扩展到三级别 64 类。
  - **买卖点在几何上可数，实盘千变万化**：一类重**趋势双中枢后背驰**；二、三类与**市场环境、放量**结合。
  - **卖出**：顶可在背驰或非背驰段出现；须防**无区间套、小转大、无利润卖点**；**盈利变亏损**为纪律大忌。
  - **误区**：笔不宜直接作中枢构件（级别不齐）；线段**原则上不可操作**；高低级别笔与线段无必然对应；笔线段**非绝对必须先学**（可先走势类型）。
  - **指数与复盘**：上证/深证/中小板/创业板 + 金融证券；板块指数与个股**区间套式**影响。
  - **持币也是头寸**：震荡市与中阴阶段，现金比例是风控工具；书中强调“会空仓”与“会持仓”同等重要。
  - **级别联立示例逻辑**：日线定方向与仓位上限 → 30 分定波段 → 5 分找精确买卖点（具体周期可替换，**比例与一致性**优先）。
- **操作规则**
  - 30 分顶分型 + 5 分三类卖 + MA5 等组合**分类卖出**。
  - 复盘：指数小级别连续分解 + 涨幅榜结构 + 行业/概念板块轮动；每周流程（市盈率排序板块 → 龙头市值排序 → 多周期个股）。
  - 买入后**走势分类跟踪**：是否按计划走出二买/三买路径；若结构失效（如三买后迅速跌回中枢），按规则减仓或离场，不“讲故事扛单”。
  - 卖出可分层：**战术卖点**（次级别背驰、破关键均线）与**战略卖点**（大级别走坏、基本面逆转）分开执行。

## 7 基本面概述

- **核心概念**
  - 技术局限：**行情性质**（牛熊震荡）、**板块**、**股性**决定同样买点后劲。
  - 周期：**康波、库兹涅茨、朱格拉、基钦**嵌套；行业与库存、设备、地产、债务共振。
  - **CRB**、**PPI**、**M1/M2**、**巴菲特指数（市值/GDP）**、**食利资金**在债市/港股/股市间轮动。
  - 股市大行情 ≈ **货币增量 + 资金入市**；估值够便宜是重要条件。
  - **政策周期**三级嵌套；宽松/紧缩质变常催化牛熊；**成交量**为牛市重要确认。
  - **M0/M1/M2 分层**：M1 偏交易活性，M2 偏总量沉淀；**剪刀差**扩大/收窄常对应风险偏好迁移（书中作宏观背景框，非日内信号）。
  - **经济短周期与库存**：基钦周期约 3～4 年，和工业企业补库去库、PPI 拐点常被一并讨论。
  - **估值锚**：除巴菲特指数外，历史市盈率/市净率分位、风险溢价等，在书中强调为**区间与概率**，非精确顶底。
- **操作规则**
  - 消息与政策须**经走势确认**；“消息测试走势健康度”而非单向因果。
  - 宏观面向下时：**降低仓位上限、放大操作级别、减少三类追高**；宏观共振向上时，技术买点**成功率与盈亏比**往往更好。
  - 基本面用于回答“这行情配不配重仓”，技术面回答“何时、何价、何级别动手”。
- **图片引用**
  - 图 7-1、7-2：`img_107.jpg`、`img_108.jpg`
- **关键要点**
  - 书中部分周期推断（如沪指十年牛起点、2024 附近等）为**作者当时归纳**，用时须结合最新数据，勿作刚性预测。
  - 基本面恶化而技术仍涨时，警惕**最后一冲**；基本面改善而技术未确认时，宜**等走势结构**再介入。

## 8 板块的基础认识

- **核心概念**
  - 操作顺序：**行情性质 → 主线板块 → 个股 → 技术买卖点**。
  - 产业链分层：**能源 → 材料/工业 → 消费** + **基础服务（金融、TMT、物流等）**。
  - 四模组：**消费、成长、周期、价值**（可互相渗透周期属性）。
  - **基钦周期约 40 个月**主线轮动经验顺序：**消费 → 成长 → 价值 → 周期**（历史归纳，非铁律）。
  - 震荡市：**量缩、结构行情、日线盘整 + 30 分趋势**常见；须跟主线、短中线换股。
  - 公司分析：**营收/净利增长、ROE、ROA、负债率、主营、毛利率、现金含量/收现比**；**垄断与龙头**（品牌、技术、细分市占）。
  - **板块指数与个股关系**：龙头先行放量突破，跟风股常走出**相似结构但级别更小**；用区间套在板块指数上定节奏，再落到个股。
  - **题材 vs 产业趋势**：短线题材多一日游；能与**业绩、订单、政策中期方向**共振的板块，更适配缠论波段持仓。
- **操作规则**
  - 后发先至：板块启动后用**龙头比价**做二梯队；媒体大热时警惕阶段顶。
  - 选股池维护：**每周更新**强势板块成分股，剔除跌破大级别均线的弱势股，保持池子与主线同步。
  - 同一板块内**回避“最弱梯队”**：除非明确博反转一类，否则弱于板块指数的结构易浪费行情。
- **图片引用**
  - 图 8-1～8-3：`img_109.jpg`～`img_111.jpg`
  - 图与案例延续：`img_112.jpg`
- **关键要点**
  - 上轮涨幅最大的板块下轮常弱——**资金要新故事与估值空间**。
  - 没有板块共振的单票技术买点，胜率依赖**个股基本面与筹码**，须降仓或缩短持有周期。

## 9 操作中的具体问题

- **核心概念**
  - **主力**：大分力引导心理，仍服从筹码与背驰；辅助非替代理论。
  - **测试与双回抽**：压力/套牢区需**换手观察**，非简单“洗盘”叙事。
  - **正确思路**：**涨了再买**（板块与个股确认后再找次级别买点）；不预测，只**分类与确认**。
  - **降成本至零**：大级别底仓 + 多级别资金分包做差价；T+1 下**拆分日内份额**；短差主要在**中枢震荡**，慎在“非背驰拉升段”乱动。
  - **实例（云铝）**：美元弱、商品涨 + 板块先行 + 周线突破回抽 + 30 分三买。
  - **选股**：大盘特征 → 板块 → **大级别多头（如 250 日线向上）** + 日线/周线二买或三买优先。
  - **止损与退出**：书中强调技术止损应**可执行**（关键位、次级别结构破坏），与基本面止损（逻辑证伪）分层。
  - **仓位与节奏**：上班族宜**少而精**，把精力放在大级别结构与板块主线上，避免分钟级过度交易。
- **操作规则**
  - 介入级别与退出级别宜对称；三买后沿 **5 分→30 分→日线 MA5** 阶梯上移，可**破 5 日线**再考虑离场（示例策略）。
  - 做差价纪律：**向上离开中枢且不背驰**时少做反 T，避免卖飞主涨段；**中枢内**可做部分仓位高抛低吸。
  - 消息突发时：先看**是否改变所在级别走势类型**；若仅次级别跳空，宜等**次级别完成**再归类买卖。
- **图片引用**
  - 图 9-1～9-10：`img_112.jpg`～`img_121.jpg`
- **关键要点**
  - 脉冲行情靠**提高级别或叠加板块/基本面**过滤。
  - “主力思维”用于理解**分力**，不用于迷信叙事；一切回到走势结构与背驰。

## 后记

- **核心概念**
  - **当下**优于预测；相同逻辑用于每个新当下。
  - 缠论难在须从**逻辑与能量**理解形态，非照猫画虎。

- **操作规则（元认知）**
  - 每日/每周固定复盘模板：指数结构 → 板块强弱 → 持仓股级别是否仍健康 → 次日仅执行**已分类**预案。

  - 理论是地图，**账户曲线**是反馈；地图与实地不一致时，改的是解读与执行，不是硬套名词。

## 附录 B：定理/公式汇总

### B.1 形态学（K 线→线段）

| 名称 | 内容提要 |
|------|----------|
| 包含处理 | 相邻 K 高低点包含则合并；方向随前两 K 趋势向上/向下合并 |
| 分型 | 经包含后三 K；顶中间最高、底中间最低 |
| 笔（旧/新） | 顶底分型 + 中间至少一 K；新笔中间可与分型元素包含，顶底间至少三 K |
| 线段 | ≥3 笔；特征序列分型确认结束；两种破坏（有/无缺口） |
| 顶底分型定理（书中表述） | 任意级别走势的顶（底），在顶（底）分型出现前不成立 |
| 跳空与线段 | 逆原线段方向跳空可成独立线段；顺向并入原线段 |

### B.2 中枢与走势类型

| 名称 | 内容提要 |
|------|----------|
| 最小中枢 | 三连续完成线段，区间 \[max(低), min(高)\] |
| 中枢延续/破坏 | 离开后被同级别拉回 / 拉不回 |
| 扩张与扩展（本书定义） | 九段震荡升级 / 破坏后大级别返回形成新中枢 |
| 盘整与趋势 | 单中枢 / 多中枢且不重叠 |
| 走势必完美 | 完成则至少三段次级别；必有中枢；结束后只转两类之一 |
| 连接段级别 | 相邻中枢之间连接走势级别低于中枢级别（极端可为缺口） |

### B.3 动力学（背驰与买卖点）

| 名称 | 内容提要 |
|------|----------|
| 背驰 | 同级别两段力度比较；中间常有中枢或反向走势间隔 |
| 盘整背驰 | a+A+b 中比较 b 与进入段 a |
| 趋势背驰 | 趋势中最后一背驰段 |
| MACD 辅助 | 黄白线位置、红绿柱面积/高度；回抽零轴后柱堆对比更常用 |
| 均线辅助 | 均线缠绕面积作力度近似 |
| 区间套 | 大级别背驰段内逐级缩小级别找精确定位 |
| 三类买卖点 | 一：背驰完成端点；二：其后次级别第二段终；三：次级别离开后回抽不入中枢 |
| 推导关系（书中） | 第三类买点 = 中枢后新同级别走势的第二类买点 |

### B.4 立体面（基本面/比价）

| 名称 | 内容提要 |
|------|----------|
| 巴菲特指数 | 股市总市值 / GDP；作长期估值区间参考 |
| M1/M2 | 剪刀差与资金活性；宏观风险偏好背景 |
| 基钦周期（约 40 月） | 短库存周期；与板块轮动经验顺序结合使用 |
| 产业链分层 | 能源→材料/工业→消费 + 金融/TMT/物流等基础服务 |

### B.5 易混名相提醒

| 易混点 | 辨析 |
|--------|------|
| 指标背离 vs 背驰 | 背离常领先或误导；须走势段完成度与级别一致 |
| 扩张 vs 扩展 | 本书对九段升级与“大级别返回”作了用语整理，读他书时需对照定义 |
| 二买 vs 中枢内低 | 二买是“一买后新走势的第二段次级别完成”，非任意中枢内最低点 |
| 笔 vs 线段 vs 走势类型 | 笔/线段偏几何工具；走势类型含“完成”与背驰 |
