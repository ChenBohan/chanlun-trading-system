## 一、入门与进阶路径（五层次与简化训练）

### 1.1 五层次（尘埃非尘埃）

- **层次**：初学 → 晋级 → 胜任 → 大师 → 仙家；**第三到第四层**质变最难，易长期卡壳。
- **心法**：买卖是你的事，涨跌是市场的事；**唯一分解** = 固定视角（同级别分解一贯到底）。
- **辅读取向**（编者）：心性可参 **《坛经》《论语》讲解** 与 108 课正文；技术之前先承认 **「股票皆废纸」** 的轻装感，减少成本与盈亏对信号的绑架。

### 1.2 简化训练（先活下来）

| 阶段 | 做什么 | 忌什么 |
|------|--------|--------|
| **起步** | 先只练 **买点**；固定周期（如 5F/30F）；只看 **向下段结束**；卖点先 **固定规则**（保本～固定百分比） | 预测、瞎操心、被成本/浮盈亏牵走 |
| **晋级门槛** | 买点约 **99% 正确**且持续 **≥3 个月**，再依次：换股频率 → 换周期 → 加卖点 → 三周期 + 仓位 | 未达标就加复杂度 |
| **操作本质（编者归纳）** | 某级别 **一笔** 的低买高卖；起止靠 **背驰** 与 **区间套** | 「一根筋」偏多、歧视绿线；要 **红绿平衡**、**双脚节奏** |

### 1.3 资金与态度（与主框架衔接）

- 资金视为 **无期限**；额度以 **「亏完能睡着」** 为上限；抛弃 **上帝式预测** 与机械 **止盈止损执念**；依据在 **图上的程序**，不在「心」。
- **蚂蟥比喻**：核心仓 ≥ **2/3 筹码** 才像吸盘；大走势未完 **核心仓不丢**；短差注意 **筹码比例与节奏**（与级别配合）。

### 1.4 编者「三级操作」叙事（历史语境，非模板）

- 卷一提及：**ZR（周日）** 抓大波段、**30F 抽血**、**15F+ 下 5F/1F 抢肉**——权当 **2006–2009 市场与工具条件下** 的编者个人节奏描述；今人执行须 **自建级别与资金管理**，勿照搬周期标签。
- **股指期货/沪深300 无风险套利** 等论述有时效性，作 **文献** 读即可。

## 二、当下与级别（战略战术）

### 2.1 当下必有级别

- **当下与级别不可分**：从年→季→月→周→日，再叠 **政策/消息**；忌沉迷 1F/5F 却 **长期跑输大盘**。
- **战略/战术**：大级别定战略，小级别定战术；战术上编者个案偏好 **全仓** 或 **≥2/3 + 短差**，**不倡**大仓纯短线（个人风格，执行时仍须匹配自己的资金与波动承受）。

### 2.2 「预测」在辅导书中的位置

- 编者表述：**当下与预测一体**——指须有 **预后**（生存与持续盈利的分类），非随意猜点位。
- **三筛子**：基本面、消息面、技术面；纯几何忽视 **基本面最大分力** 易成「书虫」。
- **底牌意识**：上游存在明或暗 **底牌**；背驰后未必立刻反转——**历史分力 ≠ 单独决定当下**，**合力**续写走势。

### 2.3 学习关键句（辅导强调）

- **没有级别就没有方向**；大级别向上时小波动宜 **持股**，技术不足忌乱短差 **丢筹**。
- **背驰反复** 常与 **区间套** 不准有关；围绕 **中枢** 的两段比力度。
- **线段破坏**：线段 **仅被线段破坏**；下跌结束常看 **下–上–下** 等结构，第二上 **不新高** + 背驰等信号。
- **震荡结束**：某级 **第三类买卖点**；**Zn**（段中轴）相对中枢 **Z** 判强弱与诱多诱空。

## 三、中枢震荡（辅导归纳与监视思路）

### 3.1 各级震荡段型备忘（原文归纳，实操须递归验证）

| 级别 | 常见段数 / 构成 | 强势 / 弱势段型（符号同原书） |
|------|-----------------|--------------------------------|
| **1F** | 常 5 或 7 段；前三段成 1F 中枢 | 强势近似 **a+A+b+B+c**，弱势 **a+A+b**（A、B 为类中枢） |
| **5F** | 或由 1F 扩展，或三段 1F 重叠成 5F 中枢 | 后一种段型多为 **a+A+b** |
| **30F** | 常 5 或 7 段，9 段可扩展向日中枢 | 内部强势 **a′+A′+b′**，弱势 **a+A+b** |
| **日线** | 可视为上述组合 | 实操常从 1F 向高级别递推 |

### 3.2 Zn 与 Z 的震荡操作提示

- **Zn 在 Z 下** 或 **中枢下沿之下** → 介入风险偏大（弱势语境）。
- **Zn 缓升却无力突破中枢** → 警惕 **上升楔形类诱多**（反向同理看诱空）。
- **末段若为趋势类型** 且 Zn 配合异常 → 警惕 **变盘**。
- 段内常结合 **次级别中枢的第三类买卖点** 定方向；不熟时 **至少用 ≥5F** 做本级震荡，级别越小要求越高。

### 3.3 与课 91–93、99 的衔接（见土匪/解析框架）

- **中枢震荡监视器**：中枢内高低点连线 + **BOLL** 辅助强弱；**中阴** 一律按 **中枢震荡** 处理。
- **表里面 (1,1)/(1,0)** 等：保守型可在足够周期 **(1,1)→(1,0)** 先兑现成本留利润；后段力度弱则 **区间套** 逃顶（细节与 `土匪注解版操作框架` 第二节互参）。

### 3.4 利润率与震荡（卷二摘录）

- 打开图先找操作级别 **最近一个中枢**；中枢内 **尽量不操作**；**围绕本级中枢震荡做差价** 相对安全；**中枢上移段** 宜满仓吃主升、少乱做差价；出现 **第三类卖点** 则停止回补。
- 比较两段力度时，若 1 分钟 MACD 乱而 30 分钟清晰 → **用大级别 MACD**。

## 四、背驰区间套与节奏（辅导摘录）

### 4.1 级别锚点

- 即使做 1F，也要懂 **大级别区间套锚点**，否则易在「该反转处」反向进出。

### 4.2 背驰段假设法

- 走势未完时 **先假设进入背驰段**；走出后若力度大于前段则 **背驰段不成立**。未否定前，在背驰段内用 **MACD** 等看次级别背驰，**逐级缩窄**。

### 4.3 常见踏错

| 情况 | 辅导提醒 |
|------|----------|
| 顶背驰区间套 **上错买** | 如 1F 三买后新高却背驰 → 须快撤 |
| 底背驰 **未套准** | 易短涨再跌、心态坏而踏空 |
| 连续踏错节奏 | 可等 **二买、三买**；编者激语「连错三次…」意在 **自警纪律与级别**，非操作口诀 |

### 4.4 节奏总纲（与主框架一致处从简）

- **买点买、卖点卖**；**节奏重于精度**；**宁卖早勿买错**；不追涨、不杀跌。
- 买前自问（可打印放电脑旁）：**级别 + 买点类型**、大盘、板块、各级 **中枢分布**（课 41 精神，辅导强调执行）。

### 4.5 「无趋势无背驰」与多级别（辅导卷一）

- 先分 **趋势/盘整**，再谈背驰；**盘整背驰** 后路径含 **三买** 等，勿线性外推为大跌。
- **趋势背驰** 至少回 **B 段**（类最小跌幅预期）；**日线强势中段** 时 5 分背驰可能仅短差；**日线末端** 小级别背驰可剧烈——**忌单级别见背驰就外推**。

## 五、解盘与均线—中枢经验（历史语境）

### 5.1 指数与个股节奏

- **深成指** 常较上证 **更敏感**；调整期重 **个股轮动**，可用 **成分指数** 把握节奏。
- **回帖提示（历史）**：深成与沪指 **背离** → 警惕盘中震荡与 **调整级别** 差异（**震荡 ≠ 调整**）；调整中关注 **逆市不跌** 品种作下一轮候选（勿当现行指数规则）。

### 5.2 均线与中枢的「经验对应」（须验证）

- **5 日线**：短线关键；**1 分中枢** 常依托 5 日线；**5 分中枢** 多破 5 日测 **10 日线**。
- **30 分/日线笔中枢**：常破 **34 日** 测 **55 日**，**89 日线** 作强支撑/压力参考。
- **注意**：具体均线与中枢前 **次级别段数** 有关，段多则均线感受会「后移」——属 **经验法则**，不能替代 ZG/ZD。

### 5.3 解盘技巧摘录

- **双次拉回 0 轴**（MACD）：第二次常对应再跌，可联想下跌第一个中枢与 **最小级别第三类卖** 结构。
- **三角形**：多见于一段走势 **末段调整**，其后多警惕。
- **震荡市**：**卖点先走**，买点看准进。

### 5.4 吻与节奏（均线阶段表述）

- **飞吻** 续趋势；**唇吻** 警惕；**湿吻** 后常转折；**男上位** 长期后湿吻，其后 **空头陷阱** 概率大——但 **趋势第一次湿吻** 不适用此条。
- **节奏口诀（辅导）**：**买尽量第二类、卖尽量第一类**（与精细化卖点程序并存，执行时以本级别完成度为准）。

## 七、节奏篇与「进入买点」条件

### 7.0 边界、自动化与「战略计划」（辅导语境）

- **完全分类的边界** = 战略进出计划；低级走势用 **区间套** 修正战术。
- 编者设想：日常如 **巡航监控**，剧烈段 **人工起降**——对应到个人执行，即 **程序先行、当下微调**，而非临场叙事。

### 7.1 多条件同时满足更稳（非唯一标准）

- **政策面** 支持；股价 **上升通道、均线多头**；长线 **月 K 底分型 + 有效站上 5 月线**，中线 **周 K 同理**，短线 **日 K 同理**；理想为操作级别 **第一、二、三类买点**。
- 卖点侧对称：政策不支持、空头排列、分型跌破对应周期均线、**第一二类卖** 理想，最迟 **第三类卖**。

### 7.2 选股范式（课 7 笔记）

- **放量突破上市首日高**（新股线索）；**放量突破年线 + 缩量回踩**，**年线走平拐头**；**趋势明确** 再进出，不抄「天下底」。

### 7.3 作业与形态备忘（辅导摘录）

- **三角形**：看形态，第五波末可与 **二买** 等共振；三角形段 **不看均线**（与均线吻体系分工）。
- **MACD 定律（阶段归纳）**：**一买** 多在 **0 轴下背驰**；**二买** 多在 **首次上 0 轴后回抽确认**；卖点对称。
- **同一图形多级别**：日线上可能是盘整，30 分钟上可能是 **下跌+盘整+下跌**——先框 **级别** 再谈买卖点。
- **背驰力度层级（复习帖归纳）**：**趋势背驰 > 盘整背驰 > 段内背驰**；定位仍靠 **区间套**。

## 八、108 课笔记纲要（辅导侧）

以下取 **辅导书归纳+编者注解**，细节仍以 108 原文为准。

| 课次 | 辅导抓取的操作/认知点 |
|------|-------------------------|
| 1–2 | 市场无慈善家；**只有赢家输家**，「围猎」看 **武器级别** |
| 3 | **喜好 = 死亡陷阱**；空头/多头陷阱助买卖 |
| 4 | **理性是干出来的**；模式如何当下与死去 |
| 6–7（历史） | 权证看 **行权价/比例/期限**；散户要有 **根**——年线范式 + 放量回踩 |
| 8–10 | **只搞能搞的**；**严格资金管理**，信号不对 **立刻走**；**众恶众好必察**，机失则不能搞 |
| 11–13 | 多周期 **吻** 分类；**缠绕** 与量；**主动防护** = 程序失效就走；一买后若再 **男上位缠绕** → 常说明「最后一吻」错，**离场** 等二买体系 |
| 14 | **大级别二买** = 次级别 **一买**；短差：**次级别一卖减、一买回补** |
| 15–16 | **没有趋势没有背驰**（趋势语境）；中小资金：**下跌+盘整+下跌** 一买介入；**一买后见盘整立即撤** |
| 17–20 | 未形成中枢 = 走势未完成；**三买三卖** 与 ZG/ZD；**级别延续/扩张** 与两中枢波动重叠 |
| 21 | 二买可在中枢上/中/下；**二买与三买重合** 实务常对应大级别上涨（仍防扩张） |
| 24–25 | 背驰—买卖点定理；**MACD 面积×2 预估**；盘整背驰 vs 趋势背驰路径 |
| 27 | 首中枢内背驰多 **盘整背驰**；**大转折** 用多级背驰段 **区间套** 锁定 |
| 31–34 | **资金管理** 优先；**当下结构 + 区间套**；多义性通过 **限制延伸段数**（如超 5 段则升级理解）减歧义；与走势对抗 → **离开** |
| 35–36 | 级别过小长期可能 **无意义**（成本/滑点）；震荡级别可低于中枢级别甚至 **缺口**；**5F 次级别未必是 1F**，可以是例如 3F——重 **递归与中枢** 非时钟 |
| 37–40 | **同级别分解** 练成韵律；乱步则 **停手**；**多重赋格** = 路况换档；盘整中勿死等高/低点，须 **多级别综合** |
| 41–44 | 小级别与大级别反向 = **刀口舔血**；**背驰级别与走势级别** 关系；**小转大** 无充分条件，看 **c 内部次级别中枢** |
| 45–48 | **等待** 根本；单日三类中枢分类；跌破 5 日线后是否拉回由市场选；震荡 **对称性** + 分笔背驰警惕 **小转大** |
| 49–50 | 本级中枢内不操作；**向下离开力度背驰** 回补点；三买与背驰回补的优先级（见第三节） |
| 55–57 | 脱离底部第一次拉升多 **前戏**；**卖点在涨中出现**；赚钱 **卖早不卖晚** |
| 79–84 | 分型与 **小级别一二类** 相关；**级别与时间无必然绑定**；顶分型 + **5 周期均线** 辅助 |
| 85–90 | 拒绝公式思维；**1F 熟练为学习提速**，实战勿被 1F 锁死；**BOLL 收口** 与中阴尾声 |
| 91–93、99 | 笔定理与 **(1,1)/(1,0)**；监视器 + BOLL；中阴 = 震荡 |
| 94–100 | 机会在 **完全分类边界**；反对虚拟目标赌徒心；选股略强于大盘而非硬逆势 |
| 101–103 | 分型笔线段为 **a0**；**级别即中枢级别**；**MACD 在 0 轴下** = 空头主导（防狼术） |
| 106–108 | 板块强弱指标；30 分反弹 **绝对性**（至少一个 30 分中枢）→ 可按 **5 分节奏** 分解；走势 **底—连接—顶**，只参与适合自己级别的 **连接段** |
