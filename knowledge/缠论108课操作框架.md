## 一、核心理论体系

缠论的分析体系是一个严格的递归结构，从最小单位逐级构建：

```
K线 → 分型 → 笔 → 线段 → 中枢 → 走势类型
```

### 1.1 分型

- **顶分型**：三根K线中，中间那根的高点最高、低点也最高
- **底分型**：三根K线中，中间那根的低点最低、高点也最低
- **包含关系处理**：两根K线存在包含关系时，需先合并为一根（向上取高高低高，向下取低低高低），再判断分型
- **分型的意义**：分型是笔的转折点，顶分型结束向上笔，底分型结束向下笔

### 1.2 笔

- **定义**：连接相邻顶分型和底分型的线段（顶→底为向下笔，底→顶为向上笔）
- **构成条件**：顶分型与底分型之间至少有一根独立K线（不含分型共用K线）
- **笔的方向**：向上笔（底分型→顶分型）和向下笔（顶分型→底分型）交替出现

### 1.3 线段

- **定义**：至少由三笔构成，且前三笔必须有价格重叠
- **特征序列**：向上线段看向下笔构成的顶分型；向下线段看向上笔构成的底分型
- **线段结束的两种情形**：
  - **第一种**：特征序列顶/底分型的第一、二元素间无缺口 → 在该分型处结束
  - **第二种**：有缺口 → 需后续反向序列出现对应分型才确认结束
- **线段破坏**：线段必须由线段破坏（笔破坏不一定结束线段）

### 1.4 中枢

- **定义**：至少三个连续次级别走势类型的价格重叠区间
- **区间计算**：ZD（中枢下沿）= max(各段低点), ZG（中枢上沿）= min(各段高点)
- **级别递归**：三个1分钟走势重叠 ≈ 5分钟中枢；三个5分钟走势重叠 ≈ 30分钟中枢，依此类推
- **中枢延伸**：围绕同一中枢震荡（不产生新中枢）
- **中枢扩展**：相邻中枢波动区间重叠 → 形成更大级别中枢
- **中枢新生**：第三类买/卖点后，新中枢与旧中枢不重叠 → 趋势组件

### 1.5 走势类型

| 类型 | 定义 | 中枢数量 |
|------|------|---------|
| **盘整** | 完成的走势中只含一个中枢 | 1个 |
| **上涨趋势** | 至少两个同向、依次出现且不重叠的中枢，方向向上 | ≥2个 |
| **下跌趋势** | 至少两个同向、依次出现且不重叠的中枢，方向向下 | ≥2个 |

### 1.6 核心定理

- **走势终完美**：任何级别的走势类型终将完成，完成后变为其他类型
- **分解定理一**：任何走势 = 同级别的盘整/上涨/下跌的连接
- **分解定理二**：任何走势类型至少由三段以上次级别走势构成
- **背驰-买卖点定理**：背驰必制造某级别买卖点；某级别买卖点必来自某级别背驰

## 二、三类买卖点

缠论证明：市场上**只有**三类买卖点，它们构成了操作的完备系统。

### 2.1 第一类买卖点

| | 一买 | 一卖 |
|---|------|------|
| **位置** | 下跌趋势背驰处（最后一段下跌力度弱于前段） | 上涨趋势背驰处（最后一段上涨力度弱于前段） |
| **MACD** | 绿柱面积缩小，黄白线在0轴下背驰 | 红柱面积缩小，黄白线在0轴上背驰 |
| **性质** | 趋势转折的第一个信号，风险最高但利润空间最大 | 趋势结束的第一个信号 |
| **操作** | 适合激进型、技术好的投资者 | 必须果断执行，不可犹豫 |

### 2.2 第二类买卖点

| | 二买 | 二卖 |
|---|------|------|
| **位置** | 一买后第一次次级别回调的低点 | 一卖后第一次次级别反弹的高点 |
| **MACD** | 黄白线首次上0轴后回抽确认 | 黄白线首次下0轴后回抽确认 |
| **性质** | 安全性高于一买，保证后面至少还有一段次级别上涨 | 确认下跌趋势 |
| **操作** | 适合稳健型投资者，初学者首选 | 未在一卖走的补救机会 |

### 2.3 第三类买卖点

| | 三买 | 三卖 |
|---|------|------|
| **位置** | 次级别向上离开中枢后，次级别回试低点不破ZG（中枢上沿） | 次级别向下离开中枢后，次级别回抽高点不破ZD（中枢下沿） |
| **性质** | 中枢破坏确认，后续至少形成新中枢 | 中枢破坏确认，趋势延续或扩展 |
| **操作** | 利润率最大模式的核心买点 | 必须执行，不出则等更大级别一买 |

### 2.4 买卖点关系

- **完备性**：三类买卖点覆盖所有可操作位置
- **二买与三买可重合**：一买后凌厉突破前下跌最后中枢，回抽不进该中枢 → 二、三买合一（常对应大行情）
- **级别关系**：大级别二买 = 次级别一买
- **三种二买强弱**：二买与三买合一最强 > 二买高于一买 > 二买低于一买（但不破一买低点）

## 三、背驰与 MACD 辅助

### 3.1 趋势背驰

- **前提**：走势结构为 a + A + b + B + c（A、B为同级别中枢，c为最后一段趋势）
- **判断**：c 段力度弱于 a 段（MACD柱子面积 c < a）
- **标准形态**：B 中枢常把 MACD 黄白线拉回0轴附近，c 段再发力时面积/高度不及 a 段
- **快速判断**：柱子伸长变缓时，可按已出面积×2预估，不必等走完

### 3.2 盘整背驰

- **场景**：中枢震荡中，离开中枢的力度比较
- **用法**：围绕同一中枢的前后两次离开段力度对比
- **预期**：回拉幅度弱于趋势背驰（不一定大幅离开中枢）

### 3.3 MACD 实用定律

| 买卖点 | MACD 典型表现 |
|--------|--------------|
| 一买 | 0轴下绿柱面积背驰（后段面积 < 前段） |
| 二买 | 黄白线首次上0轴后回抽0轴确认不破 |
| 三买 | 回抽不破中枢上沿，MACD 黄白线在0轴附近或上方 |
| 一卖 | 0轴上红柱面积背驰 |
| 二卖 | 黄白线首次下0轴后回抽0轴确认不破 |
| 三卖 | 回抽不破中枢下沿 |

### 3.4 多级别联立

- 日线上涨初中段，5分钟背驰跌幅有限
- 日线末段，1分钟背驰也可引发大跳水
- 操作前必须明确**当前处于哪个级别的哪个阶段**

## 四、区间套精确定位

### 4.1 原理

在怀疑已进入背驰段时，向内逐级用更小级别的背驰去当下确认转折点。

### 4.2 操作步骤

1. **大级别判断**：确认走势处于可能的背驰段（如30分钟级别 c 段力度开始衰减）
2. **中级别缩小**：在该段内用5分钟级别找背驰
3. **小级别定位**：在5分钟背驰段内用1分钟级别精确定位
4. **执行**：在最小级别确认的转折点执行买卖

### 4.3 关键原则

- 背驰段未走完前一律按背驰段处理，直到被否定（即走势力度超过对比段）
- 级别越小定位越精确，但信号越多、噪音越大
- 实操中1分钟级背驰往往已够用

## 五、操作系统

### 5.1 确定操作级别

| 资金量/时间 | 建议操作级别 | 看盘周期 |
|------------|-------------|---------|
| 小资金/短线 | 5分钟 | 1分钟、5分钟 |
| 中等资金 | 30分钟 | 5分钟、30分钟 |
| 大资金/中线 | 日线 | 30分钟、日线 |
| 超大资金 | 周线 | 日线、周线 |

初学者建议从30分钟级别开始，不宜过小。

### 5.2 机械化操作程式（同级别分解）

以30分钟操作级别为例：

```
1. 等待30分钟下跌趋势出现背驰（一买）→ 买入
2. 30分钟向上第一段结束（一卖信号或次级别顶背驰）→ 卖出
3. 回调不破前低 / 出现盘整背驰 → 二买回补
4. 第三段上涨：
   - 创新高且无背驰 → 持有
   - 不创新高 / 背驰 → 卖出
   - 出现第三类买点 → 加仓持有
5. 新中枢形成 → 围绕中枢做震荡降成本
6. 中枢上移后出现背驰 → 清仓
```

**向下段对称执行**：卖点卖、买点买。

### 5.3 利润最大模式

- **第一定理（固定品种）**：参与上涨+盘整，盘整用震荡降成本，三买后持股至新中枢再震荡，向上移动背驰清仓
- **第二定理（换股模式）**：仅在三买介入，新中枢形成即换股 → 单位时间利润率最高，但依赖机会密度
- **中枢上移段应满仓**，不参与短差（区别于震荡段）

### 5.4 中小资金高效法

1. 只参与 **「下跌+上涨」** 形态
2. 最佳介入：**「下跌+盘整+下跌」** 中第二段下跌的一买
3. 一旦出现盘整，按程序退出（用次级别一卖保证不亏）
4. 卖点对称：**「上涨+盘整+上涨」** 后第二段涨的一卖走人

### 5.5 中枢震荡操作

- **先卖后买**：底仓拿好，遇震荡先高位减、低位回补
- **向上离开段找卖点**，向下背驰/盘整背驰回补
- **临近三卖风险时停止回补**，等三卖后等一买再介入
- **Zn 监视器**：各次震荡区间中点相对中枢中轴的强弱，辅助判断变盘方向

### 5.6 短线反弹操作

- 反弹至少包含一个该级别中枢（三段次级别构成）
- 从第一「上」起按次级别分段操作
- 不预测反弹/反转，只跟结构
- 出现三买且非背驰强攻可持有；否则按次级别震荡兑现

### 5.7 均线辅助（懒人法）

| 操作周期 | 关注均线 | 用法 |
|---------|---------|------|
| 短线 | 5日线 / 60分钟5均线 | 不破不出 |
| 中线 | 5周线 | 跌破考虑减仓 |
| 长线 | 5月线 | 趋势定性 |

**防狼术**：MACD黄白线在0轴下 → 空头主导，回避或等重新上0轴。

## 六、资金管理

### 6.1 基本原则

- **资金必须长期无压力**：禁用借贷资金、限期资金
- **先做到成本→0**：通过波段操作逐步把持仓成本降到零甚至负数
- **成本为0后**：目标变为攒股数，大级别卖点一次性兑现

### 6.2 建仓策略

- 下跌中可分批买入，**绝不越涨越加**
- 准备充分则一次性买足，之后除非逻辑破坏不轻易丢筹码
- 机动仓做短差降成本，不增加总股数

### 6.3 短差程序

- 大级别买点介入后，**次级别一卖减仓，次级别一买回补**
- 保持底仓不动，只用机动仓操作

### 6.4 仓位配置

| 走势阶段 | 仓位建议 |
|---------|---------|
| 一买确认 | 轻仓试探（1/3） |
| 二买确认 | 加至标准仓位（2/3） |
| 三买确认 | 满仓 |
| 中枢上移段 | 满仓持有，不做短差 |
| 中枢震荡段 | 标准仓位，机动仓做短差 |
| 一卖信号 | 减至1/3或清仓 |
| 三卖确认 | 必须清仓 |

## 七、风险控制

### 7.1 核心风险观

- **唯一实质风险**：投入的钱不能在以后换回更多
- **零成本即无风险**：做到0成本后，无论涨跌都立于不败

### 7.2 止损规则

- **一买后**：若再出现同级别下跌缠绕（判断错误），先退出
- **二买后**：若跌破一买低点，反弹清仓
- **三买后**：若跌破中枢上沿（ZG），说明三买失败，减仓或清仓

### 7.3 级别保护

- 操作级别内的次级别波动是可接受的噪音
- 超过操作级别的反向走势必须按规则处理
- 不因小级别波动打乱大级别操作节奏

### 7.4 中阴阶段处理

- 前走势类型背驰「死亡」后到新走势类型确立前的模糊段
- 技术好：按大中枢震荡做差价
- 技术一般：等市场选择方向，不急于操作
- 警惕中阴阶段的多空齐杀

## 八、心理纪律

### 8.1 操作纪律

- **买点买、卖点卖**：只在理论确认的位置操作
- **宁卖早勿卖晚**：一卖信号必须果断执行
- **不追涨杀跌**：错过买点等下一个，不追高
- **级别纪律**：操作级别与看盘级别分开，不因小级别波动影响大级别判断

### 8.2 心理误区

| 误区 | 表现 | 纠正 |
|------|------|------|
| 一根筋 | 企图找永恒公式，级别混乱 | 接受多义性，严守级别 |
| 赌徒心理 | 怕踏空、砍了追追了砍 | 等买点，机械执行 |
| 预测癖 | 预测代替观察 | 当下性，只看走势不猜未来 |
| 贪嗔 | 该走不走，把股票当宝 | 买卖点面前无感情 |
| 聪明误事 | 过度分析争论 | 简化为机械操作程式 |

### 8.3 当下性原则

- 分型、笔、线段等只有K线走出来才能唯一确认
- 当下分析与事后分析规则相同
- 完全分类 + 边界条件 → 让市场自己选择触发哪一段
- **不测而测**：分段函数思维，不预测具体走哪段，只对每段有预案

### 8.4 学习路径

```
1. 学习分型 → 笔 → 线段 → 最小中枢 → 各级中枢与走势类型
2. 先看静态历史图，练习划分
3. 模拟盘练习当下判断
4. 小资金实盘，从30分钟级别开始
5. 反省每日心理与操作
6. 逐步缩小级别、增大资金
```

## 附录：快速参考表

### A. 走势结构递归

```
最小级别（约分笔）
  └─ 三个重叠 → 最小中枢
      └─ 构成最小走势类型（盘整/趋势）
          └─ 三个重叠 → 上一级中枢
              └─ 构成上一级走势类型
                  └─ ... 逐级递推
```

### B. 买卖点决策流程

```
当前持币 → 
  ├─ 是否有操作级别的下跌趋势背驰？ → 是 → 一买（轻仓）
  ├─ 一买后第一次回调不破低？ → 是 → 二买（加仓）
  └─ 中枢上沿回试不破？ → 是 → 三买（满仓）

当前持股 →
  ├─ 是否有操作级别的上涨趋势背驰？ → 是 → 一卖（减仓）
  ├─ 一卖后第一次反弹不创新高？ → 是 → 二卖（清仓）
  └─ 中枢下沿回抽不破？ → 否（破了） → 三卖（必须清仓）
```

### C. 背驰-转折后三种可能

```
趋势背驰后：
  1) 最后一个中枢级别扩展（震荡延续）
  2) 更大级别盘整
  3) 更高级别反趋势（大反转）

操作：按走势实际发展，在对应级别的买卖点操作。
```

### D. MACD 速查

```
看趋势背驰：比较柱子面积（红柱看涨、绿柱看跌）
看盘整背驰：比较柱子面积（围绕同一中枢的前后段）
看变盘：黄白线在0轴附近的行为
看级别：日线看大级别、分钟线看小级别
```
