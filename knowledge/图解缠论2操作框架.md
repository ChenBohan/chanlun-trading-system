## 一、买卖点逻辑体系

### 1.1 第一原理：走势必完美

- 任意级别走势类型必然由**次级别至少三段已完成走势类型**连接而成；由此保证**中枢必然出现**、**背驰有可比段**、**买卖点可嵌套定位**（区间套）。
- **操作含义**：不在「预测未来」，而在「结构未完成/已完成」的当下分类；离开段、回抽段是否满足次级别完成，是判定三买、周线三买等的核心依据。

### 1.2 与均线系统衔接的入门逻辑（第一章）

- **注意**：第一章「均线操作系统」中的盘整/上涨/下跌是**图形分类**，与第二章起**严格定义的走势类型**同名不同义，切勿混用。
- **一买（均线视角）**：操作级别下跌走势中 **a+b+c**，c 与 a **背驰**；背驰可用：均线两次交叉间**面积缩小**、MACD 黄白线/绿柱**不创新低**、绿柱**面积缩小**等辅助，三者同时满足则把握大；经验上 **1+2 满足**或**单独 3** 常可认定背驰。
- **一买后分类**：后续只能是**盘整或上涨**；若先盘整，第一段次级别上涨不能突破前下跌盘整区则应**先退出**（走势已弱）。
- **二买**：一买后第一段次级别走势结束，随后**盘整或下跌**的完成点；均线表述为：下跌结束后第一次**长短均线黏合/交叉**的结束点；若第二段为下跌，则取其**次级别一买**。
- **区间套**：从大级别疑似背驰段逐级下到次级别、次次级别找**该背驰段内的一买**，缩小介入区间（日线→30 分→5 分）。

### 1.3 三类买卖点的逻辑关系（全书贯穿）

| 要点 | 操作提示 |
|------|----------|
| **一买** | 趋势/盘整背驰端点；利润大、把握难度高，可用次级别一买精确定位。 |
| **二买** | 书中强调**最易掌握**；周线二买常对应主升浪；需防盘整**级别扩大**导致「必有新高」力度不足。 |
| **三买** | 次级别**离开中枢 + 次级别回抽**不破中枢上沿（上破形态对称于下破三卖）；**非所有突破回抽都是三买**，须严格次级别结构。 |
| **三买后演化** | 要么上方形成**新同中枢**走趋势；要么**九段/两中枢震荡区间重叠**导致**级别扩展**，未必走「主升浪」。 |

### 1.4 心法：当下、不预判

- **涨了再买**：板块/个股启动后，用**第一次回升后的小级别买点**确认强度，再参与；指数至少**非单边下跌**更稳妥。
- **消息**：多用来**测试**当下走势强弱，而非当作涨跌的「原因」。

### 1.5 背驰的操作化理解（第四章提要）

- **本质**：固定流通盘下，主动卖盘/买盘力量**不可无限单边**，力度衰减表现为**背驰**；期货延伸性强、股票更易出现可比较的背驰段。
- **比较原则**：背驰是**走势段之间**的力度比较；MACD 为辅助，**黄白线在 a+b+c 中持续新高则未背驰**等细则需结合结构。
- **MACD 技巧**：多段绿柱**不连片**需比面积时，可将 MACD **参数调大一倍**便于相加对比；**a+A+b** 与 **a+b+c** 比较时是否侧重黄白线应有别。

### 1.6 第二类卖点（同级别分解常用）

- **不背驰的强涨**结束后，**第一次回调**再上的高点**不创新高或盘整背驰** → 二卖；小级别里**新高且不背驰**往往已是最佳卖点（无第一类卖点时）。

## 二、中枢理论深化

### 2.1 中枢的确立

- 下跌段结束后，新走势**至少三段次级别**；a 上、b 下、c 上完成后，若 c 与 a **背驰**回落入 a/b/c **重叠区**，则形成 **a+A**，A 为**该级别中枢**。
- d 与 b 的四种高低点组合决定中枢形态（宽、窄、平等），但**不影响「只有延续或破坏」两类演化**。

### 2.2 延续与破坏

- **延续**：围绕中枢的次级别走势**始终与中枢区间有重叠**。  
- **破坏**：次级别**离开**后，次级别**回抽不进**中枢区间 → 在另一侧形成**新中枢**；回抽低点高于原中枢上沿 → **第三类买点**（对称得三卖）。

### 2.3 第三类买卖点分辨要点

- 离开段 e、回抽段 f 各有**盘整（含奔走型）/趋势**等分类；**e+f 九种组合**中，**双横盘**易形成**三段次级别与 d 段再重叠**，属**中枢震荡延伸**，**不是**针对原中枢的三买。
- **常见真三买**：**上升盘整 + 下跌或盘整回抽**等其余八种。
- **大级别三买**：如**周线三买**须 **日线级别离开 + 日线级别返回**（每段日线须完成自身次级别三段），不能用「未完成的 30 分一段」凑合；多义性下**离开起点**的划分会改变确认节奏，选**更清晰且不滞后**的分解。
- **三买精确卖点**：在次级别或次次级别找**一类卖点**把握回抽低点。

### 2.4 扩展与扩张

- **扩展**：两个**同级别中枢的震荡区间**发生重叠 → **更大级别中枢**。  
- **扩张**：先有一个中枢，突破后**以该级别走势返回**并与原区间相关 → 级别升级，形态可与扩展统一理解。  
- 三买后若未能形成**两中枢趋势**，而出现**九段次级别**等，则可能**扩展为上一级别中枢**。

### 2.5 转折的力度与级别（承接原文第 29 课思路）

- 趋势背驰后的反弹/调整**级别与力度**决定后续是**盘整、反趋势还是扩展**；书中强调须结合**走势必完美**理解，避免「背了又背」的误判（须明确**比较段**与 **a+b+c / a+A+b** 结构差异）。

### 2.6 中阴身

- 前走势类型已结束、新走势类型**尚未确立**的阶段，多表现为**原最后中枢的震荡**。  
- **操作**：不熟则**不参与**；若参与震荡，严格模式是**次级别二买**介入，避免「疑似背驰」陷阱。

## 三、机械化操作系统

### 3.1 系统定制的四个约束

| 因素 | 影响 |
|------|------|
| **资金量** | 标的流通盘、长中短超短选择；大资金宜大级别+短差降本。 |
| **性格** | 快与稳、一买与三买偏好；系统须自洽。 |
| **习惯** | 蓝筹/小盘、估值偏好等。 |
| **看盘时间** | 无全职看盘勿做 5 分钟级投机，宜日线/周线。 |

### 3.2 掌握程度的自检

- **核心**：能否真正理解**走势必完美**；否则级别、中枢、三类买卖点、同级别分解、小转大均不稳固。  
- **建议路径**：勿一次通读到底；从**最简单可执行**系统开始，**熟练一项再加一项**；**只看定义画图**，少依赖他人代划分。

### 3.3 最简单操作系统（第 16 课思路 + 本书细化）

- 寻找操作级别 **下跌 + 盘整 + 下跌**；5/10 均线有明确交叉，**后一段下跌创新低**。  
- 等一买后反弹结束；若随后**横盘**，在**横盘低点**介入（第二次「下」），博弈盘整完成后的**再一段上**。  
- **选股形态清单**：①下盘下；②下盘下+反弹；③下盘下+反弹+横盘。  
- **仅需**分清下跌/盘整形态即可上手；练习可用 **5/15 分钟尾盘**，建议不低于 **30 分钟**以免空间过小。  
- **难点**：买入后**盘整延伸**升级 → 需看**第三类买卖点**；弱市易触发。

### 3.4 牛市追涨（不盲目）

- **日线主升浪**中不宜只盯日线买点；用 **1/5 分钟回调买点**介入拉升段，**a+b+c 黄白线仍新高**则未背驰可持有。  
- **窄幅盘整三买**：可借**布林收口、时间窗口**辅助；**突破当段不买**，等**回调小级别买点**，**尾盘**防假突破；若小级别上涨与前段**盘整背驰**则先退出。

### 3.5 其他系统归类

- **围绕中枢**：①中枢下背驰（一买类）；②**中枢震荡**次级别买点；③**三买**。  
- **围绕走势类型**：即**同级别分解**（见下节）。  
- **中枢震荡风险**：a+A 可随时结束，震荡中一买类可能扩展成 a+A+b；宜**次级别二买**进震荡换安全。

### 3.6 资金与进阶（作者建议）

- 小资金牛市求快：**日线/周线三买**；熊市：**中枢震荡 + 一、二买**。  
- 短线要求**一单能买满**且不影响盘口 → 市值与挂单厚度要匹配。  
- 新手：**30/15 分钟下盘下 + 二买**练数月 → 再攻**日线三买**（多为 30 分下跌 + 5 分下盘下结构）。熟练后再升到**日线下盘下、周线三买、月二买**等。

### 3.7 降成本与零成本（扩展阅读）

- 大级别底部后通过**多级别资金分区**、部分仓位做差价，目标**零成本持仓**；仅适合**标的基本面长期无雷**且技术极熟者。  
- **短差主战场**：**中枢震荡**；小级别第一个中枢后**非背驰拉升**不宜乱卖；**T+1** 下可将日内资金**拆份**滚动。

## 四、板块轮动方法

### 4.1 大势与行情性质

- 板块选择须 **大势 + 基本面 + 技术面**；单边下跌**无板块选股意义**。  
- **震荡市**常见：涨时短、幅度小、日线常盘整而 30 分可走趋势、**量能不足** → 少数板块涨；操作宜**换股+短线+30 分节奏+盘整背驰**，资金**集中主线**。

### 4.2 均线「板块强弱指标」（第五章）

- 适用 **牛市初期**；牛市中后期多数股在年线上时**失效**，可改用周线/月线或换方法。  
- 思路：按股价相对 **5/10/20/30/60/120/250** 均线分 **8 档强弱系数**，板块内加权平均得**板块指标**，排序观轮动。  
- 震荡市、熊市该均线指标**基本无效**。

### 4.3 买卖点次序轮动（第六章核心）

- **普适方法**：在各级别 **一、二、三买出现先后**上观察板块与个股**涨速差异**（时间差即轮动）。  
- **牛市节奏**：常先**成分股/金融**抬指数，打开空间；指数与成分股**约八成**同向。  
- **梯队模型**：周线牛市下，**一买先后 → 二买先后 → 三买先后**，对应板块主升浪先后；**最先完成三买的板块/个股**往往先拉主升。  
- **行业板块**：看**龙头**（如地产看保利、万科等）在**周线/日线**上处于一买后哪一段，用走势必完美**映射**板块阶段。  
- **主板 / 中小板 / 创业板**常**交替**；复盘历史阶段可总结，但**不可机械套用**。  
- **熊市/震荡**：分别侧重 **下跌背驰段先后、中枢完成先后、震荡次级别完成先后、三买突破先后**。

### 4.4 复盘与训练

- **每日/每周**：细分板块按**市盈率**排序，再板块内个股逐一翻图（作者经验约 **4～5 小时/日**，熟练后可缩至周末）。  
- **媒体大热板块**往往一段尾声，宜警惕。

## 五、速查表

### 5.1 结构速查

| 概念 | 一句话 |
|------|--------|
| 走势必完美 | 次级别三段连完，本级走势才可结束或延伸；中枢与区间套皆源于此。 |
| 中枢 | 某级别至少三段**次级别走势**的重叠区间；之后只有**震荡延续**或**三买/三卖破坏**。 |
| 三买 | 次级别上破后次级别回抽**不破**中枢上沿；假突破多，须严格次级别。 |
| 扩展 | 两同中枢区间重叠 → 高级别中枢。 |
| 中阴身 | 新旧走势未定型，宜观望或严格次级别二买。 |
| 多义性 | 同一走势多种合法分解，选**当下最清晰**的一种指导操作，非随意。 |

### 5.2 操作速查

| 场景 | 建议 |
|------|------|
| 入门练手 | 30 分钟**第二买点**为主，找不到就空仓。 |
| 最小系统 | **下盘下** + 反弹后横盘低点；均线辅助定级别。 |
| 买/卖原则 | 买：**介入后必有一段上**（系统内确定）；卖：**看不懂演化就退出**；买谨慎、卖积极。 |
| 追涨 | 大级别在涨，**小级别回调买点**参与。 |
| 震荡市 | 少预测，跟**30 分节奏与盘整背驰**；集中主线板块。 |
| 轮动 | 牛市早用**均线板块指标**；通用用**三买完成次序**与龙头阶段。 |
| 指标 | **K 线与走势结构为本**；MACD/均线/布林为辅助。 |
| 复权 | 大级别背驰分析**送股等用不复权**；小级别可用**前复权**连贯图形。 |
| 冲动下单 | 非买点买入则**次日高点坚决离场**，不计盈亏，避免深度失控。 |
| 小转大/小盘 | 级别嵌套不规范时优先**二买**；可提高级别或选**流通盘较大**标的。 |
| 均线级别对应 | 如 30 分图半年线 ≈ 15 分年线；30 分 10 日线 ≈ 5 分 60 日线，可做短线节奏参考。 |
| 三买后持股 | 若上涨呈**级别逐步放大**（5 分 MA5 → 30/60 分 MA5 → 沿 5 日线），可**破 5 日线**再考虑退出，用少量顶部空间换趋势延续。 |
| 压力与测试 | 历史高点、均线、趋势线附近常有**测试**与**双回抽**（两次回落、第二次量缩+盘整背驰再突破）；非固定图形买卖法则。 |

### 5.3 同级别分解操作节奏（日线涨、30 分段）

- a 上、b 下、c 上：**c 段一卖必出**；同时看 c 与 a 是否**盘整背驰**。  
- 随后 d：若盘整过久以至**两段 30 分盘整相连**，等**第三买卖点**再指望 e；若 d 为下跌，看 d 与 b 是否**盘整背驰**再回补。  
- 退出条件延续：**第 N+2 段上**与**第 N 段上**盘整背驰；或不背驰时 **N+3 跌完后的 N+4 不能新高**。
