## 一、核心概念速查

### 中枢

- **定义**：某级别走势类型中，至少三段次级别走势类型的价格重叠区间
- **中枢区间**：重叠部分的最高低点到最低高点（ZG-ZD 区间）
- **形态**：平移、收敛、扩散、顺方向斜移
- **级别**：由构成中枢的次级别走势决定（三段5分钟走势重叠 → 30分钟中枢）
- **演变**：破坏（三买三卖）、延续（中枢震荡）、扩张/扩展（级别升级）

### 走势类型

| 类型 | 定义 | 中枢数量 |
|-----|------|---------|
| **盘整** | 在某级别的走势中只包含一个该级别的中枢 | 1 |
| **趋势** | 在某级别的走势中包含两个或以上同向的中枢 | ≥2 |
| **上涨趋势** | 趋势中后一个中枢比前一个中枢高 | ≥2（上移） |
| **下跌趋势** | 趋势中后一个中枢比前一个中枢低 | ≥2（下移） |

### 背驰

- **趋势背驰**：在 a+A+b+B+c 结构中，c 段力度 < a 段力度
- **盘整背驰**：中枢前后两段走势力度比较，后段弱于前段
- **MACD 辅助判断**：
  - DIF/DEA 柱面积缩小
  - 黄白线高度降低
  - 绿/红柱长度缩短

## 二、三类买点

### 第一买点（一买）⭐

- **定义**：下跌趋势结束点（趋势背驰点）
- **条件**：a+A+b+B+c 下跌趋势中，c 段 MACD 绿柱面积 < a 段
- **确认**：背驰后次级别走势反转
- **特征**：最大利润但风险最高（V 型反转常在此）

### 第二买点（二买）

- **定义**：一买后第一次回调不创新低的位置
- **条件**：一买后上涨→回调，回调低点 > 一买低点
- **优势**：确认度高，适合稳健操作

### 第三买点（三买）⭐⭐⭐

- **定义**：次级别离开中枢后，回试不跌破中枢上沿（ZG）
- **条件**：
  1. 存在一个已确认的中枢
  2. 价格向上突破中枢
  3. 回调不跌破 ZG
- **操作规则**（入门最实用）：
  1. 找到下跌→横盘→下跌→横盘结构
  2. 确认第二次横盘后 MACD 背驰
  3. 横盘突破后回试不破 → 三买买入
- **卖出**：上涨后出现更高级别中枢，在中枢上轨附近或背驰时卖出

## 三、入门级操作方法

### 中短线买点（5/10/15/30分钟）

**形态**：下跌—横盘—下跌—横盘—下跌

**操作步骤**：
1. 打开 30/15/5 分钟图
2. 找"下跌—横盘—下跌—横盘"的标准形态
3. 两次盘整时间空间相近
4. 第二次下跌 MACD 绿柱面积 < 第一次（背驰）
5. 在 5 日线即将金叉 10 日线时买入
6. 目标：至少回到第二次盘整区间

### 中长线买点（日线/周线/月线）

**季线/月线型**：
1. 经历涨—跌循环，当前创新低
2. MACD 绿柱更短、面积更小、黄白线更高（vs 前次下跌）
3. 买入持有

**周线型**：
1. 长期下跌，MACD 黄白线长期在零轴下
2. 回升后黄白线上穿零轴且翻红
3. 随后横盘，黄白线在零轴附近浅浮
4. 再次下跌后不创新低或 MACD 背驰 → 买入

### 盘整中的操作

- 在中枢内做高抛低吸
- MACD 在零轴附近，利用盘整背驰做差价
- 盘整突破后跟随，破位后止损

## 四、进阶操作

### 同级别分解

- 选定操作级别（如30分钟），只关注该级别的上涨、盘整和中枢
- 第一段上涨后回调不破低 → 持有
- 三段重叠形成中枢后，盘整背驰买入
- 遇日线/周线三买 → 切换到更大级别操作

### 利润最大化操作模式

**大资金**：
1. 月线背驰买入大底
2. 部分资金做30分钟差价
3. 差价利润不回流，直至持仓成本为零
4. 零成本后利润再加仓

**小资金**：
1. 主攻日线/周线三买
2. 配合月线背驰标的
3. 按法则反复操作

### 机械化操作流程

```
当下走势判断：
  ├── 走势在中枢之上
  │   └── 持股，等卖点
  ├── 走势在中枢之中
  │   └── 高抛低吸做差价
  └── 走势在中枢之下
      └── 空仓，等买点

买入后操作：
  ├── 形成新中枢
  │   ├── 三买确认 → 继续持有
  │   └── 跌破中枢 → 卖出
  └── 直接背驰
      └── 一卖清仓
```

## 五、MACD 使用规范

| 场景 | 方法 | 注意 |
|-----|------|-----|
| **趋势背驰** | 比较 a 段和 c 段的 MACD 面积 | 面积 = 绿/红柱总和 |
| **盘整背驰** | 比较中枢前后两段力度 | 柱高+面积+黄白线位置 |
| **零轴** | 黄白线在零轴附近 = 盘整中 | 远离零轴 = 趋势延续 |
| **金叉/死叉** | 白线上穿/下穿黄线 | 配合价格位置判断 |
| **买点确认** | 绿柱缩至无 + 黄白线金叉 | 结合均线系统 |

## 六、风险管理

### 止损原则

- 无固定点位止损，用**买卖点系统**替代
- 一买后如不能形成中枢 → 止损
- 三买后跌破 ZG → 止损
- 二买后创新低 → 一买判断失误，止损

### 仓位管理

- 一买：轻仓试探（30%以内）
- 二买：确认后加仓至60%
- 三买：满仓或接近满仓
- 中枢内做差价：仓位灵活调整

### 选股原则

1. 选择月线/周线大级别底部形态的股票
2. 技术面优先于基本面
3. 涨势中不追高买入，等回调
4. 板块轮动：选刚启动的板块龙头
