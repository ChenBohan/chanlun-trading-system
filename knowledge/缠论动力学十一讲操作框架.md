## 一、核心学习路径

本系列的独特编排（区别于传统从笔/线段入手）：

```
买卖点（实战核心）
  ├─ 第一类买卖点 ← 动力学（背驰）   ← 本系列重点
  ├─ 第二类买卖点 ← 形态学（中枢、走势类型）
  └─ 第三类买卖点 ← 形态学
```

**关键认知**：动力学是树干，形态学是树枝。理解动力学后可推导形态，不必死记。

## 二、六种走势分类速查

| 组合 | 类型 | 买入盈亏 |
|------|------|---------|
| 下跌 → 上涨 | 空头陷阱 | ✅ 赚（买在下跌段） |
| 下跌 → 盘整 → 上涨 | 反转 | ✅ 赚（买在下跌段） |
| 下跌 → 盘整 → 下跌 | 中继 | ❌ 亏（二次下跌） |
| 上涨 → 下跌 | 多头陷阱 | ❌ 亏（买在上涨段） |
| 上涨 → 盘整 → 上涨 | 中继 | ✅ 赚（买在盘整段） |
| 上涨 → 盘整 → 下跌 | 反转 | ❌ 亏（买在盘整段） |

## 三、背驰判断——三种方法

### 3.1 K线斜率法

```
同等时间跨度内，下跌斜率越小 → 力度越弱 → 背驰
优点：最直接
缺点：模糊，主观性强，新手难判断
```

### 3.2 均线交叉面积法

```
使用双均线（如 5 日 + 10 日）：
1. A 段金叉→死叉的闭合面积 = S_A
2. B 段金叉→死叉的闭合面积 = S_B
3. S_B < S_A → 背驰
4. B 段的交叉点 = 背驰点（买点）

优点：较精确，有明确买入点
缺点：等交叉确认有滞后性
```

### 3.3 MACD柱面积法

```
1. DIF 和 DEA 在零轴之下
2. C 段绿柱面积 < A 段绿柱面积 → 背驰
3. C 段 DIF/DEA 位置高于 A 段 → 力度减弱
4. 绿柱缩短点 = 背驰买点

优点：最直观
缺点：等面积走完同样有滞后
```

## 四、精确化——解决背驰滞后性

### 4.1 方法一：切换级别

```
大级别确认背驰 → 切到小级别找买点
├─ 小级别中按原办法找转折点
├─ 距离真正低点不远
└─ 实战中最常用、最好用
```

### 4.2 方法二：趋势平均力度

```
平均力度 = 均线交叉面积 ÷ 时间（实时计算）
├─ 当前平均力度 < 上段 → 背驰即将形成
├─ 短期/长期均线距离缩短 → 底部即将形成
└─ 风险：预判性强，需要盘感和经验
```

### 4.3 MACD 提前判断

```
不等柱子走完，而是：
├─ 柱子伸长力度变慢时
├─ 或柱子开始缩短时
└─ 预估面积 < 前段 → 判断背驰形成
```

### 4.4 最佳策略（两者结合）

```
1. 用方法二筛选「将要背驰」的品种（还在低位）
2. 切到小级别（方法一）确认交叉点 → 精确入场
→ 完美解决滞后问题
```

## 五、第一类买点操作体系

### 5.1 广义一买（入门级）

```
条件：
1. 确认操作级别（如 30 分钟）
2. 等待「下跌 → 盘整 → 下跌」结构出现
3. 第二段下跌力度 < 第一段 → 背驰 → 一买
4. 辅助：MACD 绿柱面积比较

持仓管理：
├─ 下跌 → 上涨 ✅ → 持仓
└─ 下跌 → 盘整 ⚠️ → 马上减仓退出
```

### 5.2 标准一买（进阶级）

```
条件（更严格）：
1. 走势为「趋势」（两个以上同方向中枢）
2. 结构：A + [中枢A] + B + [中枢B] + C
3. C段与B段背驰 → 趋势背驰 → 标准一买

优势：
├─ 成功率更高（连续下跌，动力衰竭概率大）
└─ 涨幅可预计：必然回到前一个中枢区间（至少下沿）

三种反弹结果：
├─ ① 触及中枢下沿后下跌（最弱，也必然盈利）
├─ ② 触及后横盘
└─ ③ 触及后继续上涨（最强）
```

### 5.3 解决多次背驰问题

```
背驰必然制造某级别买卖点 → 逆转必然，但不永远

方法A：量化逆转时间，在时间结束前撤退
方法B：只做标准背驰（趋势背驰），条件更苛刻→胜率更高
```

## 六、中枢识别速查

### 6.1 中枢定义

连续**三段同级别走势类型**的**价格重叠区间** = 高一级别的中枢

### 6.2 区间计算

```
区间上沿 = min(各段高点中较低者)
区间下沿 = max(各段低点中较高者)
进入段不属于中枢区间
至少三段，超出为延伸
```

### 6.3 中枢形态

| 形态 | 重心特征 | 类比 |
|------|---------|------|
| 标准 | 平移 + 规律 | 矩形 |
| 收敛 | 平移 + 逐渐收窄 | 三角形 |
| 扩散 | 平移 + 逐渐放大 | 喇叭形 |
| 顺方向斜移 | 重心沿趋势方向倾斜 | 倾斜箱体 |
| 反方向斜移 | 重心逆趋势方向 | 楔形 |

### 6.4 中枢演化

| 类型 | 定义 | 实战含义 |
|------|------|---------|
| 延续 | 超过三段仍在区间内 | 行情在震荡，等待 |
| 破坏 | 突破后回抽不返回 | **= 第三类买点** |
| 扩展 | 三买失败回落进入中枢 | 级别升一级 |
| 扩张 | 两中枢波动区间重叠（不进入） | 级别升一级 |
| 延伸9段 | 延伸达9段 | 3个同级别中枢重叠→升级 |

## 七、第二类买卖点

```
定义：一买后反弹 → 第一次次级别下跌 → 结束段 = 二买
判断：通过次级别的第一类买卖点判定

位置决定力度：
├─ 二买在一买之下 → 最弱（可能大级别盘整）
├─ 二买在前段下跌中间 → 中等
└─ 二买在前段下跌的中枢之上 → 最强（V型反转）
```

---

## 八、第三类买卖点

```
定义：反弹形成中枢 → 次级别突破 → 回抽不回中枢内 = 三买
本质：中枢的破坏

特点：
├─ 涨幅最快（对应主升浪）
├─ 日线级别三买后通常 20%+
├─ 辨别难度大，变数大
└─ 上涨接近完成（次级别将背驰）时不介入

二买 + 三买重合 → V型反转（最凌厉的上涨）
```

## 九、综合操作策略

### 9.1 大资金/稳健型

```
1. 大周期找一买 → 持有零风险底仓
2. 1/2~1/3 资金 → 30分钟级别做二买/一买波段
3. 不断降低持仓成本
```

### 9.2 小资金/激进型

```
1. 设定操作级别
2. 只操作该级别的三买
3. 避开盘整 → 买入后要么大涨要么大跌
4. 理想情况：短时间翻倍
```

### 9.3 级别共振策略

```
三个级别同步分析：
├─ 大级别确认方向（无背驰 → 安全）
├─ 操作级别找买点
└─ 小级别精确入场

规则：
├─ 小周期与大周期相悖 → 不参与
└─ 寻求多级别共振 → 胜率最高
```

### 9.4 盘整背驰的实战用法

```
├─ 大级别向上无背驰 + 小级别盘整背驰 → 可参与超短线
└─ 大级别已将形成背驰 → 小级别盘整背驰不参与
```

## 十、买入两大风险及应对

| 风险 | 描述 | 应对 |
|------|------|------|
| **跌势未尽** | 下跌→继续下跌，抄底抄早 | 用背驰判断跌势是否结束 |
| **盘整后再跌** | 下跌→盘整→再下跌（中继） | 出现盘整即减仓退出；后续用中枢概念解决 |

## 十一、实战简化建议

1. **不必从笔线段入手**：直接用中枢分析，将明显高低点视为次级别走势
2. **中枢就是核心**：打开K线图 → 找中枢 → 判断走势类型 → 找买卖点
3. **笔线段 vs 中枢**：两者可独立存在，实战优先中枢（简便+易读）
4. **1分钟决策**：打开任何行情图，1分钟内决定买入/卖出/等待/放弃
5. **三境界目标**：不执着于技术 → 心态+资金管理 → 信手拈来

## 十二、MACD 辅助使用规范

| 场景 | 用法 |
|------|------|
| 判断背驰（基础） | 比较前后两段绿/红柱面积 |
| 精确化（进阶） | 柱子伸长变慢或开始缩短时即判断背驰 |
| 确认趋势背驰 | DIF/DEA在零轴下，C段位置高于A段 + 面积小于A段 |
| 趋势方向 | DIF/DEA 在零轴上方=多头区间；下方=空头区间 |
