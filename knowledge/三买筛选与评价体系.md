## 一、三买的本质：中枢破坏的确认

### 1.1 定义回顾

第三类买点 = **次级别向上离开中枢后，次级别回试低点不破中枢上沿（ZG）**。

这个定义看似简单，但其**本质含义**远比表面深刻：

### 1.2 背后的力学解释

中枢代表**多空力量的均衡区域**——在此区间内，买方与卖方反复博弈，筹码充分交换。当价格向上突破中枢后回抽不能跌回中枢：

- **意味着**：原来中枢内的卖方已经耗尽（筹码在中枢区间内已被吸纳完毕），即使给予回调机会，也无法将价格压回均衡区
- **力学类比**：物体脱离引力场——脱离速度足够大（离开段力度），即使有引力回拉（回抽），也无法将其拉回原来的轨道
- **本质**：供需关系发生了**不可逆转变**，卖方在该价格区间已无力量

### 1.3 与一买、二买的本质区别

| 买点 | 本质 | 风险来源 | 确定性 |
|------|------|---------|--------|
| 一买 | 趋势衰竭的**预判** | 背驰可能延续（小转大） | 最低 |
| 二买 | 转折的**确认** | 可能只是盘整而非趋势 | 中等 |
| 三买 | 力量格局的**不可逆** | 可能是假突破或趋势末端 | 最高（如果筛选得当） |

**三买的哲学本质**：不是在预测未来，而是确认一个**已经发生的结构性变化**。

## 二、真三买 vs 假三买：九种组合的分辨

### 2.1 离开段与回抽段的组合分类（图解缠论2核心）

离开段 e 与回抽段 f 各可能是：**趋势上涨、盘整（含奔走型）**。回抽段可以是**下跌、盘整**。排列组合形成九种情形：

| 离开段 e | 回抽段 f | 是否三买 | 说明 |
|---------|---------|---------|------|
| **上涨趋势** | **下跌** | ✓ 强三买 | 标准形态，力度充足 |
| **上涨趋势** | **盘整** | ✓ 强三买 | 回抽极弱，供应枯竭 |
| **上升盘整** | **下跌** | ✓ 一般三买 | 需看回抽力度 |
| **上升盘整** | **盘整** | ✓ 一般三买 | 需确认不是双横盘 |
| **横盘** | **横盘** | ⚠ **非三买** | 双横盘 = 中枢延伸 |
| **横盘** | **下跌** | ⚠ 可疑 | 离开段力度不足 |
| **奔走型** | **任意** | 需具体分析 | 看是否真正脱离引力 |

### 2.2 双横盘陷阱（最常见假三买）

**核心判断**：如果离开段和回抽段都是横盘，实际上形成了三段次级别走势与中枢内 d 段再重叠，这是**中枢震荡的延续**，**不是**对原中枢的破坏。

**量化检测**（引擎中的实现）：
- 离开段振幅 / 中枢振幅 < 0.3 → 离开段偏弱
- 回抽段振幅 / 中枢振幅 < 0.3 → 回抽段偏平
- 两者同时满足 → **双横盘，非三买**

### 2.3 匪注的警告

> 「突破追进当三买」是假三买的温床。须**回到第三类定义**严格检验：
> 1. 离开段是否达到**次级别走势类型**的完成标准
> 2. 回抽段是否也是**次级别走势类型**的完成
> 3. 回抽低点是否**严格不破ZG**

## 三、筛选三买的多维度框架

### 3.1 维度一：趋势位置（最重要的筛选条件）

**108课详解（扫地僧）的核心洞见**：

> 「尽量只介入第一个中枢的第三类买点。因为第二个中枢以后，形成大级别中枢的概率将急促加大。」

| 趋势位置 | 评分 | 逻辑 |
|---------|------|------|
| 下跌末端三买（下跌最后中枢被上破） | ★★★★★ | 转势确认，二三买合一 |
| 首个中枢三买 | ★★★★★ | 趋势刚确立，空间最大 |
| 第二中枢三买 | ★★☆ | 扩展风险加大，需配合其他条件 |
| 第三中枢及之后 | ★ | 极晚期，高概率形成更大级别中枢 |

**本质理解**：
- 第一个中枢三买 = 新趋势的**起跑枪声**，后面空间大、时间成本低
- 后续中枢三买 = 趋势的**接力**，但每多一棒，接力失败概率递增
- 类比物理：火箭一级推力最大效率最高，二三级虽仍加速但受限于已有速度与燃料消耗

### 3.2 维度二：突破力度

| 突破程度 | 评分 | 含义 |
|---------|------|------|
| 强突破（>3%超过ZG） | ★★★ | 脱离引力场速度充足 |
| 一般突破（1%-3%） | ★★ | 正常 |
| 弱突破（<0.5%） | ★ | 刚刚飘过，随时可能被拉回 |

**价格相对比例（breakout_abs）而非百分比**：用实际突破幅度 / 价格中位数来衡量，避免窄中枢导致的虚高百分比问题。

### 3.3 维度三：回抽深度

| 回抽情况 | 评分 | 含义 |
|---------|------|------|
| 浅回抽（距ZG > 50%中枢宽度） | ★★★ | 卖方极弱，惜售心态 |
| 适中回抽（10%-50%） | ★★ | 正常确认 |
| 深回抽（< 2%余量） | ★ | 险些失败，信号不坚定 |

**本质**：回抽深度反映了**剩余卖方力量**的大小。浅回抽说明在更高价格就已经没有人愿意卖出，是最强的供需确认。

### 3.4 维度四：中枢质量

| 中枢属性 | 评分 | 逻辑 |
|---------|------|------|
| 充分构建（≥7笔） | ★★★ | 筹码交换充分，突破更有效 |
| 一般（4-6笔） | ★★ | 标准 |
| 窄中枢（≤3笔） | ★ | 可能只是路过，突破含义弱 |
| 中枢内缩量蓄势 | ★★★ | 活跃交易者已换手完毕 |

**本质**：中枢是"战场"，战场越大（时间越长、笔数越多），最终的胜出方就越确定。窄中枢的"突破"可能只是正常波动。

### 3.5 维度五：MACD 与能量

| MACD状态 | 评分 | 含义 |
|---------|------|------|
| DIF > 0（零轴上方） | ★★★ | 多头主导环境 |
| DIF ≈ 0（零轴附近） | ★★ | 中性，需看方向 |
| DIF < 0（零轴下方） | ★ | 空头环境下突破，防狼术 |
| 回抽时黄白线轻触零轴 | ★★★ | 能量最强（图解缠论3） |

**图解缠论3 的洞见**：三买对应的 MACD 节奏 = 中枢对应绿—红—绿三波，离开段向上，回抽时黄白线回抽零轴附近。回抽越轻（离零轴越近且未深入），后续能量越强。

### 3.6 维度六：量能确认

| 量能表现 | 评分 | 含义 |
|---------|------|------|
| 缩量回抽（<50%突破量） | ★★★ | 回抽无人卖出，惜售极强 |
| 温和缩量（50%-70%） | ★★ | 正常 |
| 放量回抽（>150%） | ☆ | 大量筹码抛出，可能假突破 |

**本质**：突破时放量（确认意愿），回抽时缩量（确认无人卖出）——这是三买最理想的量价组合。

### 3.7 维度七：方向稳定性（churn）

如果近期中枢频繁翻转方向（上中枢→下中枢→上中枢），说明大级别处于**震荡/扩展**格局，三买的有效性大打折扣。

### 3.8 维度八：大级别环境

**图解缠论3 的核心教训**：

> 技术买点若不叠加环境，稳定性往往不足。

| 环境 | 三买价值 |
|------|---------|
| 大级别上涨中的次级别三买 | 极高——顺势 |
| 大级别盘整中的次级别三买 | 中等——可能扩展 |
| 大级别下跌中的次级别三买 | 低——逆势短差 |

## 四、三买的完全分类与后续演化

### 4.1 三买后只有三条路（盘整背驰后三条路变体）

1. **上方形成新中枢 → 趋势继续**：最理想，持有到新中枢的三卖或背驰
2. **九段次级别重叠 → 级别扩展**：形成更大级别中枢，变成大盘整
3. **假三买 → 跌回中枢**：三买失败，止损

### 4.2 三买后的持有与卖出

- **三买后持股规则**：中枢上移段**不做短差**（第一利润定理），满仓持有直到新中枢形成
- **退出条件**：
  - 次级别不新高或盘整背驰 → 先走一部分
  - 跌破中枢上沿 ZG → 三买失败，清仓
  - 新中枢后出现三卖 → 离场

### 4.3 级别越大越有效

| 级别 | 三买有效性 | 适用人群 |
|------|-----------|---------|
| 周线三买 | 最高 | 大资金、中长线 |
| 日线三买 | 高 | 中线操作 |
| 30分钟三买 | 中等 | 短中线 |
| 5分钟三买 | 低 | 日内短线 |

**扫地僧**：大级别三买须对应次级别（如日线级别的离开+日线级别的返回），每段须完成自身次级别三段。不能用「未完成的30分一段」凑合。

## 五、实战中的三买策略

### 5.1 利润最大模式的核心

**第二利润定理**（108课）：
- 仅在三买介入
- 新中枢形成即换股
- 单位时间利润率最高

这是缠论中**唯一一个不需要承受盘整等待时间**的模式。三买的价值不仅在于"涨多少"，更在于**时间效率**——进入即上涨，无需忍受中枢震荡。

### 5.2 有时间的散户策略（土匪注解版）

> 「第三类买点程序（定级别、看背驰、看上移、尽量第一个中枢后的三买）；三买最快，背驰+区间套解『滞后』困惑。」

### 5.3 入门训练路径（图解缠论2）

新手训练顺序：
1. 30/15 分钟**下盘下+二买**练数月
2. 再攻**日线三买**（多为30分钟下跌+5分钟下盘下结构）
3. 熟练后升到日线下盘下、**周线三买**、月二买

### 5.4 板块轮动中的三买（图解缠论2/3）

> 「最先完成三买的板块/个股，往往先拉主升。」

三买完成次序 = 板块轮动的**领先指标**：
- 牛市中：三买最先出现的板块 → 主线
- 震荡市中：三买突破先后 → 结构性机会

## 六、三买的本质总结

### 6.1 哲学层面

三买的本质是**确认一个不可逆的力量格局转变**：

- 不是预测（一买是预测趋势会结束）
- 不是确认（二买是确认转折已发生）
- 而是**证明**（三买证明旧均衡已被打破，新均衡在更高位置确立）

### 6.2 操作层面

三买是**效率最高的买点**：
- 后知后觉但**安全** → 止损位明确（ZG）
- 时间成本最低 → 进入即启动，不需等盘整
- 逻辑最清晰 → 失败条件明确（跌回中枢即失败）

### 6.3 筛选的核心原则

**一句话总结**：好的三买 = 第一个中枢 + 强突破 + 浅回抽 + 缩量 + 大级别环境支持。

**终极筛选器**：
1. ❌ 排除双横盘（形态清晰度）
2. ❌ 排除第三中枢及之后（趋势位置）
3. ❌ 排除DIF<0且无改善趋势（防狼术）
4. ❌ 排除大级别逆向环境（级别联立）
5. ✅ 优选首个中枢+强突破+浅回抽+缩量蓄势

## 八、区间套精确定位三买入场（5分钟分析30分钟回抽段）

### 8.1 核心思路

30分钟三买的**回抽段 f** 本身是一个**5分钟级别的下跌走势**。用区间套在5分钟级别内部寻找这个下跌走势的**结束点**（即5分钟一买），就是30分钟三买的精确入场点。

```
30分钟中枢 → 离开段e（30分钟向上一笔/一段）→ 回抽段f（30分钟向下一笔）
                                                    ↓
                                        5分钟级别展开为一个完整下跌走势
                                                    ↓
                                        在5分钟内找背驰/一买 = 精确入场
```

### 8.2 回抽段f在5分钟的六种结构（从最强到最弱）

| 排名 | 5分钟结构 | 评级 | 含义 | 入场方式 |
|------|-----------|------|------|----------|
| **1** | 一段下跌（仅3笔） | ★★★★★ | 卖方极弱，下跌动能枯竭 | 第3笔底分型确认即入 |
| **2** | 一段下跌 + 盘整背驰 | ★★★★ | 标准浅回抽，背驰清晰 | 盘整背驰点入场 |
| **3** | a+A 结构（一中枢后背驰） | ★★★ | 标准5分钟盘整下跌 | 5分钟一买（A后背驰段） |
| **4** | a+A+b+B（两中枢趋势下跌） | ★★ | 回抽较深但有结构 | 5分钟趋势背驰一买 |
| **5** | 下跌中枢不断延伸 | ★ | 卖方顽强，三买可能失败 | 需等5分钟三买确认 |
| **6** | 破中枢上沿ZG | ☆ | 三买失败，止损 | 不入场 |

### 8.3 最佳5分钟走势特征（★★★★★ 级别）

**第一名：5分钟仅一段式下跌（3笔完成）**

这是最理想的三买回抽结构：

- **形态**：5分钟级别仅走出3笔（下→上→下），第3笔不创新低或力度极弱
- **MACD**：5分钟绿柱面积极小，或黄白线始终在零轴附近不下穿（回抽不产生有效空头能量）
- **量能**：全程缩量，特别是第3笔量能萎缩至前面离开段的1/3以下
- **时间**：整个回抽段时间短（通常1-3个交易日内完成）
- **价格**：跌幅浅，距离30分钟中枢上沿ZG仍有较大余量（>50%中枢宽度）

**为什么这是最好的**：
> 5分钟下跌仅3笔完成 = 卖方在次级别（1分钟）只完成了最低限度的走势就衰竭了。
> 类比物理：回拉力只来得及轻轻拽了一下，完全不足以把走势拉回原轨道。
> 本质：**中枢内的筹码已经在离开段被完全消化**，回抽时根本没有人愿意在该价格卖出。

### 8.4 次优5分钟走势特征（★★★★ 级别）

**第二名：5分钟盘整背驰**

- **形态**：5分钟走出 a+A 结构，A中枢只有一个，且c段与a段比较力度衰减（盘整背驰）
- **关键确认**：c段的MACD绿柱面积 < a段绿柱面积（5分钟MACD）
- **特征**：A中枢位置偏高（靠近30分钟中枢上沿上方），说明回抽发生在较高价位
- **入场**：c段底分型确认时（即5分钟盘整背驰的一买）

### 8.5 区间套操作流程（实操步骤）

```
Step 1: 30分钟确认三买结构
  - 中枢已构建完成（≥3段）
  - 离开段e已完成（次级别上涨走势完成）
  - 回抽段f已启动（价格开始回落）

Step 2: 切换到5分钟级别
  - 观察f段在5分钟展开的结构
  - 标记5分钟的每一笔

Step 3: 判断5分钟下跌走势的完成度
  ├─ 走出3笔 → 检查第3笔是否有背驰迹象（MACD/力度）
  ├─ 走出一个中枢 → 等后续段背驰
  └─ 两个中枢 → 看趋势背驰，但警惕回抽过深

Step 4: 精确入场
  - 在5分钟底分型确认时入场
  - 止损设在30分钟中枢上沿ZG下方1-2%

Step 5: 失败处理
  - 若5分钟下跌走势持续走强（不背驰、不止跌），破ZG → 立即止损
  - 不抱幻想等"再拉回来"
```

### 8.6 5分钟MACD辅助判断

| 5分钟MACD状态 | 判断 | 操作 |
|---------------|------|------|
| 黄白线不下穿零轴 | 极强——空方几乎无力 | 底分型即入 |
| 黄白线轻触零轴回升 | 强——标准回抽 | 金叉确认入 |
| 黄白线深入零轴下方但绿柱递减 | 一般——有背驰 | 等MACD金叉 |
| 黄白线零轴下方绿柱持续放大 | 危险——三买可能失败 | 不入场，观望 |

### 8.7 关键原则

1. **5分钟下跌走势越简单越好**：3笔完成 > 一中枢 > 两中枢。结构越复杂说明卖方力量越强。
2. **回抽时间越短越好**：时间短说明卖方组织不起有效反攻。
3. **回抽量能越低越好**：缩量说明在当前价格无人愿卖。
4. **MACD维持零轴附近最好**：5分钟黄白线不深入零轴下方，说明多头格局未被破坏。
5. **宁等不抢**：未出现5分钟级别的底背驰/底分型确认之前，不提前入场。"三买不怕晚，怕的是假"。

### 8.8 与引擎现有实现的对接

当前 `chanlun_engine.py` 的 `find_interval_nests` 函数已实现日线→30分钟→5分钟的嵌套定位。对于三买回抽的精确入场，可在 `_find_bsp_in_range` 中增加对回抽段内5分钟结构复杂度的评估：

- 计算5分钟回抽段内的笔数 → 判断结构简单/复杂
- 检查5分钟MACD是否下穿零轴 → 判断空方力量
- 评估5分钟最后一笔相对第一笔的力度衰减比例 → 量化背驰程度
