## 一、核心概念的扫地僧解读

### 1.1 分型、笔、线段

- **形态学≠100% 把握**：严谨定义建立在「已忽略更细波动」的 K 线精度上；笔段是 A0 的数学化，目的是过滤杂音，忌生搬硬套、本末倒置。
- **大周期从宽**：月线、周线不必拘泥笔段每一根 K 的争议；抓力度与方向优先，精度留给关键转折。
- **线段端点未必是最高/最低点**：大级别可包络，小级别严格「线段被线段破坏」；古怪线段多出自中枢震荡——第一种笔破坏后未在该方向走出线段破坏。
- **分型是辅助，走势是核心**：分型与走势类型不同构，可互证不可替代；顶分型出现后是否回补，仍要看小级别中枢与三类买卖点。

> 「偷心不死难学成」——基本功在千遍看图与定义推演，不在讨巧。

### 1.2 中枢与走势类型

- **吻/均线≠中枢**：有中枢处常有吻，勿把均线系统与中枢混为一谈；均线是大众锚定的评价系统，有或然率。
- **完成 vs 延伸是实操难点**：延伸结束看是否**新生中枢**；离开+回抽三种组合辨强弱；抓牛股须懂延伸与多中枢。
- **多义性根子多在中枢**：声称「完整量化交易系统」可远离缠论本质；真正看透则当下有最贴近的一种解读。重组分解不为预测，而为**最利于揭示买卖点**。
- **一买后完全分类（第29课重心）**：扩展 / 更大盘整 / 反趋势；先看第一段次级别反弹是否回抽最后中枢，排除最弱扩展。
- **中阴**：前走势已死、新走势未定型；低于你操作级别的中阴可无视；先处理该出现的本级中枢，再跟三类买卖点。

> 「能否找到最合适组合以适应操作，与经验有关，不涉及预测。」

### 1.3 背驰

- **没有趋势，没有背驰**（此语境下）：盘整中用的叫**盘整背驰**，与趋势背驰级别差一档；须先立结构再谈 MACD。
- **趋势背驰实操大坑**：背驰段 c 须含对 B 的**三买/三卖**才算标准离开段；先判定 A、B 同级与中枢级别，再辨背驰。
- **第一个中枢处的「背驰」**：多为盘整背驰（企图脱离中枢失败）；**第二个中枢后**紧盯真背驰。
- **盘整背驰最有用在大级别**：周/月/季盘背 + MACD 常对应历史性大底；高位与低位同一段盘背，风险含义完全不同。
- **小级别背驰逆大级别**：杀伤力有限，宜做短差勿当清仓依据；**不逆势**：日线强劲时 5 分钟背驰仅短差。
- **小转大**：不可预测只能预防；必要条件见第44课（最后次级别中枢三买/三卖）；冲顶赶底常配合小转大，与加速段风险呼应。

> 「背驰段问题是实操大坑，须先立结构再辨背驰。」

### 1.4 「预测」与完全分类（不测而测）

- 真预测＝**完全分类 + 分段函数边界**：列出路径与边界，让市场选，操作随边界切换；一般「测终点」多为概率话术。
- **走势客观，用什么级别分析是主观**；固定操作级别后，该级别非上涨可不参与。
- 同级别分解要求规则下**分解唯一**；多义性主要针对**未完成**走势，已完成走势在规则下应能唯一划分。
- **小级别进、大级别持有**可「换挡」（多重赋格）：各级别遵守本级节奏，资金与筹码分层配置。

> 「真正的预测，就是不测而测。」

## 二、买卖点实战要点

### 2.1 一买实战

- 一买＝趋势结束一侧；**回避跌势未尽**：标准选股结构可侧重「下跌+盘整+下跌」后的一买（第16课程序）。
- 周线级别可配合**盘整背驰**类一类买点；季线类二买可用区间套逐级定位。
- 一买后若**再男上位缠绕**或走势违背买入程序：逻辑走，勿侥幸（金亚类案例思路）。
- 背驰后只保证**回拉最后中枢**，后续须完全分类；C 段未走完慎判背驰。

> 「你的利润不是来自预测成功，而是一个包容错误的系统。」

### 2.2 二买实战

- 大级别二买＝次级别一买（区间套）；二买不明显时**降级**到日线找一买。
- 二买在**中枢中心偏弱**：防扩张、不及预期早兑现；与「一买后再缠绕先退」一致。
- **二买与三买重合**≈合力强；530 等突发下**二卖**往往优于等待一类卖点。
- 二买三种强弱（第101课思路）：与三买合一最强，低于一买最弱，中间态取折中策略。

### 2.3 三买实战

- 三买要**第一次**离开+回抽确认；非第一次回抽不构成三买（如工行 12/22 例）。
- 三买适合短线好手；三买后若走成盘整则**逢高减**，失败按盘整处理。
- 尽量做**第一个中枢的三买**；三买后次级别不新高或盘整背驰须走。
- 小级别三买可先出现于大级别三买之前，值得重视；打板可用是否出三买等过滤（熟练者）。

> 「第三类买卖点比第一、第二类要后知后觉，但抓得好往往少耗盘整时间。」

### 2.4 卖点操作

- **偏好**：同级别分解下可偏向**二买与一卖**；上涨中才出现卖点，宁卖早勿卖晚。
- 卖点多看湿吻是否重合；**不重合**时背驰看两吻间 MACD 面积与柱高。
- **顶分型 + 有效破 5 日线**：可作短线离场参考；分型中继则计划回补。
- **买之前戏，卖之高潮**：加速段短，放量/高位平台忌贪；MACD 最猛一段易钝，慎卖飞亦防逆转。
- 急速行情：**卖可降级**抓加速顶（第60课）；月线战略买、**末端卖可降到小级别**。

> 「在下跌里除最后位置外所有卖出都对，但那与缠论无关——类似赌博。」

## 三、MACD 实战应用

- **顺序铁律**：先中枢与走势分析 → 选定比较段 → 再选周期看 MACD。**顺序不能反**，比较对象错则一切无效。
- MACD **非绝对精确**；纯 MACD 约九成把握，**配中枢**可严格化；与软件显示差异处要回到定义思考。
- **0 轴**：黄白线难上 0 轴可作弱势退出参考；**防狼术**（第103课）：大周期长期在 0 轴下＝空头主导，能力一般应规避。
- 第一个中枢常伴黄白线**双回抽 0 轴**；双中枢上涨在 MACD 上常有典型路径。
- 强势股日内可看**柱高触极限**；一字涨停看 1 分钟中枢上移；日线 MACD 在 0 轴附近盘可考虑升级别观察。
- 比较 MACD 时：是否先回抽 0 轴决定用**背驰**还是**震荡**视角（第47课一类场景）。
- **BOLL 辅助**（第90课）：进出超强区且不能再回超强区，常近一类买卖点附近；收口常对应中阴时间级别扩展或结束——与 MACD 同为辅助，技巧性更高。
- **中枢震荡监视器 Zn**（第92课）：Zn 长期在震荡中轴 Z 下方介入风险大（易三卖或加速下）；Zn 缓慢抬高无力破上沿警惕楔型诱多；变盘时间常近 BOLL 收口。

> 「一定要把吻和中枢分开，不要把均线系统和中枢混在一起了。」

## 四、资金管理与仓位

- **无压力、长期限资金是第一要点**；忌融资杠杆——错一次可能归零（历史案例对照）。
- **忌越涨越加**：研究透后一次性买够；机动资金做短差**降成本**，勿养成下跌补仓摊平恶习。
- 目标：**成本归零**后「挣股票」；一倍升幅附近大级别卖出一部分收回本金。
- 散户持股数宜极少（如 1–3）；计划外改计划＝计划不周或执行不力。
- 大资金多在**月/周第二类、第三类买点**布局，少做月线一买以免成庄；小资金可全仓轮动但**级别不宜过小**（T+1、滑点）。
- 牛市暴跌（一夜情）：侧重**降成本、增筹码**；筹码越来越少是牛市大忌之一。
- **第一利润定理**（固定品种+固定级别）：只参与盘整与上涨；盘整用中枢震荡降本；三买后持到新中枢再震荡；**上移不短差**（不熟勿勉强）；最后背驰清仓。
- **第二利润定理**：不断换股只做三买，一新中枢即换，追时间效率——两种模式勿偏废，**第一种更适合大多数人**。
- 中枢震荡差价相对机械安全；级别过小则 T+1 易被困；第二种模式需市场持续给出三买机会。
- 大资金建仓共性（杂史课归纳）：**年线拐头、明显资金介入、回调年/半年线附近**；关键是对标的盘面与股性有足够了解。

> 「一笔足够长时限的钱 + 熟练运用理论 ≈ 战无不胜。」（在交易可持续前提下）

## 五、操作纪律与常见错误

- **唯一节奏**：买点买、卖点卖；节奏乱则停止交易。**节奏重于精度**，精度只影响利润多少。
- 小级别操作**必须看大级别状态**；初学者至少 **30 分钟**，不宜沉迷小于 5 分钟。
- **早泄**（程序失败）＝介入后走势未按程序：严格止损，再强反包也不侥幸；三系统输入须**本质独立**，否则乘法无效。
- **逻辑进、逻辑出**，非盈亏进出；走势违背程序即走，与盈亏无关。
- 不熟练**不全仓**；遮代码练「只看图」；卖点时自查幻想链（再等等→等反弹→幻想反转）。
- 对照第42课十种不宜：耳控大脑、赌徒、股评型、偏执狂等——严重则离场或换环境；每日复盘十分钟，写下来更佳。
- 远离荐股传销与消息捷径；一切花招落点仍是**买卖点**。
- **同级分解操作**（第38–40课）：卖错买错无所谓，只要节奏与回补逻辑对；培养机械韵律；**停错也要先守纪律**。
- **小转大预防**：跌破三买相关次级别高点则反弹先走；含三买的最后小级别中枢出现三卖可先减；勿用 30 分级别却见 1 分背就清仓（等于偷换级别）。
- **持股与持币**：买卖一瞬间，长期是等待——等待走势生长到买卖点（农耕类比）；买点后持到该级别卖点，卖点后持币到下一买点。
- **每日走势分类**（第46课辅助）：30 分钟视角下看当日中枢个数——无三三重叠为最强单边；变盘常近午盘；不与固定操作级别矛盾。
- **反弹熊市**（第107课）：操作级别**统一降一级**分解；勿因贪每个波动把级别越做越小。
- **政策与硬调控**（第74、56课）：硬调控尽一切可能先撤；盈利厚预留比例承受非系统冲击；个股质地是底线。

> 「节奏比精度更大是大非，精度是利润多少。」  
> 「所有操作归根结底只有两个字：等待。」

## 六、速查表

### 背驰判断检查单

| 步骤 | 检查项 |
|------|--------|
| 1 | 固定级别：走势类型是趋势还是盘整？ |
| 2 | 盘整只用**盘整背驰**；趋势背驰须有两段可比的趋势结构 |
| 3 | A、B 中枢是否**同级**？c 是否为次级别且含对 B 的**三买/三卖**？ |
| 4 | C 段是否**已走完**？刚新低/新高时慎判 |
| 5 | MACD：比较段选定后，再看柱面积/黄白线回抽 0 轴与否 |
| 6 | 多级别：小背逆大级别→仅短差或减仓，勿默认大反转 |

### 买卖点确认流程

| 阶段 | 动作 |
|------|------|
| 选股 | 三系统独立过滤；只做「能搞」分类；基本面/比价在选股阶段完成 |
| 定级 | 固定操作级别；大级别定战略，执行可到次级别 |
| 定位 | 先找最近本级别中枢 → 三类位置（内/下/上）→ 区间套精确定位一类 |
| 买入 | 一类/二类/三类按程序；一买后防扩展最弱路径 |
| 持有 | 该级别卖点未现前持股；中枢上移过程理论不短差（不熟勿强求） |
| 卖出 | 程序破坏即走；突发行情优先二、三类卖；顶分型与破 5 日作辅助 |
| 回补 | 卖后等新买点；三卖后不回补直至新买点 |

### 常见操作错误及改正

| 错误 | 改正 |
|------|------|
| 把均线吻当中枢 | 分开定义；中枢用三段重叠，吻作辅助 |
| 见小级别背驰就清仓 | 联立大级别；日线强则 5 分背仅短差 |
| MACD 先画后找走势 | 先分解走势与比较段，再开 MACD |
| 预测空间、与股票谈恋爱 | 只信分类与边界；能操作≠喜欢 |
| 级别越做越小 | 降回 30 分及以上为主级别 |
| 越涨越加、杠杆补仓 | 一次性买够计划仓；禁借贷配资 |
| 不听卖点、幻想反转 | 钢铁纪律：卖点敢砍；卖错宁早 |
| 迷信庄家消息荐股 | 只看图与三类买卖点 |
| 背了又背 / 分不清扩展 | 回到第29课三类演化；区分最后中枢扩展与更大盘整 |
| 中阴里追涨杀跌 | 按中枢震荡；触发分类边界再切换预案 |
| 分型一出就满仓进出 | 分型辅助；核心仍是次级别走势与三类买卖点 |

### 开仓前决策清单（第41课延伸）

| 自问 | 说明 |
|------|------|
| 操作级别是？ | 小于 5 分须有大级别背书；上班族宜 30 分及以上 |
| 最近本级别中枢在哪？ | 三类位置：内 / 下 / 上 |
| 大盘与板块同向否？ | 背驰日买若 T+1 受限，宜略强于大盘的标的 |
| 买点类型与失败边界？ | 程序破坏走，与盈亏无关 |
| 仓位与容错？ | 不熟练减仓练；不全仓赌精确点 |

### 突发利空 / 大幅低开（530 类）

| 要点 | 处理 |
|------|------|
| 一类卖点常不存在 | 重点找**二卖、三卖** |
| 缺口+向上段不新高 | 常为二卖信号 |
| A 段内部背驰 | 可确认二卖；结合 B 与缺口段盘背看反弹高度 |
| 是否回补 | 视操作级别与品种，预先写好分支 |

### 中枢震荡简要（第49、92课）

| 情境 | 倾向 |
|------|------|
| 向下离开段底背 | 介入候选 |
| 上拉不过前高或顶背 | 先出 |
| 次级别不回中枢 | 考虑三买或二卖（依方向） |
| Zn 偏弱、近下沿 | 谨慎回补，防三卖 |
