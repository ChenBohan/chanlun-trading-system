## 一、核心认知（匪注独特视角）

### 1.1 图与定义：谁说了算

- **插图是示意**：复杂走势以 **定义 + 分解** 为准，勿被示意图「带跑」（匪注多次钉死，尤其中枢扩张、三买三卖示意）。
- **MACD 周期勿机械照搬**：缠师曾用「长一倍周期」类示例，匪注提醒易 **误读参数**，须回到 **当下选定对比段** 再配 MACD（第 14 课匪注精神）。
- **神奇数字不必迷信**：两盘整比力度时以 **结构完成处** 为参照，力度判读以 **MACD + 走势类型** 为主（第 27 课匪注）；匪注亦补 **闭区间套** 的数学直觉，但不替代当下分解。

### 1.2 级别与分解的「两条路子」

- **分析顺序**：匪注强调 **从高到低** 定级别与过滤器，再落笔段中枢（与「当下」两难并存时的实务顺序）。
- **同级别分解**（机械化波段）与 **延伸 / 扩展 / 新生**（精细结构）**条款不可混用**：尤其「盘整 + 盘整」在 **同级别分解法下允许**，在另一套分解规则下可能不允许——**操作前选定主视角并一贯到底**（第 38–39 课匪注）。
- **多义性纪律**：多解合法时选 **最利于执行** 的一种，但 **不得违背已完成走势类型**；反对用多义性 **事后合理化** 错误操作（第 33 课匪注）。
- **「金钥匙」备忘**（第 99 课匪注）：**连接中枢的走势级别必小于中枢**——一段完成后至少面临 **更大级别震荡**；划分宜 **先保证中枢成立**，再用结合律整理形态。

### 1.3 理论自信从哪里来

- **信心来自逻辑自洽**：先读懂定理与完全分类，再谈盘感（第 30 课匪注与第 50 课取向一致）。
- **「我在哪里」优先于「涨到哪里去」**（第 32 课匪注）：当下只问——何级别、何中枢、何类型、边界在哪。
- **无适合自己级别的买卖点，一切概念是空谈**（第 34 课匪注）：与「能搞 / 不能搞」一脉，先锁定操作级别再谈形态。
- **完全分类要立体**（第 100 课精神）：小资金可单层次，大资金须 **多级别联立**；例如 30 分无三卖、5 分离开未三卖、1 分下跌已成立——组合成 **当下分类**，演化顺序常自 **小级别背驰** 指向 **是否构成更大级别三卖** 再反推参与与否（匪注配图在原文后续页，此处取逻辑骨架）。

### 1.4 品种、指数语境与「轻装」

- **期货 / 外汇**：匪注常强调 **不参与超级别盘整**、双向下「先卖后买」更难执行；股票可用震荡降本，期货更宜等趋势（第 45、53 课匪注互参）。
- **商品短线**：第 29 课匪注提示 **扩展** 更常见，资金利用率与换股纳入分类。
- **商品震荡**：第 92 课匪注点 **多次假突破**——Zn / BOLL 仅预警，仍以三类点为准。
- **基金与叙事**（第 28 课匪注取向）：点破传销式「价值投资」话术、**废纸本质** 与群体非理性；**承认废纸性质** 反而能 **轻装** 按走势操作（与第 26 课风险观衔接）。
- **道氏摘录**（书中引《专业投机原理》）：指数分部门、经济晴雨表等 **背景阅读** 即可，**不替代** 本级中枢与背驰；匪注价值在提醒 **大势亦为走势分解对象**，勿迷信单一叙事。

### 1.5 线段与最低级别（答疑向）

- **线段主要服务最低分析级别**；「把次级别当线段」多为比喻（第 64 课节选）；划段出错会连锁中枢级别错误——与 `缠论解析操作框架.md` 的笔线段章节交叉时，以 **定义顺序** 校准。

## 二、买卖点实战补充

### 2.1 一类与盘整：别在「第一个中枢后」赌反转

- **趋势背驰** 多在 **第二个中枢之后** 才典型；**第一个中枢后** 的「背驰」常为 **盘整背驰** 或中继（第 27 课；匪注：级别过小意义有限，**越大级别越稳**）。
- **盘整背驰** 是趋势背驰的「缩略版」：**ABC 分清楚** 才分得清趋势 / 盘整；**没有级别就没有背驰**（第 24 课匪注）。

### 2.2 二类、三类：强与险

- **二买三买合一** 仍可能演化为 **更大级别中枢扩张**——须 **当下跟踪**（第 21 课匪注）。
- **三买** 精妙在 **不依赖未完成中枢的不确定性**（第 23 课匪注）；**突破跟进** 易混 **假三买**，须 **扣回第三类定义**（第 37 课匪注）。
- **小转大**（第 44 课）：必要条件常落在 **最后次级别中枢** 上出现 **第三类卖 / 买**；匪注：**2.4 离场宜在回抽次级别将尽**，忌拖成情绪盘。
- **未创新高** 按 **中枢震荡** 看，与 **背驰** 不同（第 44 课匪注）；持有过程亦是心态训练。

### 2.3 盘整背驰后的三条路（须烂熟）

匪注要求刻进肌肉（第 25 课）：**三买 / 中枢延伸 / 更大中枢**；并记 **大级别未背驰前，次级别可延续**。

### 2.4 走势类型「完成」的答疑补丁

- **趋势完成** ≈ **背驰**；**盘整完成** 常与 **第三类买卖点** 相关；**走势类型完成** 未必只靠盘整背驰（第 42 课附录匪注）——忌「见盘背就等于该级别已死」。

### 2.5 突发与日内：评论精华取向

- **第三类卖点** 为理论保障的 **最后离场位** 之一（第 47 课）；例：跌破 5 日线后反抽确认 **对前一日中枢的三卖**——匪注强调中枢震荡 **对称性**，分笔背驰可用 **1 分 MACD 柱长** 辅助，但批判「分笔吓唬人」式的滥用。
- **530 印花税行情**（第 56 课）：巨低开时 **第一类卖点常消失**，可操作 **第二、三类卖点**；**宁卖早**；匪注对称句：**大低开盯二 / 三卖，大高开盯二 / 三买**（理解语境，勿背死句）。
- **反弹与反转**（第 107 课）：按 **次级别分段**；有 **三买 + 非背驰强攻** 可持至后续中枢直至背驰 / 三卖；**最精确定义的上升趋势**：第一中枢后 **三买且非背驰向上**（总结中匪注给出级别化趋势定义）。

### 2.6 中阴、震荡与辅助工具（操作归属）

- **中阴** = 前类型已「死」、新类型未立，**多空齐杀**（第 88–89 课匪注）：技术不足 **观望**；技术好按 **大级别中枢震荡** 做短。**公理**不能代替 **精确分类**（第 89 课匪注）。
- **BOLL**（第 90 课）：**收口** 常提示中阴 **近尾声**；可 **大级别 BOLL 看小级别中阴**；「贴不回上轨 / 碰不到下轨」等须 **自己看图归纳**（匪注：技巧性高于背口诀）。
- **Zn 监视器**（第 92 课）：**Zn** 相对中轴 **Z** 看强弱；**单次突破** 未必立刻出三类点；**楔形诱多 / 诱空** 与 Zn 无力突破 B 端结合看；商品 **多次假突破** 匪注点名害人。

### 2.7 表里关系与 (1,0) / (-1,0)（第 91、93 课）

- **(方向, 状态)** 矩阵可视作第 16 课 **趋势 + 盘整** 的精细版；**大周期过滤小周期**（匪注）。
- **(1,0) / (-1,0) 后必分叉**：保守型可先 **兑现成本留利润**；积极型在 (1,0) 做短差，若市场选 (-1,1) 则 **最后一次不买回**；若回到 (1,1)，比较 (1,0) 区间两段力度，后弱于前 → **见顶信号** + **区间套** 卖（第 93 课表格式归纳）。匪注：**盘整之后涨跌皆可**，忌单路径预测。

### 2.8 底部与分型（第 108 课匪注取向）

- 买点在 **下探分型区间失败（不破下沿）** 一侧，**不在分型区间上沿乱买**；三买先则底部构造 **完成**，三卖先则 **失败**（课文逻辑）。匪注对比混沌操作 **「五颗子弹」**：认为缠论介入点在其 **第 3～4 颗** 之间、在成功率与退出上更有优势——属 **范式对照**，实操仍按本级别分解。

### 2.9 买卖点决策树（匪注增强版）

```
怀疑「一买 / 一卖」？
├─ 是否已走出第二个本级别中枢？否 → 优先按盘整背驰 / 中继处理，控制仓位
├─ ABC（含 B 中枢级别）是否画清？否 → 先不判趋势背驰
└─ 柱缩短 ≠ 面积背驰 → 第 37 课：比段、比面积

已见二买或三买？
├─ 二 + 三重合？→ 强，仍防更大级别扩张（21 课匪注）
├─ 三买？→ 回抽级别与 ZG 严格验定义（防假三买，37 课匪注）
└─ 小转大？→ 最后次级别中枢是否已出三类点（44 课必要条件）

持仓中遇小级别顶背驰？
├─ 操作级别背驰？→ 按主框架减仓 / 清仓
├─ 仅次级别？→ 未破三买高可忽略；破三买高则回抽先离场
└─ 回抽将尽时决断（匪注），忌「怨男」拖延

突发大利空 / 巨幅低开？
├─ 一卖常「消失」→ 转向二卖 / 三卖程序（56 课）
└─ 宁卖早；再按新中枢分类决定是否回补
```

## 三、MACD 实战应用

### 3.1 顺序铁律（第 50 课 + 匪注十五条取向）

**走势分解 → 选定比较段 → 再选 MACD 周期**。压缩检查表：

| 步骤 | 要点 |
|------|------|
| 分解先行 | 无分解则 MACD 为噪声 |
| 比面积 | 趋势背驰看 **柱面积**；急走势 **已见面积 ×2** 预估 |
| 看回抽 | 段间回抽 **0 轴** 常关键；**双次拉不回 0 轴** 警惕类三卖 / 买 |
| 防狼 | **0 轴下** 空头主导，普通人回避（匪注：无技术先防狼） |
| 双头 | **高位双头** 下来多属 **次级别** 反弹结构，勿与本级别趋势背驰混淆（第 37 课） |

### 3.2 形态与特殊走势

- **两中枢上涨** MACD 路径（第 25 课）：水下上穿 → 0 轴上留驻（一中枢 + 二买区）→ 第二中枢再回 0 轴 → 再上冲背驰结束；匪注：**双重 0 轴停留**、**多周期二买共振**。
- **1 分急拉 / 一字涨停**：**柱高（乖离极限）**、**1 分中枢上移**（第 25 课）；非典型背驰语境。
- **急促走势**：MACD 用法与常态不同（第 24 课匪注）。

### 3.3 多级别与「末段」

- **日线中段** 的 5 分钟背驰力度 **有限**；**日线末段** 1 分钟背驰也可 **大跳水**（第 25 课）——先判大级别 **阶段**。

### 3.4 分笔与 1 分钟沉迷

- 匪注自省 **2010 沉迷 1 分图**（第 57 课）；混沌统计约 **140～150 根 K** 量级仅作 **背景**，不替代三类点。
- **最低分析级别以下** 可「抹平」波动（第 57 课）——与执行级别、通道匹配。

### 3.5 第 50 课附录「MACD 十五条」精要（归纳）

下列与总结文档及匪注长条一致，作 **备忘条** 即可（仍以分解为本）：

1. 先看走势，再找背驰段，最后才谈 MACD 周期。  
2. 柱子看 **面积**，不看一两根长短。  
3. 背驰段内柱子 **伸长放缓** 时可用 **已见面积 ×2** 预估（与主框架一致）。  
4. **黄白线回抽 0 轴** 后再走的段，常与比较段 A、C 对应。  
5. **0 轴下** 整体偏空，介入多为 **一买 / 背驰** 语境，忌普通追涨。  
6. **双次拉回 0 轴失败**，警惕 **类三卖 / 类三买** 方向（对称思考）。  
7. MACD **金叉死叉** 不能替代 **中枢与背驰段**。  
8. 同一图上多周期 MACD 是 **多级别联立**，不是多参数迷信。  
9. 盘整背驰先看 **是否围绕同一中枢**，再看柱面积。  
10. 背了又背常是 **级别错** 或 **段未走完**（对照第 37、43 课）。  
11. **MACD 与均线面积** 可互证，勿强行一一对应到每一笔。  
12. 选好股后，**按固定操作级别** 切换 MACD 周期，勿盘中乱换。  
13. 学习阶段可 **缩小样本**：先几只股练熟 **A-B-C** 与 0 轴关系。  
14. 复盘时把 **MACD 截图与分解图** 对齐，训练「先结构后指标」。  
15. 指标失效时回到 **三类买卖点定义** 与 **完全分类**。

## 四、资金管理与仓位

### 4.1 稳固基础（与主框架一致处从简）

- **成本 → 0 → 负成本**；**盈亏股分类**；**比例与级别、把握度匹配**（第 31 课）。
- **量 = 资金管理**；**先保命再求发展**（第 26 课匪注）。

### 4.2 匪注强调的执行点

- **第一笔钱**：盈利后 **抽本、利润滚动**；勿无限追加（第 95 课）；匪注：**稳定技术与操作比初始本金更重要**。
- **多重赋格**（第 40 课）：各级别 **规则自洽**，禁止 **临时改级别**；周复盘问：**是否越级**、是否把 **短线卖点当中线清仓**。
- **三买后上移**：持股至 **新中枢** 再震荡差价，**上移途中不做短差**（第 49 课匪注对齐第一利润最大定理）。
- **交易成本上升** → 最低操作级别宜 **5 分或 30 分以上**（第 48 课）。
- **不参与超级别盘整**（期货外汇匪注，第 53 课）与 **大资金月周二、三买布局**（第 26 课取向）可并入自身资金属性检查。

### 4.3 政策与泡沫（第 74 课）

- 泡沫阶段 **只战略持有、不战略买入**；硬调控 **先逃** 再论空间；政策为 **分力**，忌阴谋论一根筋（匪注）。

### 4.4 不同人群的资金策略（第 79、95、97 课取向）

- **极忙人**：定投 **指数 + 成长基金** 一类方案（课文建议）；技术未过关前 **少单票重仓**。
- **有时间的散户**：**第三类买点** 程序（定级别、看背驰、看上移、尽量 **第一个中枢后** 的三买）；匪注：**三买最快**，背驰 + 区间套解「滞后」困惑（第 79 课总结）。
- **第一笔钱纪律**：赢利抽本、利润滚动；**十年尺度** 看技术与修养（第 95 课）；青蛙隐喻——不懂结构、进出无据则难进化（匪注）。

### 4.5 均线、轮动与板块（第 106 课匪注）

- 参数需 **贴合历史走势**（文中介 5、13、21、34、55、89、144、233 等 **成套均线**）；**同趋势多中枢** 常受 **相近均线** 压制；反弹能否过 **55 / 89 / 34** 等可作 **级别强弱试金石**。
- 按 **当前未攻克的最小周期均线** 给个股分 **9 类**，**轮动** 时从顶背驰的一类换到已调整、可再启动的一类——匪注：类别是 **力度 / 位置** 的横向比较工具，非圣杯公式。

## 五、心态修炼

### 5.1 市场即人性道场

- **道** 在贪嗔痴与陷阱处同样现前（第 23 课匪注）；归根是 **人格、见识、修养**。
- **节奏**：买点在下跌、卖点在上涨；**勿在买点上换股到卖点上**（第 41 课匪注）。
- **面首 vs 怨男**（第 34 课）：**买点勇敢、卖点如果断**；踏错节奏 **先玩好一只**，忌追高换股（第 55 课取向）。

### 5.2 复盘与观心

- **每日收盘 10 分钟**：操作 + **心理过程**（第 42 课）；匪注比附 **生住坏灭** 观心——可当作 **注意力训练**，不必宗教绑定。
- **反省要具体**（第 50 课匪注）：级别错、分解错还是执行错。

### 5.3 不适合与市场退出（第 42、96 课）

- 十种不宜类型（耳控大脑、赌徒、股评依赖等）根子问题宜 **退出** 或 **降杠杆**；承认 **我不行**、**离开数年** 亦理性（第 96 课）。

### 5.4 学佛、中医、兵法式操作观（第 52、97、98 课匪注取向）

- **操作级别** = 对你有用的分类；**中医式**：理论输出 → 当下望闻问切 → 边界内开方；**贪字近贫**；热爱走势才能把图看懂而不被盈亏糊眼。

### 5.5 分型心理与执行（第 82、80 课）

- 顶分型 **二三 K 小阴小阳** 多中继；**长上影 / 长阴** 且第三 K 弱 → 成笔概率大；**钢铁战士** 纪律与 **禅定式** 执行（第 80 课匪注取向）；期货执行难度高于股票。

### 5.6 心态与执行检查清单（收盘可用）

- [ ] 买卖是否落在 **本级别三类点**（或预设次级别计划）？
- [ ] 是否 **临时改级别** 或混淆短线与中线卖点？
- [ ] 是否把 **示意图 / 股评** 当主因？
- [ ] **MACD** 是否先于 **分解**？
- [ ] **中阴 / 扩张** 期是否重仓赌方向？
- [ ] 是否 **赌徒循环**（砍追连环）？→ 减仓或离场。
- [ ] 一句话能否说清：**何级别、何中枢、何走势类型？**

### 6.1 错误对照表（匪注向）

| 错误 | 后果 | 纠正 |
|------|------|------|

| 二 + 三买合一不跟踪 | 遇扩张被动 | 21 课匪注：仍可更大级别扩张 |
| 突破追进当三买 | 假三买 | 回第三类定义（37 课） |
| 两套分解条款混用 | 执行崩溃 | 38–39 课：主视角一贯 |
| 沉迷 1 分钟 | 噪音 + 心态崩 | 57 课匪注；放大可执行级别 |
| 中阴重仓 | 多空齐杀 | 观望或仅限高手法震荡 |
| 多义性粉饰错误 | 不进步 | 已完成类型不可歪曲（33 课） |
| 辅助工具替代三类点 | 逆势或踏空 | 辅助 + 结构双轨 |
| 一根筋「止损词」替代三类点 | 与理论割裂 | 第 86 课取向：以走势类型与卖点程序为主；与主框架止损表并用时 **自洽为先** |
