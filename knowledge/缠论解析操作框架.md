## 场景 A：从 K 线到笔（几何打底）

### 决策流程（必须按序）

1. **包含处理**：从左到右只处理**相邻**两根；合并后新 K 再与下一根比；图中**不得残留**相邻包含。
2. **定方向**（与「前一根非包含 K」比第一根包含 K 的**高点**）：高于前高 → **向上处理**（新高取 max，低取两低中较高者）；低于前高 → **向下处理**（新低取 min，高取两高中较低者）。
3. **标分型**：顶分型 = 中间 K **高点最高且低点也最高**；底分型对称。**先做包含再分型**。
4. **合并同类分型**：多顶取**更高顶**，多底取**更低底**（中继分型省略）。
5. **连笔**：仅**顶底相邻交替**相连；两顶或两底**不能直接成笔**；检查**旧笔**或**新笔**规则（二选一、全图统一）。

### 旧笔 vs 新笔（速决）

| 规则 | 旧笔（经典） | 新笔（放宽） |
|------|-------------|-------------|
| 顶底之间 | 至少 **1 根独立 K**（不属于两端分型三根） | 顶最高 K 与底最低 K **之间**（不含这两根）裸数至少 **3 根 K** |
| 禁止 | 顶底**共用 K 线** | 同样禁止共用 K |
| 区间 | 顶区间须与底区间**不矛盾**（顶不低于底的整个区间） | 同左 |

### 笔的「当下四状态」（变量数组）

- 分量一：`1` 向上笔，`-1` 向下笔。分量二：`0` 分型构造中，`1` 分型已确认后的延伸/新笔过程。
- 合法跳转：`(1,1)→(1,0)→…`，**不可**从 `(1,1)` 直接跳到 `(-1,1)`。
- **简易对策（书中归纳）**：`(1,1)` 持股；`(1,0)` 考虑卖；`(-1,1)` 持币；`(-1,0)` 考虑买（均可能中继，需结合大级别）。

### 分型操作口诀

- **无顶分型则无顶**（上涨段）：未出顶分型不宜急于卖。
- **无底分型则无底**（下跌段）：未出底分型不宜急于买。
- 第一次分型**中继概率高**；第二、三次同向分型风险意识要提高。强顶分型：第二根长上影/长阴且第三根弱，杀伤力大（底对称）。

## 场景 B：线段、中枢与走势状态

### 线段结束（解析书步骤）

1. **笔破坏**：向上线段 — 最后顶后向下笔**跌破前一顶**连线；向下线段 — 最后底后向上笔**升破前一底**连线。
2. **真破坏**：笔破坏后若发展出**新线段**则原线段结束；若仅一笔破坏又创新高/低 → 原线段**延续**（**笔破坏 ≠ 线段结束**）。
3. **有笔破坏**：向上线段只看 **X（向下笔）** 的标准特征序列是否出**顶分型**；向下线段只看 **S（向上笔）** 是否出**底分型**。包含须先处理成**标准特征序列**。
4. **无笔破坏（有缺口）**：特征序列第一、二元素间有**缺口** → 用后续另一序列是否出现**相反分型**确认端点；后序列**不必封闭**缺口，**有分型即可**（与课 67 思路一致）。

### 中枢（本书实务口径）

- 严格递归易循环；**实务常用**：**三段次级别线段**的重叠区间为中枢；**最小中枢零件取线段**（笔过碎，不宜单独构成中枢）。
- **ZG / ZD**：三段重叠的**高取低、低取高**得区间上沿/下沿。
- **形态**：上涨趋势中多 **下–上–下**；下跌趋势中多 **上–下–上**。
- **延伸**：次级别离开再回中枢区间 → 震荡。**新生**：离开不回、形成**新同向中枢** → 趋势。**扩展**：后中枢波动**触及**前中枢延伸时的波动区间 → **更大级别中枢**，按盘整处理。
- **同级别趋势**：前后中枢区间**不得重叠**（含瞬时波动触及则升级为更大中枢，见课 18 精神）。

### 中枢三类情形的操作倾向（书中示意）

| 情形 | 倾向 |
|------|------|
| 延伸（振荡） | 下沿附近偏买、上沿附近偏卖做差价；警惕变扩展/新生 |
| 新生 | 向上新生持股、向下新生持币；少做短线「点」博弈 |
| 扩展 | 视为高一级盘整，按盘整策略 |

## 场景 C：三类买卖点 + 背驰联立

### 辨析口诀（本书）

- **一类** = **背驰点**（趋势末端）。
- **三类** = **中枢破坏点**（回抽不进 ZG/ZD）。
- **二类** = **次级别的一类**（本级别二买 = 次级别一买）。

### 位置要点（与中枢）

- **没有趋势就没有背驰**；一买至少在**下跌趋势第二中枢下**，一卖至少在**上涨趋势第二中枢上**（解析书图意）。
- **二买 / 三买可重合**：一买后次级别强劲上破最后下跌中枢，回抽**不进**该中枢 → 二、三买合一（卖点对称）。
- **中枢延续**：不产生标准「三类买点意义上的新点」，可按**盘整背驰**做震荡差价。

### 背驰判断（三联立）

| 方法 | 怎么用 | 注意 |
|------|--------|------|
| **形态** | 相邻同向两段，后段**幅度/力度**弱于前段；**段须走完**再比 | 易把中继当背驰 |
| **MACD** | 结构 **A–中枢B–C**；B 常把黄白线拉回 **0 轴**附近；**C 段红/绿柱面积（或高度）**小于 A → 趋势背驰；柱伸缩变慢可用「已见面积×2」预估 | 辅助，以走势分解为准 |
| **黄白线** | 跌中 C 新低但黄白线回 0 轴后**不再新低** → 底背驰嫌疑；顶对称 | 多级别联立 |
| **均线面积** | 两「吻」间短长均线**相交面积**比力度；后段面积缩小 → 背驰；可用 **面积/时间** 做趋势平均力度 | 与中枢体系并行，勿强行一一对应 |

### 盘整背驰 vs 趋势背驰

- **盘整背驰**：**一个中枢**附近欲脱离却力度不足被拉回；**非**标准趋势背驰；第一个中枢后常见，级别过小则实战意义有限。
- **趋势背驰后分类（理论）**：至少**拉回原中枢**；其后可能是**最后中枢扩展**、**更大级别盘整**、**反趋势**；是否最强反转看是否走出**第三类买卖点**等。

## 场景 D：区间套（精确定位）

### 流程

1. 大级别（如日线）标定疑似 **C 段**（背驰段）。
2. 在 C 段内打开 **30 分钟** → 找更小级别背驰段。
3. 再缩至 **5 分钟 → 1 分钟**（乃至分笔），直到满足你的下单精度。
4. **原则**：背驰段未走完前**按背驰段处理**，直到被更强力度否定；级别越小噪音越大。

### 与三类买卖的关系（书中提醒）

- 小级别背驰引发大级别转折，常需**最后次级别中枢出现三类买卖**作为**必要条件**（**非充分**），忌机械套用。

## 场景 E：均线系统（女上位 / 男上位与「吻」）

### 概念速查

| 术语 | 含义 |
|------|------|
| **飞吻** | 短期略走平但不真正靠拢长期，原趋势极强延续 |
| **唇吻** | 轻触长期，未有效跌破/突破，延续原趋势 |
| **湿吻** | 反复缠绕、跌破又升破 — **转折多由此引发** |
| **女上位** | 短期在长期之上 |
| **男上位** | 短期在长期之下 |

### 走势分类（均线高低点）

- **上涨**：最近高点高于前高 **且** 最近低点高于前低。
- **下跌**：最近高点低于前高 **且** 最近低点低于前低。
- **盘整**：高低点不规则交替。

### 均线视角买卖点（与结构体系并行）

| 点 | 解析书归纳 |
|----|------------|
| **一买** | **男上位**最后一吻后的**背驰式下跌**低点 |
| **二买** | **女上位**后**第一次缠绕**中的下跌低点 |
| **一卖** | **女上位**最后一吻后的**背驰式上涨**高点 |
| **二卖** | **男上位**后**第一次缠绕**的上涨高点 |

### 操作流（懒人链）

长期 **男上位** → 等最后一次湿吻的**背驰下跌**试一买 → 转入女上位后**第一次缠绕**做二买/加仓 → 持有至女上位后**顶背驰**（一卖）或转男上位后**第一次缠绕高点**（二卖）。

### 风险与偏好（本书观点）

- 一买易判成**下跌中继**；二买易判成**上涨中继**。**一般投资者买入更宜二买**；**卖出宜尽量一卖**（背驰）。

## 场景 F：防狼术与高效买入程序

### 防狼术（过滤）

- 以 **MACD 黄白线与 0 轴**分多空：某周期黄白线在 **0 轴下** → 该周期**空头主导**，宜**回避**（个股/指数同理）。**级别越大，过滤越强**。

### 高效买入（程序归纳）

- 六种连接里，**值得买**的多来自「跌后转折」类：**下跌+上涨**、**下跌+盘整+上涨**、**上涨+盘整+上涨**中后两段等（书中概率叙述）。
- **程序**：只选 **下跌+盘整+下跌**；在**第二段下跌的一买**介入；介入后**一旦出现盘整坚决退出**；不盘整则持有博反转。
- 实质：用**背驰一买**控「跌势未尽」，用**见盘整就走**控「跌+盘+跌」陷阱。

## 场景 G：震荡、中阴、仓位与风控

### 中阴阶段

- 旧走势类型已结束、新类型未定的**模糊段**；易**多空齐杀**。技术好按**大级别中枢震荡**做短；一般投资者**减仓/观望**，等类型确立。

### 仓位与资金习惯（解析书第四章要点，落地请结合自身风险）

- 资金**长期无压力**、**不假手他人**；忌背水一战。
- **绝不上涨加仓**；**可下跌分批**；机动仓做短差**原则上不增加总股数**（与 108 课文档一致处不重复展开，此处强调解析书表述）。
- **买错严于卖错**；卖点尽量靠前（背驰/一卖思维）。
- 每日收盘 **10 分钟**复盘心理与执行是否偏离程序。

### 止损参照（与结构联动）

- **三买失败**：回跌**破 ZG** → 三买不成立，减仓或清仓。
- **二买**：跌破一买低点 → 结构破坏，反弹清仓（与主框架一致，表格式细节见 `股票交易系统.md`）。

## 缠论分析全流程（单页总图）

```
包含处理 → 分型 → 同类合并取极值 → 笔（旧/新笔择一）→ 线段（笔破坏 / 特征序列 / 缺口）
    → 三段次级别线段重叠定中枢 → 判走势类型（盘/趋势）与延伸|新生|扩展
        → 趋势内比背驰（形态 + MACD + 可叠加均线面积）→ 一类点
            → 次级别一类验证二类 → 回抽 ZG/ZD 验证三类
                → 区间套缩小执行价位；均线/防狼术做过滤与懒人确认
```

### 表 4：学习《解析》时的务实原则（第五章精神）

- 定义冲突处（尤其**新/旧笔、线段性价比**）建立**个人一致约定**，复盘只认一套规则。  
- 不把缠论当**封闭公式**；**多系统互证**（形态、MACD、ZG/ZD、均线）。  
- **三买**参照最明确；**一买**重在背驰；**二买**位置自由度大、须看力度与中枢形态。

## 常见错误速查表（解析书强调点）

| 错误 | 后果 | 纠正 |
|------|------|------|
| 包含处理**跳序**或以为可**传递** | 分型、笔全错 | 严格从左到右相邻合并 |
| 未合并包含就画分型 | 假顶底 | 先包含后分型 |
| 同类分型不取极值就连笔 | 笔数混乱 | 顶取高、底取低再连 |
| 旧笔忽略独立 K；新笔允许共用 K | 不成笔或争议 | 统一旧笔或新笔，禁止共用 K |
| 把笔破坏当线段结束 | 级别错乱 | 等线段破坏或特征序列确认 |
| 第一个中枢后见「背驰」就满仓反转 | 多为盘整背驰 | 分清盘整背驰与趋势背驰 |
| 单级别 MACD 背驰满仓进出 | 噪音与大级别未结束 | 多级别联立 |
| 均线与笔线段强行一一对应 | 信号打架 | 并行辅助，规则固定即可 |
| 防狼术替代三类点 | 错过结构机会或逆势 | 过滤 + 结构双轨 |
| 中阴重仓赌方向 | 多空齐杀 | 观望或仅限高手法震荡 |
