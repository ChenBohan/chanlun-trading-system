## 一、核心概念速查

### K 线处理

- 只取**高低点**，不做传统 K 线形态分析
- 四种分型：上升 K 线、下降 K 线、顶分型（品字形）、底分型（倒品字形）
- 包含处理：先找方向 → 上升取高中高/低中高，下降取低中低/高中低 → 按时间顺序逐一处理

### 笔

- **最小 5 根 K 线**：顶分型 + 独立 K 线 + 底分型
- 笔的确立需要反向笔成立确认
- 笔是缠论最基础的**构建单位**

### 线段

- **3 笔以上且有重叠**构成线段
- 向上线段始于上升笔、终于上升笔（奇数笔）
- 线段确立需要反向线段成立确认
- 不使用特征序列（李晓军简化处理）

### 中枢

- **3 段连续重叠**构成中枢（标准：3 线段；实战：3 笔也可）
- 中枢有**方向**：向上走势的中枢 = 下-上-下构筑
- 中枢有**区间**：ZG（高中低）和 ZD（低中高）
- 中枢有**能量**：段数越多能量越大
- 奔走中枢：区间极窄的大 N 型，仍为有效中枢

### 走势类型

| 类型 | 中枢数量 | 结构 |
|---|---|---|
| 盘整 | 1 | a + A + b |
| 趋势 | ≥2 | a + A + b + B + c |

- 走势方向由**起始段**定义
- **走势级别由中枢定义**（不是由进入/离开段定义）

### 级别

- 级别 = 计量单位，由**中枢的构成**决定
- 常用序列：1分钟 → 5分钟 → 30分钟 → 日线 → 周线
- 与看哪张周期图无关；需精确时往小周期看中枢实际构成

## 二、三类买点操作指南

### 第一买点（一买）

- **定义**：下跌趋势终结点（背驰引发）
- **条件**：C 段区间套锁定力量衰竭点 + 底分型确认
- **特征**：利润最大但难度最高
- **建议**：初学者慎用，需熟练掌握区间套后再操作

### 第二买点（二买）

- **定义**：一买后回调不创新低
- **条件**：次级别回调 + 同级别不出新低
- **李晓军观点**：二买不能出新低（参考波浪），出新低按线段背驰一买处理

### 第三买点（三买）⭐ 重点推荐

- **定义**：离开中枢后回试不跌破 ZG
- **确认作用**：三买出现才能确认反趋势成立（否则可能是更大盘整）
- **操作建议**：**散户首选三买交易**，确认性最强

### 买卖点关键规则

1. 买卖点**必须搭配级别**描述（如"30 分钟三买"）
2. 买卖点是**多重的**（不同级别的买卖点可同时存在）
3. "30分钟+"概念：30 分钟三买 + 1 分钟一买
4. 卖点 = 买点的反向对应

## 三、背驰与区间套

### 背驰判断

- **原理**：离开段力量 < 进入段力量 → 极可能被吸回中枢
- **MACD 辅助**：红柱开始缩短后，用面积×2 与前段面积比较
- **背驰段**：趋势中 C 段为背驰段（90% 趋势只有 A/B 两个中枢）

### 区间套使用

1. 确定大级别走势的 C 段（背驰段）
2. 进入次级别观察 C 段内部，找到 C 中的 c 段
3. 继续往更小级别推，直到找到力量衰竭点
4. **关键**：必须先锁定正确的比较段（相同性质才能比较）

## 四、走势进阶

### 走势必完美（核心理念）

- 任何走势终将完成 → 新走势的开始
- 交易的本质：参与未完成走势的完成过程
- **缠论三核心**：走势必完美 + 级别 + 背驰（掌握 = 缠论 70-80%）

### 结合律

- 任何组件**只能使用一次**
- 保证分析结果的**唯一性**
- 缠论中唯一不可违背的铁律

### 小转大

| 类型 | 处理 |
|---|---|
| C 段中有背驰的小转大 | 小级别背驰引发大级别转折，正常应对 |
| C 段中无背驰的小转大 | 等二买/三买出现再介入 |
| B 段中的小转大 | 用中枢扩张处理 |

### 中枢生长（三种方式）

| 方式 | 条件 | 升级 |
|---|---|---|
| 延伸 | 中枢内无三买三卖 | 9段以上升级 |
| 扩展 | 三买三卖后回到原中枢（看 ZG/ZD） | 不一定升级 |
| 扩张 | 两个同方向同级别中枢 GG/DD 重叠 | 升级 |

### 走势生长三种模型

| 模型 | 特征 | 判断线索 |
|---|---|---|
| 中枢扩张型 | 大B位置延伸生长更高级别中枢 | 回落笔力量不足 |
| 同级别对应型 | 上→下→上构筑更高级别中枢 | 常规走势 |
| 反向更高级别型 | 上→更高级别反向下跌 | 可能处于更高C段中 |

## 五、多维度分析框架

**李晓军核心观点**：缠论结构只是一个维度

| 维度 | 作用 |
|---|---|
| 缠论结构 | 确定走势阶段、买卖点 |
| 基本面 | 确定价值支撑 |
| 市场情绪/博弈 | 判断方向选择 |
| 市场环境 | 宏观周期判断 |
| 突变因子 | 催化剂/黑天鹅 |

**提前布局条件**：
- 有外因 + 多维度支持 → 可在中枢尾期（二买位置）提前介入
- 不需等三买确认

## 六、学习建议（李晓军）

1. **先建立概念**，再深入运用
2. 多做**练习题**，多复盘
3. 从**1 分钟图**开始感受级别生长
4. **把握特征、完全分类** = 学缠最大要点
5. 放弃传统 K 线分析思维，完全按缠论定义处理
6. 划分感觉"别扭"→ 检查是否违反结合律
7. 进入 C 段时提高警觉（小转大可能发生）
