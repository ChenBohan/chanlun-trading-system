## 1. 系统总览

本系统是一个**纯缠论驱动**的指数ETF轮动交易系统。核心思想是在8只指数（6只A股宽基 + 2只跨市场）中，通过缠论九维度量化评分选出结构最优的指数，然后用缠论买卖点确认交易时机。所有评分维度均来自缠论理论体系，不使用动量、量价等非缠论指标。

**入口脚本**：`scripts/index_trading_system.py`，执行 `full_update()` 按以下6步流水线完成一次完整更新：

```
[1/6] 数据获取 → [2/6] 缠论分析 → [3/6] 行情性质 → [4/6] 信号记录 → [5/6] 轮动评分 → [6/6] 报告生成
```

**三级联立模式**：日线（定方向）→ 120分钟（定买卖点）→ 30分钟（精确择时）。级别倍率：30分钟 ×4→ 120分钟 ×2→ 日线，符合缠论标准递推关系。

## 3. 数据获取流程

`fetch_all_index_data()` 为每个指数获取4组数据：

1. **指数日线** — `fetch_index_kline(code, "101", beg, end)`，用于展示指数点位
2. **ETF日线** — `fetch_kline(etf_code, "101", beg, end)`，用于缠论日线分析（方向级别）
3. **ETF 60分钟线** — `fetch_kline(etf_code, "60", beg, end)`，通过 `_aggregate_to_120min()` 合成为120分钟K线（操作级别）
4. **ETF 30分钟线** — `fetch_kline(etf_code, "30", beg, end)`，用于精确择时

**120分钟数据合成**：由于新浪/东方财富API不支持原生120分钟周期，系统获取60分钟数据后按交易日分组，每两根连续60分钟K线合并为一根120分钟K线（上午半场 + 下午半场，每天恰好2根）。

数据来源：新浪财经API（主）/ 东方财富API（备）（通过 `fetch_data.py`），数据起始日期由配置文件 `settings.data_start` 控制（默认 `20250101`）。

数据保存为 Markdown 表格格式，存放在 `indices/{code}_{name}/data/` 目录下（日线、120分钟线、30分钟线各一个文件）。

## 4. 缠论分析引擎

缠论分析引擎 `chanlun_engine.py` 是系统的核心，对每个指数的ETF数据进行**多级别分析**（日线 + 30分钟）。

### 4.1 处理流水线（8步）

```
[1] K线解析 → [2] MACD计算 → [3] 包含处理 → [4] 分型识别 → [5] 笔划分 → [6] 笔MACD面积 → [7] 中枢构建 → [8] 背驰判断+买卖点识别
```

### 4.2 包含处理

相邻K线若存在包含关系（一根K线的高低点完全被另一根覆盖），按方向合并：
- **上升方向**：取高点的最大值、低点的最大值（向上合并）
- **下降方向**：取高点的最小值、低点的最小值（向下合并）

这是缠论的标准K线处理，目的是消除噪音、识别有效分型。

### 4.3 分型与笔

- **顶分型**：中间合并K线的高点高于前后两根（局部高点）
- **底分型**：中间合并K线的低点低于前后两根（局部低点）
- **笔**：连接相邻的顶分型和底分型，要求中间至少间隔4根合并K线
- 同类型分型取极值（顶取更高、底取更低），确保笔的有效性

### 4.4 中枢构建

中枢是缠论的核心概念——价格在一段时间内反复运行的价格区间。

**构建逻辑**：取连续3笔的价格范围取交集：
- **ZG（上沿）** = min(3笔各自的最高点)
- **ZD（下沿）** = max(3笔各自的最低点)
- 当 ZD < ZG 时，中枢有效
- 后续笔若仍在 ZD~ZG 区间内穿越，则延伸中枢
- 离开区间的笔标志中枢结束

中枢还记录 **GG**（中枢范围最高价）和 **DD**（中枢范围最低价）。

### 4.5 走势类型判断

```
if 中枢数 == 0: 看最后一笔方向
if 中枢数 == 1: 看价格相对中枢位置（上方运行/下方运行/盘整）
if 中枢数 >= 2:
    后中枢.ZD > 前中枢.ZG → 上涨趋势（中枢上移）
    后中枢.ZG < 前中枢.ZD → 下跌趋势（中枢下移）
    其他 → 盘整（中枢重叠）
```

### 4.6 MACD背驰检测

**趋势背驰**（a+A+b+B+c 结构）：
- 在有至少2个中枢的走势中，比较离开最后一个中枢的段（c段）与进入第一个中枢前的段（a段）的MACD面积
- 若 c段面积 < a段面积，说明推动力度衰减，背驰成立

**盘整背驰**：
- 在同一个中枢内，比较相邻两次同方向离开中枢的MACD面积
- 后一次面积更小，则盘整背驰成立

### 4.7 三类买卖点识别

| 类型 | 条件 | 含义 | 置信度 |
|------|------|------|--------|
| **一买** | 下跌趋势背驰，c段MACD面积 < a段 | 趋势即将反转的第一个买点 | ratio<0.6=高，否则=中 |
| **一卖** | 上涨趋势背驰，c段MACD面积 < a段 | 趋势即将反转的第一个卖点 | ratio<0.6=高，否则=中 |
| **二买** | 一买后第一次回调的低点不破一买价 | 一买确认后的加仓点 | 低点>1买价×1.02=高 |
| **二卖** | 一卖后第一次反弹的高点不破一卖价 | 一卖确认后的减仓点 | 高点<1卖价×0.98=高 |
| **三买** | 向上离开中枢后回试，低点不破中枢ZG | 中枢升级确认，强势买点 | 固定=高 |
| **三卖** | 向下离开中枢后回抽，高点不破中枢ZD | 中枢跌落确认，必须卖出 | 固定=高 |

## 5. 纯缠论轮动评分体系（v3 九维度）

`compute_chanlun_scores()` 为每个指数计算综合评分，所有维度**完全来自缠论理论体系**。v3 版本在 v2 的5个核心维度基础上，新增4个理论增强维度，并引入行情性质判断。

### 5.0 行情性质判断（图解缠论3 §3.2）

在评分之前，系统首先通过沪深300（市场基准）的缠论走势判断当前行情性质。
来源：图解缠论3 §3.2「行情性质与策略」。

```
标准顺序：① 行情性质 → ② 主线板块 → ③ 板块内品种 → ④ 技术买卖点

行情性质判定（基于沪深300日线+30分钟走势）：
  日线上涨趋势 + 30分钟上涨 → 牛市（轮动收益有限，系数×0.7）
  日线上涨趋势                → 牛市初中期（系数×0.8）
  日线下跌趋势 + 30分钟下跌 → 熊市（空仓为主，系数×0.3）
  日线下跌趋势                → 熊市（系数×0.5）
  日线盘整/其他               → 震荡市（轮动最有效，系数×1.0）

rotation_multiplier 作用于最终评分，在熊市降低轮动权重（建议空仓）。
```

**核心洞察**：轮动策略在震荡市最有效——资金不足以推动全面牛市，只能结构性地在指数间切换。全面牛市时齐涨齐跌，轮动收益有限；全面熊市时应空仓，轮动无意义。

### 5.1 核心五维度评分（75%）

**维度1：走势类型分（Trend Score）**，权重 15%

基于缠论走势类型判定（108课 §1.5），日线权重60%、30分钟权重40%。

```
走势类型映射：
  上涨趋势 → +10
  盘整（上方运行）→ +5
  盘整（内部）→ 0
  盘整（下方运行）→ -5
  下跌趋势 → -10

d1_trend = daily_trend_score × 0.6 + min30_trend_score × 0.4
```

**维度2：买卖点信号分（Signal Score）**，权重 18%

基于缠论三类买卖点（108课 §二，图解缠论 §二），汇总日线+30分钟两个级别的所有信号。

```
信号权重：
  一买/一卖 → ±10（最强信号：趋势反转）
  二买/二卖 → ±7（确认信号）
  三买/三卖 → ±5（中枢突破/跌破）
  盘整买卖点 → 对应权重 × 0.6

d2_signal = clamp(Σ(各信号权重), -20, +20)
```

**维度3：MACD动力学分**，权重 15%

基于缠论的MACD应用——**防狼术**（0轴判断）和**柱状体方向**（背驰辅助）。
来源：108课 §三「背驰与MACD辅助」、土匪注解版「MACD实战技巧」。

```
防狼术：
  DIF > 0 → +5（多头区间，可做多）
  DIF < 0 → -5（空头区间，防狼术警告）

柱状体方向：
  红柱扩大 → +3（上涨动能增强）
  绿柱扩大 → -3（下跌动能增强）

d3_macd = (daily_macd_score × 0.6 + min30_macd_score × 0.4)
```

**维度4：中枢结构分**，权重 12%

基于缠论中枢位置关系（108课 §1.4）和中枢上移/下移判断。

```
价格相对中枢位置：
  最新价 > ZG（中枢上方）→ +5
  最新价 < ZD（中枢下方）→ -5
  最新价在ZD~ZG内 → 0

中枢递进方向：
  最近两个中枢上移（后ZD > 前ZG）→ +5
  最近两个中枢下移（后ZG < 前ZD）→ -5

d4_hub = 位置分 + 递进分
```

**维度5：级别共振分**，权重 15%

基于缠论多级别联立分析（图解缠论3「立体操盘」、缠论辅导「当下与级别」）。

```
共振规则：
  日线上涨 + 30分钟上涨 → +10（完美共振）
  日线下跌 + 30分钟下跌 → -10（完美共振向下）
  日线上涨 + 30分钟下跌 → -2（级别矛盾）
    但若30分钟有买点信号 → +3（矛盾中有转机）
  日线下跌 + 30分钟上涨 → -3
  日线上涨 + 30分钟盘整 → +5

d5_resonance = 共振得分
```

### 5.2 理论增强四维度（25%）

**维度6：买卖点完成进度分（BSP Progress）**，权重 10%

来源：图解缠论2 §4.3「买卖点次序轮动」——谁先完成三买谁先拉主升。

```
核心逻辑：评估每个指数在买卖点周期中的位置。
  最近出现三买 → +10（最强，已完成升级确认）
  最近出现二买 → +7（确认阶段）
  最近出现一买 → +4（刚启动）
  最近出现一卖 → -4（趋势转弱）
  最近出现三卖 → -10（中枢跌破）

日线买点权重 0.7，30分钟买点权重 0.3。
若日线同时出现一买+二买或二买+三买，额外加分（序列完整性奖励）。

d6_bsp_progress = clamp(进度得分, -15, +15)
```

**维度7：逆市抗跌分（Anti-drop Score）**，权重 5%

来源：缠论辅导 §5.1——「调整中关注逆市不跌品种作下一轮候选」。

```
逻辑：当沪深300（基准）近10日下跌时，对比各指数的相对强度。
  基准下跌而该指数明显抗跌（相对强度 > +3%）→ +5
  基准下跌该指数也大跌（相对强度 < -3%）→ -3
  基准未下跌 → 该维度不计分（0）

d7_anti_drop = 相对强度映射
```

**维度8：均线强弱分（MA Strength Score）**，权重 5%

来源：土匪注解 §4.5「均线9类分档轮动」+ 图解缠论2 §4.2「均线板块强弱指标」。

```
逻辑：按价格征服的均线档位评分（MA5 → MA250 逐级递增）。
  站上MA5    → +1.0
  站上MA10   → +1.5
  站上MA20   → +2.0
  站上MA60   → +2.5
  站上MA120  → +3.0
  站上MA250  → +3.5（年线以上，最强档）
  跌破则对称扣分。
  
  附加：MA5 方向向上 → +1.5，向下 → -1.0

d8_ma_strength = clamp(均线得分, -15, +15)
```

**维度9：冠军修正分（Champion Adjustment）**，权重 5%

来源：图解缠论3 §3.4「基钦周期」——上一波涨幅最大的板块，下一轮往往偏弱。

```
逻辑：查阅最近4次轮动历史，统计该指数排名第一/最后的次数。
  连续≥3次排名第一 → -3.0（冠军疲劳惩罚）
  连续≥2次排名第一 → -1.5
  连续≥3次排名最后 → +2.0（落后反弹潜力）
  连续≥2次排名最后 → +1.0

d9_champion_adj = 修正得分
```

### 5.3 综合评分

```
raw_score = (d1×0.15 + d2×0.18 + d3×0.15 + d4×0.12 + d5×0.15 +
             d6×0.10 + d7×0.05 + d8×0.05 + d9×0.05)

final_score = raw_score × index_weight × rotation_multiplier
```

其中：
- `index_weight` 是指数配置权重（核心指数1.0，卫星指数0.8）
- `rotation_multiplier` 来自行情性质判断（震荡市1.0，牛市0.7~0.8，熊市0.3~0.5）

### 5.4 排序逻辑

按 `final_score` 从高到低排序，得到轮动排名。

## 6. 信号跟踪系统

`IndexSignalTracker` 为每个指数维护信号历史（`tracking/signals.jsonl`）：

## 8. 操作策略规则

### 8.1 仓位管理

| 综合分区间 | 信号条件 | 建议仓位 |
|-----------|---------|---------|
| > 5 且有缠论买点 | 强势 + 信号确认 | 40%~60% |
| 0 ~ 5 | 趋势向好但动量偏弱 | 20%~30%（轻仓观察） |
| < 0 | 弱势 | 空仓观望 |

### 8.2 调仓频率

- **分析频率**：每周末运行一次 `python3 index_trading_system.py`
- **调仓频率**：月度调仓（避免过度交易）
- **信号触发**：缠论买卖点出现时，可在下一交易日执行

### 8.3 止损规则

- 跌破最近中枢下沿 ZD → 减半仓
- 跌破前低 → 清仓
- 三卖信号出现 → 必须清仓

### 8.4 大小盘轮动

系统通过类别标签实现大小盘轮动判断：
- **大盘价值**：沪深300、上证50
- **中小盘成长**：中证500、中证1000
- **成长创新**：创业板指、科创50

当综合分最高的指数从大盘切换到中小盘（或反之），标志着市场风格轮动。

## 9. 用户画像适配

系统设计面向以下用户场景：
- **上班族**：不能盯盘，需要收盘后分析
- **操作级别**：日线（ETF波动小，日线级别最适合）
- **辅助级别**：30分钟线（用于精确择时）
- **分析频率**：每周末一次
- **执行方式**：周末分析 → 周一开盘执行
