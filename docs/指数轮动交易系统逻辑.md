## 1. 系统总览

本系统是一个**纯缠论驱动**的A股宽基指数ETF轮动交易系统。核心思想是在6只宽基指数中，通过缠论五维度量化评分选出结构最优的指数，然后用缠论买卖点确认交易时机。所有评分维度均来自缠论理论体系，不使用动量、量价等非缠论指标。

**入口脚本**：`scripts/index_trading_system.py`，执行 `full_update()` 按以下5步流水线完成一次完整更新：

```
[1/5] 数据获取 → [2/5] 缠论分析 → [3/5] 信号记录 → [4/5] 轮动评分 → [5/5] 报告生成
```

## 3. 数据获取流程

`fetch_all_index_data()` 为每个指数获取3组数据：

1. **指数日线** — `fetch_index_kline(code, "101", beg, end)`，用于展示指数点位
2. **ETF日线** — `fetch_kline(etf_code, "101", beg, end)`，用于缠论分析和轮动评分（ETF价格可直接交易）
3. **ETF 30分钟线** — `fetch_kline(etf_code, "30", beg, end)`，用于小级别缠论精确择时

数据来源：新浪财经API（主）/ 东方财富API（备）（通过 `fetch_data.py`），数据起始日期由配置文件 `settings.data_start` 控制（默认 `20250101`）。

数据保存为 Markdown 表格格式，存放在 `indices/{code}_{name}/data/` 目录下。

## 4. 缠论分析引擎

缠论分析引擎 `chanlun_engine.py` 是系统的核心，对每个指数的ETF数据进行**多级别分析**（日线 + 30分钟）。

### 4.1 处理流水线（8步）

```
[1] K线解析 → [2] MACD计算 → [3] 包含处理 → [4] 分型识别 → [5] 笔划分 → [6] 笔MACD面积 → [7] 中枢构建 → [8] 背驰判断+买卖点识别
```

### 4.2 包含处理

相邻K线若存在包含关系（一根K线的高低点完全被另一根覆盖），按方向合并：
- **上升方向**：取高点的最大值、低点的最大值（向上合并）
- **下降方向**：取高点的最小值、低点的最小值（向下合并）

这是缠论的标准K线处理，目的是消除噪音、识别有效分型。

### 4.3 分型与笔

- **顶分型**：中间合并K线的高点高于前后两根（局部高点）
- **底分型**：中间合并K线的低点低于前后两根（局部低点）
- **笔**：连接相邻的顶分型和底分型，要求中间至少间隔4根合并K线
- 同类型分型取极值（顶取更高、底取更低），确保笔的有效性

### 4.4 中枢构建

中枢是缠论的核心概念——价格在一段时间内反复运行的价格区间。

**构建逻辑**：取连续3笔的价格范围取交集：
- **ZG（上沿）** = min(3笔各自的最高点)
- **ZD（下沿）** = max(3笔各自的最低点)
- 当 ZD < ZG 时，中枢有效
- 后续笔若仍在 ZD~ZG 区间内穿越，则延伸中枢
- 离开区间的笔标志中枢结束

中枢还记录 **GG**（中枢范围最高价）和 **DD**（中枢范围最低价）。

### 4.5 走势类型判断

```
if 中枢数 == 0: 看最后一笔方向
if 中枢数 == 1: 看价格相对中枢位置（上方运行/下方运行/盘整）
if 中枢数 >= 2:
    后中枢.ZD > 前中枢.ZG → 上涨趋势（中枢上移）
    后中枢.ZG < 前中枢.ZD → 下跌趋势（中枢下移）
    其他 → 盘整（中枢重叠）
```

### 4.6 MACD背驰检测

**趋势背驰**（a+A+b+B+c 结构）：
- 在有至少2个中枢的走势中，比较离开最后一个中枢的段（c段）与进入第一个中枢前的段（a段）的MACD面积
- 若 c段面积 < a段面积，说明推动力度衰减，背驰成立

**盘整背驰**：
- 在同一个中枢内，比较相邻两次同方向离开中枢的MACD面积
- 后一次面积更小，则盘整背驰成立

### 4.7 三类买卖点识别

| 类型 | 条件 | 含义 | 置信度 |
|------|------|------|--------|
| **一买** | 下跌趋势背驰，c段MACD面积 < a段 | 趋势即将反转的第一个买点 | ratio<0.6=高，否则=中 |
| **一卖** | 上涨趋势背驰，c段MACD面积 < a段 | 趋势即将反转的第一个卖点 | ratio<0.6=高，否则=中 |
| **二买** | 一买后第一次回调的低点不破一买价 | 一买确认后的加仓点 | 低点>1买价×1.02=高 |
| **二卖** | 一卖后第一次反弹的高点不破一卖价 | 一卖确认后的减仓点 | 高点<1卖价×0.98=高 |
| **三买** | 向上离开中枢后回试，低点不破中枢ZG | 中枢升级确认，强势买点 | 固定=高 |
| **三卖** | 向下离开中枢后回抽，高点不破中枢ZD | 中枢跌落确认，必须卖出 | 固定=高 |

## 5. 纯缠论轮动评分体系

`compute_chanlun_scores()` 为每个指数计算综合评分，所有维度**完全来自缠论理论**。

### 5.1 五维度评分

**维度1：走势类型分（Trend Score）**，权重 20%

基于缠论走势类型判定（108课 §1.5），日线权重60%、30分钟权重40%。

```
走势类型映射：
  上涨趋势 → +10
  盘整（上方运行）→ +5
  盘整（内部）→ 0
  盘整（下方运行）→ -5
  下跌趋势 → -10

d1_trend = daily_trend_score × 0.6 + min30_trend_score × 0.4
```

**维度2：买卖点信号分（Signal Score）**，权重 25%

基于缠论三类买卖点（108课 §二，图解缠论 §二），汇总日线+30分钟两个级别的所有信号。

```
信号权重：
  一买/一卖 → ±10（最强信号：趋势反转）
  二买/二卖 → ±7（确认信号）
  三买/三卖 → ±5（中枢突破/跌破）
  盘整买卖点 → 对应权重 × 0.6

d2_signal = clamp(Σ(各信号权重), -20, +20)
```

**维度3：MACD动力学分**，权重 20%

基于缠论的MACD应用——**防狼术**（0轴判断）和**柱状体方向**（背驰辅助）。
来源：108课 §三「背驰与MACD辅助」、土匪注解版「MACD实战技巧」。

```
防狼术：
  DIF > 0 → +5（多头区间，可做多）
  DIF < 0 → -5（空头区间，防狼术警告）

柱状体方向：
  红柱扩大 → +3（上涨动能增强）
  绿柱扩大 → -3（下跌动能增强）

d3_macd = (daily_macd_score × 0.6 + min30_macd_score × 0.4)
```

**维度4：中枢结构分**，权重 15%

基于缠论中枢位置关系（108课 §1.4）和中枢上移/下移判断。

```
价格相对中枢位置：
  最新价 > ZG（中枢上方）→ +5
  最新价 < ZD（中枢下方）→ -5
  最新价在ZD~ZG内 → 0

中枢递进方向：
  最近两个中枢上移（后ZD > 前ZG）→ +5
  最近两个中枢下移（后ZG < 前ZD）→ -5

d4_hub = 位置分 + 递进分
```

**维度5：级别共振分**，权重 20%

基于缠论多级别联立分析（图解缠论3「立体操盘」、缠论辅导「当下与级别」）。

```
共振规则：
  日线上涨 + 30分钟上涨 → +10（完美共振）
  日线下跌 + 30分钟下跌 → -10（完美共振向下）
  日线上涨 + 30分钟下跌 → -2（级别矛盾）
    但若30分钟有买点信号 → +3（矛盾中有转机）
  日线下跌 + 30分钟上涨 → -3
  日线上涨 + 30分钟盘整 → +5

d5_resonance = 共振得分
```

### 5.2 综合评分

```
final_score = (d1×0.20 + d2×0.25 + d3×0.20 + d4×0.15 + d5×0.20) × index_weight
```

其中 `index_weight` 是指数配置权重（核心指数1.0，卫星指数0.8）。

### 5.3 排序逻辑

按 `final_score` 从高到低排序，得到轮动排名。

### 5.4 与旧评分体系的对比

| 项目 | 旧体系（v1） | 新体系（v2） |
|------|-------------|-------------|
| 动量分（窗口涨幅） | ✅ 权重40% | ❌ 移除（非缠论） |
| 量能分（成交量比） | ✅ 权重30% | ❌ 移除（非缠论） |
| MACD分（DIF方向） | ✅ 权重30% | → 改为缠论防狼术+柱状体（权重20%） |
| 缠论加分 | 附加项 | → 拆分为走势+信号+中枢+共振（共80%） |
| 理论纯度 | 混合 | **100%缠论** |

## 6. 信号跟踪系统

`IndexSignalTracker` 为每个指数维护信号历史（`tracking/signals.jsonl`）：

- 每次缠论分析识别出新的买卖点，自动去重后追加记录
- 信号记录包含：日期、类型、价格、级别、置信度、描述、状态（active/resolved）
- 支持查询活跃信号和历史信号

## 8. 操作策略规则

### 8.1 仓位管理

| 综合分区间 | 信号条件 | 建议仓位 |
|-----------|---------|---------|
| > 5 且有缠论买点 | 强势 + 信号确认 | 40%~60% |
| 0 ~ 5 | 趋势向好但动量偏弱 | 20%~30%（轻仓观察） |
| < 0 | 弱势 | 空仓观望 |

### 8.2 调仓频率

- **分析频率**：每周末运行一次 `python3 index_trading_system.py`
- **调仓频率**：月度调仓（避免过度交易）
- **信号触发**：缠论买卖点出现时，可在下一交易日执行

### 8.3 止损规则

- 跌破最近中枢下沿 ZD → 减半仓
- 跌破前低 → 清仓
- 三卖信号出现 → 必须清仓

### 8.4 大小盘轮动

系统通过类别标签实现大小盘轮动判断：
- **大盘价值**：沪深300、上证50
- **中小盘成长**：中证500、中证1000
- **成长创新**：创业板指、科创50

当综合分最高的指数从大盘切换到中小盘（或反之），标志着市场风格轮动。

## 9. 用户画像适配

系统设计面向以下用户场景：
- **上班族**：不能盯盘，需要收盘后分析
- **操作级别**：日线（ETF波动小，日线级别最适合）
- **辅助级别**：30分钟线（用于精确择时）
- **分析频率**：每周末一次
- **执行方式**：周末分析 → 周一开盘执行
