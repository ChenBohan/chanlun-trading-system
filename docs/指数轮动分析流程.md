# 缠论交易系统 v2 — 分析流程

> 三级联立：日线（方向）→ 30分钟（买卖点）→ 5分钟（择时）
> 覆盖 8 只宽基 ETF，纯 Python 标准库，零外部依赖

## 模块 1：数据拉取 (`src/data_fetcher.py`)

### 职责

从金融 API 拉取 K 线数据，保存为 CSV。

### 数据源

| 优先级 | 数据源 | API | 特点 |
|--------|--------|-----|------|
| 主 | 新浪财经 | `money.finance.sina.com.cn` | 稳定，无 IP 限制，最多 2000 根 |
| 备 | 东方财富 | `push2his.eastmoney.com` | 字段丰富，可能封禁非浏览器 IP |

### 数据流

```
config/index_watchlist.json    # 8只指数+ETF配置
         │
         ▼
  load_index_watchlist()       # 解析配置 → [IndexConfig]
         │
         ▼
  fetch_all_indices()          # 遍历 8×3=24 组
    ├── fetch_kline(etf_code, "daily")
    ├── fetch_kline(etf_code, "30min")
    └── fetch_kline(etf_code, "5min")
         │                       每组：新浪优先 → 失败切东财 → 指数退避重试
         ▼
  [FetchResult]                # daily/min30/min5 三组 KlineBar 列表
         │
         ▼
  save_fetch_results()         # 写入 CSV
         │
         ▼
  data/{etf_code}_{etf_name}/
    ├── daily.csv              # 日线 (~300根)
    ├── 30min.csv              # 30分钟 (~1500根)
    └── 5min.csv               # 5分钟 (~1500根)
```

### CSV 格式

```
datetime,open,close,high,low,volume,amount,change_pct,change
2025-01-02,3.844,3.838,3.853,3.812,328025789,0.0,0.0,0.0
2025-01-03,3.838,3.816,3.846,3.813,331174050,0.0,-0.5732,-0.022
```

### 关键数据结构

```python
@dataclass
class KlineBar:
    datetime: str       # "2025-01-02" 或 "2025-01-02 10:00:00"
    open: float
    close: float
    high: float
    low: float
    volume: int
    amount: float
    change_pct: float
    change: float

@dataclass
class FetchResult:
    index_cfg: IndexConfig
    daily: list[KlineBar]     # 日线数据
    min30: list[KlineBar]     # 30分钟数据
    min5:  list[KlineBar]     # 5分钟数据
    errors: list[str]
```

## 模块 2：缠论分析引擎 (`src/chanlun_engine.py`)

### 职责

读取 CSV K 线数据，执行完整缠论分析流水线，输出结构化分析结果。

### 分析流水线

```
  CSV 文件 ──→ load_bars_from_csv() ──→ [RawBar]
                                           │
               analyze(bars, level)        │
          ┌────────────────────────────────┘
          │
  [1] compute_macd()              # EMA12/26 → DIF → DEA → MACD柱
          │
  [2] inclusion_processing()      # K线包含处理（向上取高高，向下取低低）
          │                         → [MergedBar]
  [3] find_fractals()             # 顶底分型识别
          │                         → [Fractal]
  [4] find_strokes()              # 笔划分（分型间>=4根独立K线）
          │                         → [Stroke]
  [5] compute_stroke_macd()       # 每笔的 MACD 面积
          │
  [6] find_segments()             # 线段划分（特征序列法，108课§67课）
          │                         → [Segment]
  [7] find_hubs()                 # 笔中枢（3笔重叠区间）
      find_seg_hubs()             # 线段中枢（3线段重叠）
          │                         → [Hub], [SegHub]
  [8] determine_trend()           # 走势类型判断
          │
  [9] check_trend_divergence()    # 趋势背驰（a+A+b+B+c结构）
      check_consolidation_div()   # 盘整背驰（同一中枢连续出入减弱）
          │
  [10] find_buy_sell_points()     # 三类买卖点
          │
          ▼
     AnalysisResult               # 完整分析输出
```

### 三类买卖点规则

| 类型 | 代码 | 触发条件 | 置信度 |
|------|------|----------|--------|
| 一买 | 1B | 下跌趋势背驰：c段面积 < a段面积 | c/a < 0.6 → 高 |
| 一卖 | 1S | 上涨趋势背驰：c段面积 < a段面积 | c/a < 0.6 → 高 |
| 二买 | 2B | 一买后首次回调不破一买价 | 回调低点 > 一买价×1.02 → 高 |
| 二卖 | 2S | 一卖后首次反弹不破一卖价 | 反弹高点 < 一卖价×0.98 → 高 |
| 三买 | 3B | 离开中枢后回试不破 ZG | 直接判定 → 高 |
| 三卖 | 3S | 离开中枢后回抽不破 ZD | 直接判定 → 高 |
| 盘整买点 | PB | 盘整背驰（向下出中枢减弱） | 当次/前次 < 0.7 → 中 |
| 盘整卖点 | PS | 盘整背驰（向上出中枢减弱） | 当次/前次 < 0.7 → 中 |

### 关键数据结构

```python
@dataclass
class AnalysisResult:
    level: str                              # "daily" / "30min" / "5min"
    raw_bars: list[RawBar]                  # 原始K线（含MACD）
    merged_bars: list[MergedBar]            # 包含处理后
    fractals: list[Fractal]                 # 顶底分型
    strokes: list[Stroke]                   # 笔
    segments: list[Segment]                 # 线段
    hubs: list[Hub]                         # 笔中枢
    seg_hubs: list[SegHub]                  # 线段中枢
    trend: str                              # 走势类型
    divergences: list[dict]                 # 背驰信号
    buy_sell_points: list[BuySellPoint]     # 买卖点
```

### 3b. HTML 仪表盘 (`src/visualize.py`)

```python
from src.visualize import generate_dashboard
generate_dashboard()   # → reports/dashboard.html
```

功能：
- 8 个指数 Tab 切换
- 每个指数 3 级别切换（日线 / 30分钟 / 5分钟）
- ECharts 交互式 K 线图：
  - 蜡烛图（红涨绿跌）
  - 笔（黄色连线 + S编号）
  - 线段（紫色粗线 + D编号）
  - 笔中枢（蓝色半透明矩形）
  - 线段中枢（橙色矩形）
  - 买卖点标记（三角形 + 标签）
  - MACD 柱状图 + DIF/DEA 线
  - a+A+b+B+c 趋势背驰结构标注
- 底部信号面板（表格：日期、位置、类型、价格、置信度、判断依据、面积对比）
- 全数据内嵌，单 HTML 文件可离线打开

## 使用方式

### CLI 命令

```bash
# 完整流水线：拉取 → 分析 → 生成仪表盘
python main.py run

# 仅拉取数据
python main.py fetch
python main.py fetch --beg 20260101 --delay 2.0

# 分析单个 CSV 文件
python main.py analyze data/510300_沪深300ETF/daily.csv --level daily
python main.py analyze data/510300_沪深300ETF/30min.csv --level 30min

# 仅生成仪表盘（用现有数据）
python main.py dashboard
python main.py dashboard --output /tmp/my_dashboard.html
```

### Python API

```python
from src import fetch_kline, analyze, format_report, generate_dashboard

# 拉取单标的
bars = fetch_kline("510300", "daily", market="SH")

# 分析
from src.chanlun_engine import RawBar, analyze
raw_bars = [RawBar(idx=i, dt=b.datetime, open=b.open, close=b.close,
                   high=b.high, low=b.low, volume=b.volume)
            for i, b in enumerate(bars)]
result = analyze(raw_bars, "daily")

# 文本报告
print(format_report(result))

# 或直接从 CSV 分析
from src import analyze_from_csv
result = analyze_from_csv("data/510300_沪深300ETF/daily.csv", "daily")
```
