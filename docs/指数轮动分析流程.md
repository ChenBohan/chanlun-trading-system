# 宽基指数轮动分析 — 标准操作流程

> 每日收盘后执行一次，或盘中需要更新时执行。
> 全流程约10秒完成（数据拉取+分析+报告生成+HTML构建）。

---

## 流程概览

```
Step 1: 运行交易系统（数据+分析+评分+报告）
  ↓
Step 2: 构建自包含HTML（K线图内嵌）
  ↓
Step 3: 检查输出（排名/信号/报告）
  ↓
Step 4: 发送移动版到手机查看
```

---

## Step 1: 运行指数交易系统

```bash
cd /home/chenbohan/github/chanlun-trading-system/scripts
python3 index_trading_system.py
```

**自动完成**：
1. 从新浪财经API拉取6大宽基指数 + ETF的日线和30分钟K线数据
2. 对每个指数运行缠论多级别分析（K线包含处理→分型→笔→中枢→走势类型→背驰→买卖点）
3. 记录买卖点信号到 `tracking/signals.jsonl`
4. 计算纯缠论五维度轮动评分
5. 生成轮动报告、各指数分析报告、分析图HTML
6. 更新 `tracking.md` 持续跟踪日志

**产出文件**：

| 文件 | 路径 | 说明 |
|------|------|------|
| 轮动分析报告 | `indices/reports/YYYYMMDD/指数轮动分析报告.md` | 综合排名+各指数技术分析 |
| 各指数分析图 | `indices/{code}_{name}/analysis/缠论分析图.html` | 个股独立K线图（日线/30分钟切换） |
| 各指数分析报告 | `indices/{code}_{name}/analysis/YYYYMMDD/缠论买卖点分析.md` | 个股详细缠论分析 |
| 轮动评分 | `indices/reports/rotation_scores.json` | 评分数据（JSON） |
| 跟踪日志 | `indices/reports/tracking.md` | 持续追踪历史结论 |
| 信号历史 | `indices/{code}_{name}/tracking/signals.jsonl` | 买卖点信号流水 |

---

## Step 2: 构建自包含HTML

```bash
python3 build_standalone_html.py YYYYMMDD
# 例如：python3 build_standalone_html.py 20260331
```

**自动完成**：
1. 从6个指数独立图表HTML中提取全部K线数据（dailyData + min30Data）
2. 内嵌Canvas渲染引擎（K线图、笔、中枢、MACD、买卖点标注）
3. 生成桌面版和移动版HTML（单文件约700KB，零外部依赖）
4. 复制到 `indices/reports/` 根目录作为latest链接

**产出文件**：

| 文件 | 路径 | 说明 |
|------|------|------|
| 桌面版分析图 | `indices/reports/YYYYMMDD/指数轮动分析图.html` | 完整版（Tab切换6个指数×2级别） |
| 移动版分析图 | `indices/reports/YYYYMMDD/指数轮动分析报告-移动版.html` | 响应式版本，可发送到手机 |

## Step 3: 检查输出

### 3.1 查看排名

终端输出中直接显示排名（`Rotation ranking`部分），或查看报告：

```bash
head -20 indices/reports/YYYYMMDD/指数轮动分析报告.md
```

### 3.2 查看关键信号

重点关注**一买/一卖**信号（趋势转折点）：

```bash
grep -r "一买\|一卖" indices/*/analysis/YYYYMMDD/缠论买卖点分析.md
```

### 3.3 查看防狼术警告

```bash
grep "防狼术\|0轴下方" indices/*/analysis/YYYYMMDD/缠论买卖点分析.md
```

### 3.4 对比前次分析

```bash
# 查看tracking.md中的历史结论对比
cat indices/reports/tracking.md
```

---

## Step 4: 发送到手机

将以下文件发送到手机即可查看完整分析：

```
indices/reports/YYYYMMDD/指数轮动分析报告-移动版.html
```

**注意**：
- 这个文件是**自包含的**，不需要其他文件
- 约700KB，包含6个指数×2级别的全部K线数据和交互式图表
- 在手机浏览器中打开即可，横屏查看效果更佳

## 常见操作场景

### 场景A：每日收盘后例行分析

```bash
cd /home/chenbohan/github/chanlun-trading-system/scripts
python3 index_trading_system.py && python3 build_standalone_html.py $(date +%Y%m%d)
```

### 场景B：盘中实时更新（获取最新K线）

同场景A，系统自动拉取最新数据。同一天多次运行会覆盖当日报告。

### 场景C：查看特定指数详细分析

```bash
# 例如查看上证50
cat indices/000016_上证50/analysis/$(date +%Y%m%d)/缠论买卖点分析.md
# 或在浏览器中打开
open indices/000016_上证50/analysis/缠论分析图.html
```

### 场景D：查看历史信号

```bash
cat indices/000016_上证50/tracking/signals.jsonl | tail -5
```

## 评分体系速查

| 维度 | 权重 | 来源 | 正分含义 | 负分含义 |
|------|------|------|---------|---------|
| 走势分类 | 20% | 日线+30分钟走势类型 | 上涨趋势 | 下跌趋势 |
| 信号强度 | 25% | 三类买卖点加权 | 有买点/无卖点 | 有卖点/无买点 |
| MACD动力学 | 20% | 防狼术(0轴)+柱方向 | 红柱+0轴上方 | 绿柱+0轴下方 |
| 中枢结构 | 15% | 价格vs中枢位置 | 中枢上方 | 中枢下方 |
| 级别共振 | 20% | 多级别信号一致性 | 日线30分钟同向 | 级别矛盾 |
