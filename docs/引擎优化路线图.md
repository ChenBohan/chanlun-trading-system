### P1 — 重要优化（核心价值提升）

#### ~~P1.1 多级别联立/共振~~ ✅ 已完成

- **来源**: 108课 §3.4 / 图解缠论2 §3.5 / 图解缠论3 §1.1 / 土匪注解 §1.3
- **已实现**: `synthesize_multi_level()` → 三级别联立分析
- **核心功能**:
  - 方向一致性判断（三级共振/部分一致/大小分歧）
  - 跨级别共振检测（同日同方向信号匹配）
  - 大级别环境增强（日线趋势+中枢位置→小级别信号置信度调整）
  - 日线阶段判断（初中段/末段→影响小级别背驰力度解读）
  - 整体倾向评估 + 操作建议
- **数据结构**: `MultiLevelSynthesis` dataclass
- **展示**: `format_synthesis_report()` 文字报告 + HTML dashboard 联立面板

#### ~~P1.2 MACD 多维度验证~~ ✅ 已完成

- **已实现**: 三维度背驰验证系统
  1. ✅ 柱面积缩小 (`area_diverged`)
  2. ✅ DIF极值不创新高/新低 (`dif_diverged`)
  3. ✅ 柱峰值（最大值）缩短 (`hist_peak_diverged`)

### P2 — 进阶优化（策略精细化）

#### ~~P2.1 中枢演化分类~~ ✅ 已完成

- **来源**: 108课 §1.4 / 缠论解析 场景B / 图解缠论2 §2.2-2.4
- **已实现**: `classify_hub_evolution()` + `classify_seg_hub_evolution()`
- **三种演化**:
  - **延伸**: 单中枢笔数 ≥ 5，围绕同一中枢长期震荡 → 高抛低吸做差价
  - **新生（上/下）**: 相邻中枢 [DD,GG] 不重叠 → 趋势确认，持仓/回避
  - **扩展**: 相邻中枢 [DD,GG] 重叠 → 升级为更大级别中枢，按盘整处理
- **字段**: `Hub.evolution_type` / `SegHub.evolution_type`
- **展示**: 文字报告含演化标签+操作建议；HTML dashboard 中枢标签含颜色区分（延伸=灰、新生上=绿、新生下=红、扩展=黄）

#### ~~P2.2 区间套精确定位~~ ✅ 已完成

- **来源**: 108课 §四 / 缠论解析 场景D / 图解缠论2 §1.2
- **问题**: 当日线检测到疑似背驰段时，应在 30 分钟内找更精确的背驰点，再在 5 分钟定位
- **实现方案**: 集成于 `synthesize_multi_level()` 多级别联立框架
  1. `_div_time_range()` — 提取背驰段时间窗口
  2. `_find_divs_in_range()` / `_find_bsp_in_range()` — 在时间窗口内搜索更小级别的背驰和买卖点
  3. `find_interval_nests()` — 逐层下钻构建嵌套链（日线→30分→5分）
  4. 输出 `IntervalNest` 数据结构，含精确进出价格和时间
- **数据结构**: `IntervalNest`（big_level/mid_level/small_level, precision_price/precision_dt, depth 1~3）
- **输出**: 文字报告表格展示各层级定位；HTML dashboard 卡片式展示含深度星级
- **验证**: 沪深300ETF 检出 4 个日线背驰段，其中 2 个完成三级嵌套（depth=3）

#### ~~P2.3 二买强弱分类~~ ✅ 已完成

- **来源**: 108课 §2.4
- **三种强弱**:
  1. **最强 (strongest)**：二买+三买合一 — 回抽价 > 中枢 ZG（二买三卖对称：回抽价 < ZD）
  2. **强势 (strong)**：二买高于一买价（回调幅度小）
  3. **标准 (standard)**：二买低于一买价但不破
- **实现**: 在 `find_buy_sell_points()` 的 Type 2 逻辑中，通过 `hub_by_idx` 查找一买所属中枢，比较回抽价与 ZG/ZD
- **字段**: `BuySellPoint.strength`（"strongest"/"strong"/"standard"）
- **展示**: 文字报告含 🔥最强/💪强势/📌标准 标签；HTML dashboard 信号表增加"强弱"列
- **注意**: 当前数据中所有 1B/1S 都在数据尾部，尚无完整回调形成 2B/2S；当新数据到来后自动生效

### P3 — 理论完备（长期目标）

#### ~~P3.1 走势完成判断~~ ✅ 已完成

- **来源**: 108课 §1.6（走势终完美）/ 图解缠论2 §1.1
- **实现**: `assess_trend_completion()` 函数，基于走势类型、中枢数、背驰、买卖点综合判断
- **三种状态**:
  - 🔄 **进行中**：趋势正常发展，无背驰信号
  - ⚠️ **疑似完成**：检测到背驰但未形成确定买卖点
  - ✅ **已确认完成**：趋势背驰 + 一买/一卖信号确认
- **判断逻辑**:
  - 趋势（上涨/下跌）：趋势背驰 → 疑似完成；+ 一买/一卖 → 已确认；3+中枢 → 后期阶段
  - 盘整：三买/三卖突破 → 已确认完成；盘整背驰 → 疑似完成
  - 中枢上方/下方运行：背驰 → 疑似完成
- **字段**: `AnalysisResult.trend_completion` (dict: status/reason/confidence/stage)
- **展示**: 文字报告走势类型下方；HTML info bar 标签+原因；联立分析表增加"走势状态"列

#### ~~P3.2 仓位建议~~ ✅ 已完成

- **来源**: 108课 §6.4 / 图解缠论 §六
- **实现**: `_apply_position_advice()` 函数，在 `find_buy_sell_points()` 中调用
- **映射规则**:
  | 买卖点 | 基础建议 | 特殊调整 |
  |--------|---------|---------|
  | 1B (一买) | 轻仓试探 1/3 | — |
  | 2B (二买) | 加至标准仓位 2/3 | strongest→满仓, strong→2/3强势 |
  | 3B (三买) | 满仓 | — |
  | PB (盘整买) | 轻仓试探 1/3 | — |
  | 1S (一卖) | 减至 1/3 或清仓 | — |
  | 2S (二卖) | 清仓 | strongest→必须清仓 |
  | 3S (三卖) | 必须清仓 | — |
  | PS (盘整卖) | 减仓 1/3 | — |
- **动态调整**: 置信度 low 时自动降仓一档
- **字段**: `BuySellPoint.position_advice` (含建议+原因)
- **展示**: 文字报告 💰 标签；HTML dashboard 信号表增加"仓位建议"列（hover 显示完整原因）

#### P3.3 新笔定义支持

- **来源**: 缠论解析 场景A（旧笔 vs 新笔）
- **问题**: 当前仅实现旧笔规则（gap≥4）。新笔规则在某些走势中更能捕捉结构
- **新笔规则**: 顶最高K与底最低K之间（不含这两根）裸数至少3根K
- **实现方案**: 在 `find_strokes()` 中添加可选参数 `stroke_mode="old"/"new"`
- **复杂度**: 低
