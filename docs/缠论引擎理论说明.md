# 缠论分析引擎 — 理论说明文档

> 本文档说明 `src/chanlun_engine.py` 中每个模块对应了缠论的哪些概念和理论，以及这些实现背后的本质思考。
> 不是 API 手册，而是帮助理解"为什么这么做"的知识地图。

---

## 总览：引擎的本质

缠论引擎做的事情，本质上是一个**从混沌到秩序的递归分解过程**：

```
原始K线 → MACD → 包含处理 → 分型 → 笔 → 线段 → 中枢 → 走势类型 → 背驰 → 买卖点
```

这条流水线的每一步都在**降低噪声、提升结构层级**。缠论的核心哲学是：市场的所有走势都可以被**完全分类**——任何走势要么是盘整，要么是趋势，没有第三种。一旦走势被分类，买卖决策就变成了机械化的逻辑推演。

背后的本质思想是**分型学**（形态学）和**动力学**的结合：
- **分型学**（形态）回答"现在是什么结构"——从K线到笔到线段到中枢，层层递归地刻画市场的空间结构
- **动力学**（力度）回答"这个结构会不会结束"——用 MACD 面积/DIF 极值/柱峰值量化多空力度的消长

引擎的终极输出——买卖点——正是这两者的交汇：**在特定结构位置，检测到力度衰竭，就是交易信号**。

---

## 一、MACD — 力度的度量工具

### 1.1 对应缠论概念

**MACD 辅助判断**（108课 §三、图解缠论 §一背驰、缠论解析 场景C）

缠论中，MACD 不是独立的交易系统，而是**背驰判断的辅助量化工具**。缠中说禅原文反复强调：MACD 的本质是用一个可计算的指标来近似刻画"走势力度"。

### 1.2 MACD 基础计算

引擎函数：`compute_macd()` — 标准 EMA(12,26,9) 参数。

MACD 由五个量逐步派生而来，每一步都在前一步基础上计算：

```
步骤 1: EMA12（12日指数移动平均线，"快均线"）
  EMA12[0] = 第一根K线的收盘价
  EMA12[i] = EMA12[i-1] × (1 - 2/13) + Close[i] × 2/13
               ≈ EMA12[i-1] × 0.846 + Close[i] × 0.154

步骤 2: EMA26（26日指数移动平均线，"慢均线"）
  EMA26[0] = 第一根K线的收盘价
  EMA26[i] = EMA26[i-1] × (1 - 2/27) + Close[i] × 2/27
               ≈ EMA26[i-1] × 0.926 + Close[i] × 0.074

步骤 3: DIF（离差值，又称"快线"/"白线"）
  DIF = EMA12 - EMA26
  含义：短期趋势偏离中期趋势的程度
  DIF > 0 → 近期多头占优，DIF < 0 → 近期空头占优

步骤 4: DEA（信号线，又称"慢线"/"黄线"）
  DEA[0] = 0
  DEA[i] = DEA[i-1] × (1 - 2/10) + DIF[i] × 2/10
             ≈ DEA[i-1] × 0.8 + DIF[i] × 0.2
  含义：DIF 的 9 日指数平滑线

步骤 5: Histogram（柱状图，又称"MACD 柱"/"红绿柱"）
  histogram = 2 × (DIF - DEA)
  含义：DIF 偏离其信号线的程度（× 2 放大显示）
  正值 = 红柱（多头动能），负值 = 绿柱（空头动能）
```

**本质**：EMA 的特点是**近期数据权重更大**——12 日 EMA 对价格变化反应快（每日权重 ~15.4%），26 日 EMA 反应慢（每日权重 ~7.4%）。DIF = 快 - 慢，反映的是"近期力量相对于中期趋势的偏离程度"。DEA 是 DIF 的平滑，histogram 是 DIF 偏离 DEA 的放大——它本质上是力度变化的二阶信号。

### 1.3 从 K 线级到笔级：三维度聚合

引擎在每根K线上计算完 MACD 后，通过 `compute_stroke_macd()` 在**笔级别**聚合为三个维度。这三个维度是背驰判断的核心数据来源。

| 维度 | 含义 | 物理类比 | 引擎字段 |
|------|------|---------|---------|
| 柱状图面积 | 一段走势的**累积动能** | 冲量（力 × 时间） | `Stroke.macd_area` |
| DIF 极值 | 一段走势的**速度峰值** | 峰值速度 | `Stroke.dif_extreme` |
| 柱状图峰值 | 一段走势的**瞬时爆发力** | 峰值加速度 | `Stroke.hist_peak` |

### 1.4 维度一：柱状图面积 — 累积动能

**定义**：一笔范围内 MACD 柱状图的累加值。

**计算策略**：**同方向优先，绝对值回退**。

| 阶段 | 计算方式 | 含义 |
|------|---------|------|
| **阶段一**（dir_area） | 只累加与笔方向一致的柱子：上涨笔→红柱，下跌笔→绿柱 | 度量"推动走势的纯力量" |
| **阶段二**（abs_area） | 对所有柱子取绝对值求和 | 备用，防止同方向面积为 0 |
| **取值** | dir_area > 0 时用 dir_area，否则用 abs_area | — |

**红绿柱混合时的处理**（以一笔向上为例）：

```
日期   柱状图    笔方向    计入 dir_area?   计入 abs_area?
D1     +0.05    ↑ 上涨    ✓ (红柱=同方向)   ✓
D2     +0.08    ↑ 上涨    ✓                 ✓
D3     -0.02    ↑ 上涨    ✗ (绿柱=反方向)   ✓ (|值|=0.02)
D4     -0.01    ↑ 上涨    ✗                 ✓ (|值|=0.01)
D5     +0.10    ↑ 上涨    ✓                 ✓
D6     +0.06    ↑ 上涨    ✓                 ✓
───────────────────────────────────────────────
dir_area = 0.05 + 0.08 + 0.10 + 0.06 = 0.29  ← 最终使用
abs_area = 0.05 + 0.08 + 0.02 + 0.01 + 0.10 + 0.06 = 0.32  ← 备用
```

**为什么忽略反方向柱子**：缠论中背驰对比的是"推动走势的力量"。一笔上涨中出现的绿柱是多头的短暂休息或空头的小反扑，不属于"推动上涨的力量"。只计入同方向柱子，才能纯粹地度量多头投入了多少能量。

**为什么需要绝对值回退**：零轴附近的弱势上涨可能全程都是绿柱（短期均线在长期均线下方但在缓慢收敛）。此时 dir_area = 0，回退到 abs_area 确保背驰比较有数据。

**优势**：面积累加了整段走势的所有 K 线信息，最稳定，不容易被单根异常 K 线干扰。

**局限**：对"持续时间"敏感。一段持续 30 天的缓慢下跌面积可能比 5 天的急跌更大，但实际力度不如后者。

**引擎代码**（`compute_stroke_macd()` 中）：

```python
for ki in range(si, min(ei + 1, len(bars))):
    v = bars[ki].macd_hist
    abs_area += abs(v)
    if (s.direction == 1 and v > 0) or (s.direction == -1 and v < 0):
        dir_area += abs(v)
s.macd_area = dir_area if dir_area > 0 else abs_area
```

### 1.5 维度二：DIF 极值 — 速度峰值

**定义**：一笔范围内 DIF 的极端值——上涨笔取 max(DIF)，下跌笔取 min(DIF)。

DIF = EMA12 - EMA26，反映短期均线相对中期均线的偏离程度。DIF 极值就是这段走势中多空力量差距**最大的那一瞬间**。

**数值示例**（一笔下跌）：

```
日期   DIF        说明
D1     -0.15      空头刚起势
D2     -0.22      力度增大
D3     -0.31      ← 极值（空头力量峰值，偏离最大）
D4     -0.28      开始收敛
D5     -0.25      进一步收敛
──────────────────
dif_extreme = min(-0.15, -0.22, -0.31, -0.28, -0.25) = -0.31
```

**背驰判定**：比较 a 段与 c 段的 DIF 极值。
- 下跌趋势：c 段 min(DIF) > a 段 min(DIF)（即"没那么负"）→ 空头峰值力量衰减 → 背驰
- 上涨趋势：c 段 max(DIF) < a 段 max(DIF)（即"没那么正"）→ 多头峰值力量衰减 → 背驰

**为什么需要这个维度**：有些走势面积差不多，但 DIF 极值一个创了新低、另一个没有——说明后者的**力量峰值**不如前者。面积维度可能漏判这种情况。在缠论原文中，这被称为"黄白线高度背驰"。

**引擎代码**：

```python
dif_vals.append(bars[ki].dif)
# ...
s.dif_extreme = max(dif_vals) if s.direction == 1 else min(dif_vals)
```

### 1.6 维度三：柱状图峰值 — 瞬时爆发力

**定义**：一笔范围内 |histogram| 的最大值（取绝对值，不区分红绿）。

histogram = 2 × (DIF - DEA) 衡量的是 DIF 偏离其信号线 DEA 的程度——本质上是**力度变化的速度**。当 DIF 急速远离 DEA 时，histogram 出现大值（"柱子变长"）。

**数值示例**（一笔上涨）：

```
日期   histogram   |值|     说明
D1     +0.03       0.03     上涨初起
D2     +0.07       0.07     力度增大
D3     +0.12       0.12     ← 峰值（最大瞬时爆发力）
D4     +0.09       0.09     开始回落
D5     +0.04       0.04     进一步减弱
D6     -0.01       0.01     短暂绿柱（同样计入|值|）
──────────────────────────
hist_peak = max(0.03, 0.07, 0.12, 0.09, 0.04, 0.01) = 0.12
```

**为什么不区分红绿**：与面积维度不同，柱峰值关心的是"最剧烈的一次脉冲有多强"，不管脉冲方向。一笔上涨中出现的大绿柱代表剧烈的多空交锋，同样是力度信息。

**背驰判定**：c 段 hist_peak < a 段 hist_peak → c 段最猛的一下也不如 a 段 → 柱峰维度背驰成立。

**为什么需要这个维度**：趋势末期的"钝化"走势中，面积可能很大、DIF 极值可能还行，但每一波的**瞬时推力**在递减。柱峰值能捕捉这种"越推越无力"的衰减模式。土匪注解（§3.1）特别强调了红/绿柱"缩短"作为独立判据。

**引擎代码**：

```python
if abs(v) > peak_hist:
    peak_hist = abs(v)
# ...
s.hist_peak = peak_hist
```

### 1.7 三维度协同判定

三个维度从不同角度刻画同一件事——"力度"：

```
                    面积（总冲量 → 累积了多少能量）
                   /
背驰 = 力度衰竭 ── DIF极值（峰值速度 → 最快跑多快）
                   \
                    柱峰值（峰值加速度 → 最猛推多猛）
```

三者的关系类似于物理学中描述运动的三个层次：

| 物理概念 | MACD 对应 | 衡量的是 |
|---------|-----------|---------|
| 位移 / 冲量 | 面积 | 一段走势投入了多少**总能量** |
| 速度 | DIF 极值 | 多空力量差距最大时的**偏离强度** |
| 加速度 | 柱峰值 | 力度变化最剧烈时的**变化速率** |

**把握度映射**：三者一致性越高，背驰判断越可靠。

| 满足维度数 | 把握度 | 含义 |
|-----------|--------|------|
| 3/3 | **high** | 总量、峰值、爆发力全面衰竭 → 高度确定的背驰 |
| 2/3 | **medium** | 大部分维度衰竭 → 较可靠的背驰 |
| 1/3 | **low** | 仅一个维度衰竭 → 可能是假背驰，需谨慎 |

**报告展示**：文字报告中以 `[面积✓ DIF✓ 柱峰✗]` 的形式标注每个维度的判定结果，买卖点描述中附带 `(N/3维)` 标签。

### 1.8 为什么是三维度而非单维度

108 课原文主要用面积对比，但图解缠论 2（§1.5）和土匪注解（§3.1）指出单维度面积有以下典型失败场景：

| 失败场景 | 现象 | 面积表现 | 真实情况 | 哪个维度能发现 |
|---------|------|---------|---------|--------------|
| **长走势 vs 短走势** | a 段 30 天缓跌，c 段 5 天急跌 | a 段面积更大 | c 段力度可能更强 | DIF 极值、柱峰值 |
| **震荡衰减型** | 面积差不多，但柱子从高到低逐渐降低 | 看不出 | 每波推力在衰减 | 柱峰值 |
| **钝化型** | DIF 在高位运行但不创新高 | 面积因时间长而很大 | 力度实际在衰竭 | DIF 极值 |

三维度验证的本质是**冗余检验降低假信号率**——只有当多个独立的度量手段都指向同一结论时，才给出高置信度的判定。这是对原始理论的工程化增强。

### 1.9 知识库中 MACD 的使用全景

MACD 在 9 本缠论知识库中的使用方式可归纳为以下几个层面：

#### 一、顺序铁律（最重要的原则）

所有知识库一致强调：**先分解走势结构，再选定比较段，最后才看 MACD**。顺序不能反。

> "先中枢与走势分析 → 选定比较段 → 再选周期看 MACD。顺序不能反，比较对象错则一切无效。"（土匪注解 §3.1 / 108课详解 §三）

引擎的实现忠实遵循这一原则：`analyze()` 函数的流水线是先完成所有结构分析（包含处理→分型→笔→线段→中枢→走势类型），然后才运行背驰检测（调用 MACD 数据）。MACD 从不参与结构的构建，只在结构确定后辅助判断力度。

#### 二、MACD 与买卖点的对应关系

108 课操作框架给出了各买卖点的 MACD 典型表现：

| 买卖点 | MACD 典型表现 | 引擎对应实现 |
|--------|-------------|-------------|
| **一买** | 0轴下绿柱面积背驰（c < a） | `check_trend_divergence()` + `_apply_wolf_filter()` |
| **二买** | 黄白线首次上0轴后回抽确认 | `find_buy_sell_points()` 中 Type 2 逻辑 |
| **三买** | 回抽不破 ZG，黄白线在0轴附近或上方 | `_check_type3_buy()` |
| **一卖** | 0轴上红柱面积背驰 | `check_trend_divergence()` + `_apply_wolf_filter()` |
| **二卖** | 黄白线首次下0轴后回抽确认 | `find_buy_sell_points()` 中 Type 2 逻辑 |
| **三卖** | 回抽不破 ZD | `_check_type3_sell()` |

#### 三、0轴的核心地位

**0轴是什么**：DIF = 0 的位置，即 EMA12 = EMA26。此时 12 日均线与 26 日均线完全重合，短期力量与中期力量处于**均衡**状态。

**0轴上方（DIF > 0）意味着什么**：

EMA12 > EMA26 → 短期均价高于中期均价 → 近期的买入力量（多头）压过了中期的平均力量。形象地说，市场在"加速上涨"或"尚处于上涨惯性中"。

```
价格持续上涨 → 短期均线（12日）比长期均线（26日）更快地跟上价格上涨
→ EMA12 > EMA26 → DIF > 0 → 在0轴上方
→ 整体环境偏多头
```

0轴上方越高，说明短期涨得越快于中期——多头力量越强。DIF 从高位开始回落但仍在0轴上方，说明上涨速度在减慢但多头仍然主导。

**0轴下方（DIF < 0）意味着什么**：

EMA12 < EMA26 → 短期均价低于中期均价 → 近期的卖出力量（空头）压过了中期的平均力量。市场在"加速下跌"或"尚处于下跌惯性中"。

```
价格持续下跌 → 短期均线（12日）比长期均线（26日）更快地跟随价格下跌
→ EMA12 < EMA26 → DIF < 0 → 在0轴下方
→ 整体环境偏空头
```

0轴下方越深，空头力量越强。DIF 从低位开始回升但仍在0轴下方，说明下跌速度在减慢但空头仍然主导。

**穿越0轴的含义**：

| 穿越方向 | 含义 | 类比 |
|---------|------|------|
| DIF 从下向上穿越0轴 | 短期均线金叉长期均线，多头开始主导 | 从冬天进入春天 |
| DIF 从上向下穿越0轴 | 短期均线死叉长期均线，空头开始主导 | 从夏天进入秋天 |
| DIF 在0轴上方回抽到0轴附近又上去 | 中期回调但多头格局未破 | 夏天的一场阵雨 |
| DIF 在0轴下方回抽到0轴附近又下去 | 短暂反弹但空头格局未破 | 冬天的一次回暖 |

**0轴在缠论中的多重用途**：

| 0轴用途 | 来源 | 引擎实现 |
|---------|------|---------|
| **多空分界线** | DIF > 0 多头占优，DIF < 0 空头占优 | `_apply_wolf_filter()` 中的 `macd_zone` |
| **防狼术** | 0轴下整体偏空，能力一般者应回避 | `wolf_warning` 字段 + 置信度降级 |
| **段间分界** | 趋势背驰中 B 中枢常把黄白线拉回0轴附近，形成 a/c 段的自然分界 | `check_trend_divergence()` 中 a/c 段选取 |
| **二买确认** | 黄白线首次上0轴后回抽确认不破 → 强二买 | 通过价格回调判定间接体现 |
| **双次拉回** | 黄白线两次回抽0轴失败 → 警惕类三卖 | ✅ `detect_double_pullback_zero()` |
| **一买定律** | 一买多在0轴下背驰（108课详解） | `_apply_wolf_filter()` 标注 `below_zero` |
| **强弱判断** | 黄白线长期不能上0轴 = 极度弱势 | 防狼术警告 |

**为什么0轴如此重要**：因为 DIF = 0 代表短期和中期力量的**精确均衡点**。在0轴上方做多、在0轴下方做空，本质上就是"顺着当前的力量不对称方向操作"。0轴不是一个预测工具，而是一个**环境判断工具**——它告诉你当前是在多头的地盘还是空头的地盘，帮助你避免逆势操作。

#### DEA（黄线）与 0 轴

**DEA 是什么**：DEA 是 DIF 的 9 日指数移动平均线，即 DIF 自身的"趋势线"。如果说 DIF 反映的是"短中期力量对比的当前值"，DEA 反映的是"这个对比值的近期平均水平"。

```
DIF  = EMA12 - EMA26          → 力量对比的「快照」（当前瞬间）
DEA  = EMA(DIF, 9)             → 力量对比的「趋势」（近期平均）
柱状图 = 2 × (DIF - DEA)       → 快照偏离趋势的程度
```

**DIF 与 DEA 的关系**：

| DIF 与 DEA 关系 | 含义 | 柱状图表现 |
|----------------|------|-----------|
| DIF > DEA | 力量对比正在**走强**（当前比近期平均更偏多头） | 红柱（正） |
| DIF < DEA | 力量对比正在**走弱**（当前比近期平均更偏空头） | 绿柱（负） |
| DIF = DEA | 力量对比**稳定**，既不走强也不走弱 | 柱状图为 0 |
| DIF 上穿 DEA | **金叉** — 力量对比从走弱转为走强 | 柱从绿转红 |
| DIF 下穿 DEA | **死叉** — 力量对比从走强转为走弱 | 柱从红转绿 |

**DEA 与 0 轴的关系**：

DEA 穿越 0 轴比 DIF 穿越 0 轴更**滞后但更可靠**。这是因为 DEA 是 DIF 的平滑——它过滤掉了 DIF 的短暂波动。

| DEA 位置 | 含义 |
|---------|------|
| DEA > 0 | DIF **持续一段时间**在 0 轴上方 → 多头格局已稳固（不是短暂穿越） |
| DEA < 0 | DIF **持续一段时间**在 0 轴下方 → 空头格局已稳固 |
| DEA 上穿 0 轴 | 多头格局的**确认信号**（比 DIF 上穿 0 轴更可靠，但更晚） |
| DEA 下穿 0 轴 | 空头格局的**确认信号** |

**DIF 和 DEA 同时在 0 轴上方**：这是缠论中所说的"多头主导"环境。此时买入信号可靠度最高（既有短期力量优势，又有持续性确认）。

**DIF 和 DEA 同时在 0 轴下方**：空头主导环境。此时防狼术生效，买入信号需要额外谨慎。

**DIF 在 0 轴上方但 DEA 仍在 0 轴下方**：多头刚起步的过渡阶段。DIF 已经翻正（短期力量逆转），但 DEA 还没跟上（持续性尚未确认）。这种状态常对应"一买后、二买前"的窗口——趋势可能在转折，但还需要确认。

**缠论的两种背驰语境与 0 轴的关系**：

```
典型下跌趋势的 MACD 路径：

    0轴 ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─
                              ∧        ∧
                             / \      / \
    DIF ─────────────── ╱     ╲  ╱     ╲────
         ╲  a段      ╱  A中枢  ╲╱  B中枢  ╲  c段
          ╲        ╱           ↑回抽0轴    ╲
           ╲     ╱                         ╲──← 背驰：c段没有a段深
            ╲  ╱
             ╲╱ ← a段DIF最低点

    说明：
    - a 段：DIF 深入 0 轴下方（第一波下跌力量释放）
    - A 中枢：DIF 向 0 轴回升（市场暂时均衡）
    - B 中枢：DIF 再次向 0 轴回升
    - c 段：DIF 再次下探，但不如 a 段深 → DIF 维度背驰
```

这就是 108 课所说的"B 中枢常把黄白线拉回 0 轴附近"——中枢期间多空力量暂时均衡，DIF/DEA 向 0 轴收敛。而 c 段如果 DIF 极值不如 a 段，就是力度衰竭的直接证据。

#### DIF 为什么会从 0 轴上方回到 0 轴附近甚至下方

**场景**：一段上涨后价格横盘不动，DIF 为什么会下降？

DIF = EMA12 - EMA26。EMA 的公式是：

```
EMA[i] = EMA[i-1] × (1 - α) + Close[i] × α
```

关键在于 **EMA 是向当前价格"收敛"的**——如果价格不动（横盘），EMA 会逐渐向当前价格靠拢。

**上涨阶段**：

```
假设价格从 10 元涨到 15 元：
  EMA12（反应快）：很快追上 15 元附近（比如 14.5）
  EMA26（反应慢）：追得慢，可能才到 13 元
  DIF = 14.5 - 13 = 1.5 → 在 0 轴上方（多头）
```

**开始横盘在 15 元**：

```
价格停在 15 元不动了：
  EMA12（每天权重 15.4%）：已经接近 15，继续收敛到 15 → 几乎不动了
  EMA26（每天权重 7.4%）：从 13 元慢慢向 15 元靠拢 → 在缓慢上升

第1天横盘: EMA12 ≈ 14.9, EMA26 ≈ 13.2 → DIF = 1.7
第5天横盘: EMA12 ≈ 15.0, EMA26 ≈ 13.8 → DIF = 1.2  ← 开始下降！
第10天横盘: EMA12 ≈ 15.0, EMA26 ≈ 14.3 → DIF = 0.7
第20天横盘: EMA12 ≈ 15.0, EMA26 ≈ 14.8 → DIF = 0.2  ← 接近 0 轴
第30天横盘: EMA12 ≈ 15.0, EMA26 ≈ 14.95 → DIF ≈ 0.05 ← 几乎到 0 轴
```

**本质原因**：上涨时 EMA12 比 EMA26 "领先"（因为反应更快），造成 DIF > 0。但横盘后，两条均线都向同一个价格（15 元）收敛——慢的那条（EMA26）在"追上来"。两者的差距逐渐缩小，DIF 就自然回落到 0 轴附近。

**如果横盘后轻微下跌**（比如从 15 跌到 14.5）：

```
EMA12（反应快）：快速跟随下跌，降到 14.6
EMA26（反应慢）：因为之前的上涨惯性，还在 14.8 附近
DIF = 14.6 - 14.8 = -0.2 → 穿过 0 轴到下方！
```

即使只是从 15 跌到 14.5（幅度很小），DIF 也会转负——因为快均线比慢均线更快地"感受到"了价格的下跌。

**缠论意义**：这就是为什么 108 课说"中枢常把 DIF 拉回 0 轴附近"。中枢 = 价格在一个区间震荡 ≈ 横盘。横盘的时间越长，EMA12 和 EMA26 越趋于一致，DIF 越接近 0。中枢结束后的新走势（无论上涨还是下跌）会让 DIF 重新远离 0 轴——这段新走势的 DIF 极值和面积就成为背驰比较的对象。

```
上涨 a 段: DIF 远离 0 轴（正方向）
  ↓
A 中枢横盘: DIF 回归 0 轴（EMA12 追上 EMA26）
  ↓
上涨 c 段: DIF 再次远离 0 轴
  → 如果 c 段的 DIF 峰值不如 a 段 → 背驰（多头力量衰竭）
```

**引擎的实现**：引擎当前主要使用 DIF 与 0 轴的关系（`_apply_wolf_filter()` 中的 `macd_zone`），DEA 的 0 轴位置未作为独立判据。DEA 的信息间接体现在 histogram（= 2 × (DIF - DEA)）中，被柱状图面积和柱峰值维度所捕获。

#### 四、多级别 MACD

缠论辅导框架提到："比较两段力度时，若 1 分钟 MACD 乱而 30 分钟清晰 → 用大级别 MACD"。引擎通过多级别联立框架（`synthesize_multi_level()`）实现了类似的效果——每个级别独立计算 MACD 和背驰，然后在联立层面综合判断，让大级别的清晰信号主导决策。

## 二、包含处理 — 消除噪声的第一步

### 对应缠论概念

**K线包含关系处理**（108课 §1.1、缠论解析 场景A）

### 实现

`inclusion_processing()` — 从左到右扫描相邻K线对，检测包含关系并合并。

### 理论说明

包含关系的定义：两根K线中，一根的高低范围完全覆盖另一根。处理规则：

- **向上合并**（前一根高点高于再前一根）：新高 = max(两高), 新低 = max(两低) — 即"取高高低高"
- **向下合并**（前一根高点低于再前一根）：新高 = min(两高), 新低 = min(两低) — 即"取低低高低"

**背后的本质**：包含关系代表市场在某个价格区间内的**犹豫不决**。一根K线完全包含另一根，说明多空双方在更小范围内拉锯。合并的方向取决于"进入这对K线时市场的倾向"——如果之前在涨（向上），就按乐观方式合并（保留高点和较高的低点）；如果之前在跌，就按悲观方式合并。

这一步的本质是**信号去噪**：把市场犹豫的噪声压缩掉，只保留真正有方向意义的K线，为后续分型识别提供干净的输入。

## 三、分型识别 — 转折的最小单元

### 对应缠论概念

**顶分型与底分型**（108课 §1.1、缠论解析 场景A）

### 实现

`find_fractals()` — 在合并后的K线序列上，用三根滑动窗口检测顶底分型。

### 理论说明

- **顶分型**：中间那根K线的高点和低点都**高于**左右两侧 → 局部最高点
- **底分型**：中间那根K线的高点和低点都**低于**左右两侧 → 局部最低点

注意不是只比较高点——必须"高点最高**且**低点也最高"（底分型对称）。这个"且"字很关键：它确保分型代表的是**整体的局部极值**，而不仅仅是某一端的突出。

**背后的本质**：分型是市场力量转换的**最小可观测单位**。一个顶分型意味着多头尝试推高价格后，被空头成功压制——中间K线的高点就是多头的"力竭点"。底分型反之。分型是笔的端点，笔是线段的组件，线段构成中枢——整个递归体系的最底层起点就是分型。

## 四、笔的构建 — 结构化的第一层抽象

### 对应缠论概念

**笔**（108课 §1.2、缠论解析 场景A 旧笔规则）

### 实现

`find_strokes()` — 从分型序列中，按顶底交替、间隔检查等规则构建笔。

### 理论说明

笔是连接相邻**顶分型↔底分型**的最小走势单元。构建规则：

1. **顶底交替**：笔必须是顶→底或底→顶，不能顶→顶
2. **间隔要求**（旧笔规则）：顶分型与底分型之间至少隔 1 根独立K线（在合并K线上，间隔 ≥ 4 个位置）
3. **同类取极值**：连续出现多个顶分型时，保留最高的那个；连续出现多个底分型时，保留最低的
4. **方向一致性**：向上笔的终点必须高于起点，向下笔反之

引擎当前实现的是**旧笔规则**（经典规则），路线图中 P3.3 计划支持新笔规则。

### 旧笔 vs 新笔规则对比

缠论原文在第 81 课前后修改了笔的定义，形成"旧笔"和"新笔"两套规则。缠论解析（场景A）和土匪注解均建议**择一统一，全图一致**。

#### 旧笔规则（经典，引擎当前实现）

**核心条件**：顶分型与底分型之间，至少有 **1 根独立K线**——这根K线不属于顶分型的三根，也不属于底分型的三根。

```
包含处理后的合并K线序列：

  ①  ②  ③    ④    ⑤  ⑥  ⑦
  底分型      独立K线      顶分型
  (⑤⑥⑦)      ④          (①②③)
```

由于分型占 3 根合并K线，且中间至少 1 根独立K线，因此顶底之间的最小间隔 = 3（分型） + 1（独立） = **4 个位置**。引擎中的 `gap >= 4` 就来自这个要求。

**实际计数**：在合并K线上，顶分型中间元素（mk_idx）和底分型中间元素（mk_idx）之间的距离 ≥ 4。

#### 新笔规则（放宽，第 81 课后）

**核心条件**：顶分型的最高K线与底分型的最低K线**之间**（不含这两根本身），裸数至少 **3 根K线**。

```
包含处理后的合并K线序列：

  顶的最高K    ①  ②  ③    底的最低K
              ↑  三根K线  ↑
              （不含两端）
```

#### 两种规则的核心差异

| 维度 | 旧笔（经典） | 新笔（放宽） |
|------|-------------|-------------|
| **间隔要求** | 至少 1 根**独立**K线（不属于两端分型） | 两端之间至少 3 根K线（不含两端本身） |
| **计数对象** | 合并K线上分型中间位置的间距 ≥ 4 | 顶最高K与底最低K之间的K线数 ≥ 3 |
| **共用K线** | 禁止（顶底分型不能共用K线） | 同样禁止 |
| **严格程度** | **更严格** — 过滤掉更多短笔 | **更宽松** — 允许更多短笔 |
| **笔的数量** | 同样的走势中产生的笔**更少** | 同样的走势中产生的笔**更多** |
| **适用场景** | 大级别（日线、周线）— 需要过滤噪声 | 小级别（5分钟、1分钟）— 需要捕捉更细的结构 |

#### 本质区别的直觉解释

旧笔规则要求"中间有足够的**空间**给走势表达自己"——如果两个分型之间的K线太少，说明市场还没来得及真正走出一段方向性运动就转折了，这更可能是噪声而非真正的笔。

新笔规则相对放宽——它只要求两端之间有足够的K线，但不强制这些K线必须"独立"于分型。这使得新笔能在更紧凑的走势中识别出更多结构。

#### 引擎的实现选择

引擎选择旧笔规则，原因是：

1. **更保守**：对于日线级别的分析（上班族的操作级别），过滤噪声比捕捉细节更重要
2. **更稳定**：旧笔产生的笔更少，后续的线段、中枢、走势类型更不容易被短期波动扰乱
3. **实现简单**：只需检查 `gap >= 4`，逻辑清晰

路线图 P3.3 计划添加 `stroke_mode="old"/"new"` 参数，让用户在两种规则间选择。

### 背后的本质

如果说分型是"转折点"，那笔就是"连接两个转折点的一段确定的走势"。它是将零散的分型组织成有方向的线性结构的过程。笔的间隔要求是为了排除过于短暂的伪分型——如果两个分型紧挨着，中间没有足够的K线来"表达"这段走势，那它就不够资格被称为一笔。

笔的本质是**市场最小的完整波动**。每一笔都代表多头或空头的一次完整的力量释放。

## 五、线段构建 — 特征序列法

### 对应缠论概念

**线段**（108课第 62-67 课、缠论解析 场景B）

### 实现

`find_segments()` — 严格按第 67 课特征序列法实现，包含两种终结情形。

辅助函数：
- `_process_char_seq_inclusion()` — 特征序列的包含处理
- `_find_char_fractal()` — 特征序列中的分型检测
- `_check_reverse_fractal()` — 第二种情况的反向确认

### 理论说明

线段由至少 3 笔构成，且前三笔必须有价格重叠。线段结束的判定是缠论中较复杂的部分：

**特征序列法**：向上线段的"特征序列"是其中所有**向下笔**（反方向笔），每根向下笔用其完整高低点作为一个"元素"。对这些元素做包含处理形成"标准特征序列"，然后在标准序列中找顶分型——找到顶分型就意味着向上线段结束。向下线段对称，找底分型。

**两种终结情形**：
1. **第一种**（无缺口）：特征序列分型的前两个元素之间有价格重叠 → 直接在分型处结束
2. **第二种**（有缺口）：前两元素之间有缺口 → 需要在后续的**反向特征序列**中出现对应分型才能确认（第 67 课）

#### 直观举例

**前置知识**：向上线段中，每一根"向下笔"就是特征序列的一个元素。对这些元素做包含处理后的序列叫"标准特征序列"。在标准特征序列中找**顶分型**（中间元素高于两侧），即判定向上线段结束。

---

**第一种情形（无缺口）— 直接确认**

假设一段向上线段由以下笔组成（↑ = 向上笔，↓ = 向下笔）：

```
价格
 │
25│          ↑5
 │         / \
23│   ↑3  /   \
 │  / \ /     \
21│ /   ↓4     ↓6
 │/               \
19│↑1                ↓8（向下笔高点20、低点17）
 │ \                /
17│  ↓2   ↑7(high 22)/
 │        \       /
15│         \    /
 │
```

**提取特征序列**（所有向下笔）：
- ↓2：高点 19、低点 17
- ↓4：高点 23、低点 21
- ↓6：高点 25、低点 22
- ↓8：高点 20、低点 17

**包含处理后**的标准特征序列（假设无包含）：

| 元素 | 高 | 低 |
|------|----|----|
| A (↓2) | 19 | 17 |
| B (↓4) | 23 | 21 |
| C (↓6) | 25 | 22 |
| D (↓8) | 20 | 17 |

寻找**顶分型**：B-C-D 中，C 的高 25 > B 的高 23 且 > D 的高 20，C 的低 22 > B 的低 21 且 > D 的低 17 → **顶分型成立**。

**判断缺口**：看 B 和 C（分型前两个元素）是否有价格重叠。B 的区间 [21,23]，C 的区间 [22,25] → 在 [22,23] 有重叠 → **无缺口**。

✅ **结论**：直接在分型处结束向上线段。线段终点在 ↓6 对应的笔处。

**代码对应**：`_find_char_fractal()` 返回 `(fractal_stroke=↓6, has_gap=False)` → `find_segments()` 中 `has_gap` 为 False → 不调用 `_check_reverse_fractal()`，直接结束线段。

---

**第二种情形（有缺口）— 需要反向确认**

假设特征序列长这样：

| 元素 | 高 | 低 |
|------|----|----|
| A (↓2) | 19 | 17 |
| B (↓4) | 28 | **25** |
| C (↓6) | 30 | 27 |
| D (↓8) | 26 | 24 |

顶分型 B-C-D：C 高 30 > B 高 28 且 > D 高 26 → **顶分型成立**。

**判断缺口**：看 B 和 A（分型前两个元素）。A 的区间 [17,19]，B 的区间 [25,28] → 没有重叠（A 的最高 19 < B 的最低 25）→ **有缺口**！

这个缺口意味着什么？特征序列从 A 到 B 跳跃了一大段（价格从 19 突然到 25），说明向上线段中间有一段**非常强劲的上涨**，以至于回调笔之间出现了断层。这种情况下，仅凭特征序列中的顶分型**还不够确定**线段真的结束了——万一这只是一次猛烈上涨中的暂时调整呢？

**反向确认流程**：引擎从分型位置（↓6）开始，取后续的**向上笔**作为反向特征序列：

| 反向元素 | 高 | 低 |
|---------|----|----|
| ↑7 | 28 | 26 |
| ↑9 | 25 | 23 |
| ↑11 | 27 | 24 |

在反向序列中找**底分型**（中间元素低于两侧）：↑7-↑9-↑11 中，↑9 的低 23 < ↑7 的低 26 且 < ↑11 的低 24 → **底分型成立**。

✅ **结论**：反向确认通过，向上线段确认结束。

如果反向序列中**找不到底分型**，则 `_check_reverse_fractal()` 返回 False，这次分型被**否决**（`rejected_ids` 记录），引擎继续向后扫描寻找下一个符合条件的分型。

**为什么需要反向确认**：缺口说明趋势力量极强。在强趋势中，一次顶分型可能只是"狂飙中的喘息"。反向确认要求**另一个方向也出现了结构性转折**——这才能证明趋势力量真的衰竭了，不是假摔。

---

**两种情形的核心区别**：

| | 第一种（无缺口） | 第二种（有缺口） |
|---|---|---|
| 特征序列相邻元素 | 有价格重叠 | 价格断层（跳空） |
| 趋势强度 | 正常 | 异常强劲 |
| 确认条件 | 分型成立即可 | 分型成立 + 反向序列出现反分型 |
| 引擎代码 | `has_gap=False` → 直接结束 | `has_gap=True` → 调用 `_check_reverse_fractal()` |
| 本质含义 | 正常力度衰减，自然转折 | 极强趋势中的转折，需"双重证据" |

**背后的本质**：线段是比笔更高一级的结构单元。如果笔是"一次完整的波动"，线段就是"一段由多次波动构成的方向性运动"。特征序列法的精妙之处在于：它不直接看价格新高/新低来判断线段是否结束，而是看**反方向笔**是否形成了"转势分型"。

这背后的思想是：一段向上的线段，要被终结，不是因为出现了一次下跌（那只是一笔回调），而是因为**连续的回调笔**形成了越来越强的空头力量格局（即反方向的分型结构）。这比简单的"跌破前低"更能捕捉真正的结构性转折。

## 六、中枢构建 — 市场的"价格共识区"

### 对应缠论概念

**中枢**（108课 §1.4、图解缠论 §一中枢）

### 实现

- `find_hubs()` — 笔中枢：3 笔重叠区间 + 延伸
- `find_seg_hubs()` — 线段中枢：3 线段重叠区间 + 延伸（高一级别）
- `classify_hub_evolution()` / `classify_seg_hub_evolution()` — 中枢演化分类

### 理论说明

**中枢的定义**：至少 3 个连续**次级别走势**（笔或线段）的价格重叠区间。

#### 什么是"次级别走势"

缠论中的"级别"是一个**递归定义**的层级系统。理解次级别走势，需要先理解级别体系：

```
级别层级（从低到高）：

1分钟笔 → 1分钟线段 → 5分钟笔 → 5分钟线段 → 30分钟笔 → 30分钟线段 → 日线笔 → 日线线段 → ...
```

**"次级别"的含义**：对于某个级别的中枢而言，构成它的**最小组件**就是"次级别走势"。

| 当前中枢级别 | 次级别走势是什么 | 引擎实现 |
|------------|----------------|---------|
| **笔中枢** | 笔（Stroke） | `find_hubs(strokes)` — 3 根笔的重叠区间 |
| **线段中枢** | 线段（Segment） | `find_seg_hubs(segments)` — 3 条线段的重叠区间 |

**具体举例**：

**笔中枢**的次级别走势是**笔**。假设有 5 根连续笔：

```
价格
 │    ↑笔2        ↑笔4
25│   /    \       /    \
 │  /      \     /      \
22│ /        \   /        ↑笔6（离开）
 │          \ /          /
19│     ↓笔3   ↓笔5      /
 │                      /
16│                    /
 │
```

- 笔1-笔2-笔3 三根笔的价格在 [19, 25] 有重叠 → 形成**笔中枢**
- 笔4、笔5 仍然穿越中枢区间 → **延伸**到同一中枢
- 笔6 完全脱离中枢上沿 → 中枢结束

这里每根笔就是"次级别走势"。

**线段中枢**的次级别走势是**线段**。这是"看高一级"的结果——把若干根笔构成的线段当作一个整体，3 条线段的重叠区间构成更高级别的中枢：

```
线段1（由笔1-笔5构成）  线段2（由笔6-笔10构成）  线段3（由笔11-笔15构成）
        ↑                       ↓                       ↑
       / \                     / \                     / \
      /   \                   /   \                   /   \
     /     \       ←─ 三条线段的重叠区间 ─→        /     \
    /       \_________________/       \_____________/       \
```

这里每条线段就是"次级别走势"。

#### "次级别走势"与时间级别的关系

这是缠论中最容易混淆的概念之一。**次级别走势与时间级别有关，但不是简单的"笔就是次级别"**。

**缠论原文的严格定义**（108课 §1.4）：

> 中枢 = 至少三段**次级别走势类型**的价格重叠区间。

这里的"次级别走势类型"不是笔，而是**低一个级别的完整走势**（盘整或趋势）。严格来说：

| 中枢级别 | 次级别走势类型 | 举例 |
|---------|--------------|------|
| 30分钟中枢 | 三段5分钟走势类型 | 5分钟的盘整或趋势 |
| 日线中枢 | 三段30分钟走势类型 | 30分钟的盘整或趋势 |
| 周线中枢 | 三段日线走势类型 | 日线的盘整或趋势 |

但这个定义有一个实操困难：**走势类型本身也包含中枢**，而中枢又要用走势类型来定义——这是一个**循环递归**。缠论解析一书直接指出了这个问题："严格递归易循环"。

**实务简化**（缠论解析、图解缠论的共识）：

实际操作中，几乎所有缠论实现都采用以下简化：

| 简化方式 | 次级别用什么 | 说明 |
|---------|------------|------|
| **笔中枢**（本引擎 `find_hubs()`） | 笔（Stroke） | 3 笔重叠 → 最小中枢 |
| **线段中枢**（本引擎 `find_seg_hubs()`） | 线段（Segment） | 3 线段重叠 → 较高级别中枢 |

**为什么笔可以近似次级别走势**：

1. **笔是最小的完整波动单元**。一根向上笔从底分型到顶分型，本身就是一个"最小级别的走势"——它有起点、有终点、有方向。虽然严格来说它不是"走势类型"（没有包含中枢），但它是**最小级别中枢的构建原料**
2. **递归的起点必须有一个"最小零件"**。缠论的递归定义需要一个基础案例（base case），笔就是这个基础案例。正如数学归纳法中 n=1 的情况
3. **实测效果足够好**。缠论解析明确建议"最小中枢零件取线段"（认为笔过碎），但用笔构建的中枢在细粒度分析中（如30分钟以下）同样有效

**引擎的两级实现**：

```
笔（最小级别走势）
 ├─ 3 笔重叠 → 笔中枢（find_hubs）        ← 最小级别中枢
 │
 └─ 多笔 → 线段（find_segments）
      └─ 3 线段重叠 → 线段中枢（find_seg_hubs）← 较高级别中枢
```

**时间周期如何影响级别**：

引擎的 `analyze(bars, level)` 接受不同周期的 K 线数据。用**不同周期的 K 线**做分析，本质上就是在**不同级别**上操作：

| K线周期 | 笔中枢 ≈ | 线段中枢 ≈ |
|--------|---------|-----------|
| 5分钟 | 5分钟级别中枢 | 30分钟级别中枢 |
| 30分钟 | 30分钟级别中枢 | 日线级别中枢 |
| 日线 | 日线级别中枢 | 周线级别中枢 |

这里的"≈"是近似关系。缠论原文指出"日线上的一笔，大致对应30分钟的一个走势类型"——这就是时间周期和结构级别之间的桥梁。

**多级别联立**（`multi_level_synthesis()`）正是利用这个关系：分别在30分钟、日线、周线上运行 `analyze()`，得到三个级别的中枢和买卖点信息，然后综合判断。这等效于在不同级别上识别"次级别走势"并构建对应级别的中枢。

**总结**：笔中枢的次级别走势是笔——这是一个**实务简化**，不是缠论原文的严格定义。严格来说次级别走势应该是"低一级别的走势类型"。但由于递归循环问题，用笔和线段作为两级基础构件是业界通行做法，引擎也采用了这种方案。时间周期通过决定 K 线的粒度间接影响级别——30分钟 K 线上的笔中枢就是30分钟级别的中枢。

**区间计算**：
- ZG（中枢上沿）= min(各笔高点) — 所有笔都到达过的最低高点
- ZD（中枢下沿）= max(各笔低点) — 所有笔都到达过的最高低点
- 有效条件：ZD < ZG（重叠区间存在）
- GG = 区间内最高价, DD = 区间内最低价（波动范围）

**延伸规则**：中枢形成后，后续的笔如果仍然穿越 ZD~ZG 区间（即 `sj_l < zg and sj_h > zd`），则该笔**延伸**到同一中枢内。直到某笔完全离开中枢区间，中枢结束。

**背后的本质**：中枢是缠论最核心的概念之一。它的本质是**多空双方的暂时均衡区域**——在这个价格范围内，买方和卖方的力量大致平衡，价格在此反复震荡。

中枢的物理意义类似于"引力场"：价格一旦进入中枢范围，就会被反复拉回。只有当一方力量足够强大，才能使价格**脱离中枢**——这就是趋势的起点。

ZG 和 ZD 的计算方式揭示了中枢的本质：ZG 是 min(各段高点)，意味着"所有段都曾上冲到至少这个价格"；ZD 是 max(各段低点)，意味着"所有段都曾下探到至少这个价格"。它们的交集就是市场**真正的共识区间**。

### 中枢演化 — 三种命运

引擎实现了对中枢演化方向的分类（`classify_hub_evolution()`）：

| 演化类型 | 判定条件 | 本质含义 | 操作倾向 |
|---------|---------|---------|---------|
| **延伸** | 单中枢笔数 ≥ 5 | 多空继续胶着，谁也奈何不了谁 | 高抛低吸做差价 |
| **新生（上/下）** | 相邻中枢 [DD,GG] 不重叠 | 一方力量突破均衡，趋势形成 | 持仓/回避 |
| **扩展** | 相邻中枢 [DD,GG] 重叠 | 假突破，回到更大级别的震荡 | 升级为大中枢，按盘整处理 |

#### 操作指导

**延伸**：中枢未结束，价格围绕 ZD\~ZG 震荡。操作核心是做差价——向下离开中枢的低点（接近 DD）倾向买入，向上离开的高点（接近 GG）倾向卖出。差价的价值取决于中枢区间宽度和级别。需警惕延伸随时可能转为新生或扩展。

**新生**：趋势确认信号。向上新生持股不动，向下新生持币回避，不做短线博弈。新生的确认点就是第三类买/卖点。一旦确认，必须切换思维模式——从震荡差价切到趋势持仓。

**扩展**：本质是"假突破"。两个中枢的波动范围 [DD,GG] 重叠，说明价格并未真正脱离原来的博弈区间。扩展最常出现在三买后的"假趋势"、趋势背驰后的弱反弹、以及九段升级三种场景中。确认扩展后应放弃趋势预期，回到震荡做差价模式，但区间放大一级。

#### 扩展中枢合并（`merge_expanded_hubs()`）

当相邻中枢被标记为"扩展"时，引擎将它们合并为一个更大级别的中枢。合并后的大中枢用于走势类型判定（`determine_trend()`），解决了扩展场景下"标注为扩展但仍判定为趋势"的逻辑矛盾：

- **合并前**：2个中枢（其中一个标记为扩展）→ `determine_trend()` 判定为趋势 ❌
- **合并后**：合并为1个大中枢 → `determine_trend()` 判定为盘整 ✅

合并逻辑支持链式合并（连续多个扩展中枢合并为一个），原始中枢列表保留在 `result.hubs` 用于图表展示和单中枢级别的背驰/买卖点检测，合并后的列表存储在 `result.merged_hubs` 用于走势判定。

## 七、走势类型判定 — 完全分类定理

### 对应缠论概念

**走势类型**（108课 §1.5）+ **走势终完美**（108课 §1.6）

### 实现

- `determine_trend()` — 走势类型判定
- `assess_trend_completion()` — 走势完成度评估

### 理论说明

走势类型的判定基于中枢数量：

| 中枢数 | 走势类型 | 细分 |
|--------|---------|------|
| 0 | 跟随最后一笔方向 | 上涨/下跌 |
| 1 | 盘整 | 中枢上方运行/中枢区间震荡/中枢下方运行 |
| ≥2 | 趋势 | 后一中枢 ZD > 前一中枢 ZG → 上涨趋势；反之 → 下跌趋势 |

**走势终完美**是缠论最深刻的定理之一：任何级别的走势类型**终将完成**。这不是经验总结，而是逻辑必然——因为走势的分类是完备的，任何走势在某个时刻必然属于某种类型，而该类型的延续需要满足特定条件（如趋势需要不断产生新的同向中枢），这些条件不可能无限满足。

引擎的走势完成度评估（`assess_trend_completion()`）实现了三种状态：

| 状态 | 标识 | 含义 |
|------|------|------|
| 进行中 | 🔄 | 趋势正常发展，无背驰信号 |
| 疑似完成 | ⚠️ | 检测到背驰但未形成确定买卖点 |
| 已确认完成 | ✅ | 趋势背驰 + 一买/一卖信号确认 |

**背后的本质**：走势类型判定的意义在于为操作提供**坐标系**。你必须先知道"当前处于什么走势中"，才能决定"应该做什么"。盘整中做高抛低吸，趋势中持仓不动，走势转折时进出场——缠论的所有操作都建立在走势分类之上。

### 操作第一原则：盘整做差价，趋势持仓不动

盘整和趋势的赚钱逻辑完全相反，用错了模式两种钱都赚不到：

| | 盘整 | 趋势 |
|---|------|------|
| **赚钱逻辑** | 区间的宽度（低买高卖） | 时间的长度（价格的持续运动） |
| **操作频率** | 高（反复进出） | 低（一次进场，耐心持有） |
| **核心动作** | 中枢下沿买、上沿卖 | 买入后持仓，等背驰信号再出 |
| **最忌讳** | 高点不卖（等突破）→ 回到低点白坐过山车 | 低点频繁卖出（怕回调）→ 踏空后追高 |

趋势中"持仓不动"不是"闭眼不看"——出场条件触发时必须执行：
- 趋势背驰信号出现 → 减仓
- 一卖/一买确认 → 大幅减仓或清仓
- 三卖/三买触发 → 必须清仓

趋势不一定在两个中枢后就结束。两个中枢是趋势背驰检测的最低条件（需要两段同质推动来比较），但趋势可以有3个、4个甚至更多中枢。走势终完美定理保证趋势终将结束，但不预测在第几个中枢后。

### 背驰比较的对象选择

趋势背驰检测比较的是 a 段和 c 段（a+A+b+B+c 结构中的第一段和最后一段推动），而不是 b 和 c，因为：

- a 和 c 都是从 MACD 零轴出发的纯粹驱动段（中枢让 DIF/DEA 回到0轴附近，相当于"重置"基准线）
- b 跨越了中枢 B 的形成过程，包含"驱动+震荡"混合成分，不纯粹
- a 和 c 的比较基准一致（同质可比），b 和 c 的基准不同

引擎的实现严格筛选中枢前/后的笔作为 a/c 段，不计入中枢内部的笔，确保力度比较的纯粹性。

## 八、背驰检测 — 力度衰竭的量化判定

### 对应缠论概念

**趋势背驰**和**盘整背驰**（108课 §三、缠论解析 场景C、图解缠论 §一背驰）

### 实现

- `check_trend_divergence()` — 趋势背驰：a+A+...+B+c 结构中 c 段力度 < a 段
- `check_consolidation_divergence()` — 盘整背驰：同一中枢前后连续同向出入力度递减

### 理论说明

#### 趋势背驰

趋势背驰是缠论中最重要的信号之一，它的标准结构是 **a+A+b+B+c**：

```
a段（趋势起始的一笔/一段）
  ↓
A中枢（第一个中枢）
  ↓
b段（连接两个中枢的过渡）
  ↓
B中枢（第二个中枢，与A不重叠 → 趋势成立）
  ↓
c段（趋势末端的一笔/一段）
```

**判定条件**：c 段的 MACD 面积 < a 段的 MACD 面积。引擎还同时检查 DIF 极值和柱峰值，构成三维度验证。

引擎会分组处理连续同方向的中枢位移，支持包含 2 个以上中枢的长趋势。还会完整记录 a+A+b+B+c 结构的时间和价格信息，用于后续的区间套和报告展示。

#### 盘整背驰

盘整背驰发生在**同一个中枢**内部：连续两次同方向离开中枢（如两次上冲突破 ZG），后一次的力度弱于前一次。

引擎实现中，先收集每个中枢的所有向上/向下出入笔（突破 ZG 或跌破 ZD 的笔），然后逐对比较同方向出入的 MACD 面积。

**背后的本质**：背驰的物理含义是**力度衰竭**。趋势之所以是趋势，是因为有持续的力量推动。当推动力减弱（c 段面积 < a 段面积），说明推动趋势的主导力量正在耗尽，走势大概率要转向。

盘整背驰的含义更直接：在同一个均衡区域（中枢）中，同方向的尝试一次比一次弱，说明这个方向已经试不出来了，反方向突破的可能性增大。

背驰是缠论将**定性判断转化为定量判断**的关键机制。没有背驰检测，买卖点就只能靠"感觉"；有了 MACD 面积的量化对比，买卖点的判定就变成了机械化的计算。

## 九、三类买卖点 — 操作的完备系统

### 对应缠论概念

**三类买卖点**（108课 §二、图解缠论 §二、缠论解析 场景C）

### 实现

`find_buy_sell_points()` — 统一识别一买/一卖、二买/二卖、三买/三卖、盘整买/卖。

### 理论说明

缠论证明：市场上**只有三类买卖点**，它们组成完备的操作系统。

#### 第一类买卖点（一买 1B / 一卖 1S）

- **触发**：趋势背驰
- **含义**：趋势力度衰竭的第一个信号，是转折的"先行者"
- **特征**：利润空间最大，但风险也最高（可能是假背驰）

**本质**：一买/一卖抓的是**趋势拐点**。它对应的是力量耗尽后的第一次反转。之所以风险最高，是因为你在赌"旧趋势已经结束"，但此时还没有新趋势的结构性确认。

#### 第二类买卖点（二买 2B / 二卖 2S）

- **触发**：一买后第一次回调不破一买低点（二卖对称）
- **含义**：一买的有效性被"回调不破"所确认
- **强弱分类**（108课 §2.4，引擎已实现三级）：
  - **最强**：回调不进中枢（二买 + 三买合一）→ 大行情信号
  - **强势**：回调低点高于一买价 → 回调幅度小
  - **标准**：回调低点低于一买价但不破 → 经典二买

**本质**：二买是对一买的**确认**。市场给出一个信号（一买），然后"测试"这个信号——如果回调无法推翻它（不创新低），就证明转折成立。二买的强弱分类本质上是**市场共识强度**的度量。

#### 第三类买卖点（三买 3B / 三卖 3S）

- **触发**：价格离开中枢后回试，不破中枢上沿 ZG（三买）或下沿 ZD（三卖）
- **含义**：中枢被突破后的有效确认

**本质**：三买/三卖抓的是**突破确认**。价格突破中枢后回来"测试"——如果回试不进中枢，说明突破有效，新趋势确立。这是风险最低的买卖点，因为你有明确的止损位（中枢上/下沿），且已有结构性的趋势确认。

#### 盘整买卖点（PB / PS）

- **触发**：盘整背驰
- **含义**：中枢内的震荡反转信号
- **置信度**：通常较低（可能是假信号，中枢震荡可能延续）

**三类买卖点的逻辑关系**：

```
一买（趋势拐点）→ 二买（拐点确认）→ 三买（趋势延续确认）
     最高利润          均衡选择            最低风险
     最高风险          中等风险            已无超额利润
```

这三类买卖点构成了一个**从冒险到保守的连续谱**。不同性格和能力的交易者可以选择不同的买卖点类型：激进者做一买，稳健者做二买，保守者做三买——缠论的完备性保证了无论你选哪种，都能找到对应的机械化操作规则。

### 各类买卖点的后续观察与操作

#### 一买（1B）后的三种可能（108课 §29）

一买触发后（下跌趋势背驰），后续只有三种走法：

| 力度 | 情景 | 判断标准 | 操作 |
|------|------|---------|------|
| 最弱 | 最后中枢扩展 | 反弹连最后下跌中枢的 DD 都没回到 | 保持轻仓观望，在扩展大中枢下沿做差价 |
| 中等 | 更大级别盘整 | 反弹进入最后中枢区间但未走成反趋势 | 在大盘整区间做差价，等三买突破 |
| 最强 | 反趋势 | 反弹直接超越所有下跌中枢，走成上涨趋势 | 等二买加仓，三买满仓 |

止损：一买后若再出现同级别下跌缠绕（判断错误），先退出。

#### 二买（2B）后的观察

二买的三种强弱（引擎 `strength` 字段）：

| 强度 | 形态 | 操作 |
|------|------|------|
| 最强（二买三买合一） | 回调不进最后下跌中枢 | 满仓 |
| 强势 | 二买高于一买 | 标准仓位 |
| 标准 | 二买低于一买但不破 | 保守仓位 |

失败条件：回调跌破一买低点 → 一买结构被破坏 → 反弹清仓。

#### 三买（3B）后的四种走向

| 情景 | 判断标准 | 操作 |
|------|---------|------|
| 趋势形成（新生） | 上方新中枢与原中枢 [DD,GG] 不重叠 | 持仓不动，等趋势背驰 |
| 中枢扩展 | 上方新中枢与原中枢 [DD,GG] 重叠 | 降低预期，切换为大中枢震荡做差价 |
| 假突破（失败） | 回抽跌破中枢上沿 ZG | 三买不成立，减仓或清仓 |
| 九段升级 | 次级别走势延伸至9段 | 可能扩展为更高级别中枢 |

#### 盘整买点（PB）后的三条路

盘整背驰后只有三种可能（土匪注解版 第25课）：三买（突破中枢，加仓）、中枢延伸（回到中枢继续差价）、更大中枢（扩展，止损或降级操作）。

#### 卖出信号的后续

- **一卖（1S）**：减至1/3仓。后续观察同一买的三种可能（对称方向）。
- **二卖（2S）**：清仓。一卖后第一次反弹不创新高即为二卖，是一卖的补救。
- **三卖（3S）**：必须清仓。中枢下沿被有效跌破，不出则等更大级别一买。

#### 仓位速查

| 信号 | 仓位 | 信号 | 仓位 |
|------|------|------|------|
| 一买 | 1/3 | 一卖 | 减至1/3 |
| 二买 | 2/3 | 二卖 | 清仓 |
| 三买 | 满仓 | 三卖 | 必须清仓 |
| PB | 1/4~1/3 | 中枢上移段 | 满仓持有 |

## 十、防狼术 — 零轴过滤器

### 对应缠论概念

**防狼术**（108课 §5.7、缠论解析 场景F、土匪注解 §3.1）

### 实现

`_apply_wolf_filter()` — 根据 MACD DIF 的零轴位置，对买卖点进行置信度调整。

### 理论说明

- DIF < 0（零轴下方）→ 空头主导 → 买入信号降级 + 警告
- DIF > 0（零轴上方）→ 多头主导 → 卖出信号降级 + 警告

**背后的本质**："防狼术"这个名字很形象——它防的是"狼来了"式的假信号。DIF 的零轴位置代表了**市场的中长期趋势环境**。在空头环境（DIF < 0）中出现的买入信号，相当于在暴风雨中看到一丝阳光——它可能是真的转晴，但更可能只是暂时的间歇。

防狼术的本质是**大级别环境对小级别信号的过滤**。它体现了缠论的一个核心原则：小级别的信号必须在大级别的背景下才有意义。

## 十一、仓位建议 — 信号到操作的映射

### 对应缠论概念

**资金管理**（108课 §6.4、图解缠论 §六）

### 实现

`_apply_position_advice()` — 基于买卖点类型、强弱、置信度给出仓位建议。

### 理论说明

| 买卖点 | 基础仓位 | 本质逻辑 |
|--------|---------|---------|
| 一买 | 轻仓 1/3 | 趋势拐点未确认，风险管理优先 |
| 二买 | 标准 2/3 | 拐点已确认，可以加码 |
| 三买 | 满仓 | 趋势已确认，全力参与 |
| 一卖 | 减至 1/3 | 趋势可能结束，保留利润 |
| 二卖 | 清仓 | 转折确认，不留幻想 |
| 三卖 | 必须清仓 | 趋势反转确认，立即离场 |

**动态调整**：
- 二买强弱影响仓位：最强二买（二买三买合一）直接满仓
- 置信度低时自动降仓一档

**背后的本质**：仓位管理体现了**风险和收益的动态平衡**。一买利润空间最大但不确定性最高，所以轻仓试探；随着二买确认、三买延续，确定性逐步增加，仓位也逐步加码。这种"逐步加仓"的模式确保了：即使一买判断错误（假背驰），损失也被控制在可接受范围内。

## 十二、中枢位置标注 — 当下的坐标系

### 对应缠论概念

**机械化操作流程**（图解缠论 §四、缠论解析 场景B）

### 实现

`_compute_position_vs_hub()` — 比较最新收盘价与最后一个中枢的 ZG/ZD，给出位置标注和偏离百分比。

### 理论说明

标注结果为三种之一：
- **中枢上方运行**：价格 > ZG → 持股等待卖点
- **中枢区间震荡**：ZD ≤ 价格 ≤ ZG → 高抛低吸
- **中枢下方运行**：价格 < ZD → 空仓等待买点

同时标注线段中枢位置，提供更高级别的参考。

**背后的本质**：中枢位置标注解决的是"当下在哪里"的问题。交易中最重要的不是预测未来，而是**精确定位当下**。当你知道价格在中枢上方、中间还是下方，你的操作就有了明确的参照系。这是缠论"不测而测"思想的具体体现。

## 十三、多级别联立 — 三级共振系统

### 对应缠论概念

**多级别联立**（108课 §3.4、图解缠论2 §3.5、图解缠论3 §1.1、土匪注解 §1.3）

### 实现

`synthesize_multi_level()` — 综合日线（方向）+ 30分钟（买卖点）+ 5分钟（择时）。

子功能：
- `_check_direction_alignment()` — 三级别方向一致性判断
- `_enrich_small_level_signals()` — 大级别环境增强小级别信号
- `_find_resonance()` — 跨级别共振检测
- `find_interval_nests()` — 区间套精确定位

### 理论说明

多级别联立是缠论实战中**最核心的操作框架**。三个级别各司其职：

| 级别 | 角色 | 作用 |
|------|------|------|
| 日线 | **方向灯** | 判断大趋势方向，决定操作倾向 |
| 30分钟 | **信号源** | 产生具体的买卖点信号 |
| 5分钟 | **精确定位** | 在买卖点附近寻找最佳进出时机 |

#### 方向一致性（Direction Alignment）

| 判定 | 含义 |
|------|------|
| 三级共振 | 三个级别同方向 → 最强信号 |
| 部分一致 | 两个级别同方向 → 较强 |
| 大小分歧 | 大小级别方向相反 → 谨慎 |
| 方向不明 | 无明确方向 → 观望 |

#### 大级别环境增强

日线环境会调整小级别信号的置信度：
- 日线多头 + 中枢上方 → 小级别买入信号升级
- 日线空头 + 中枢下方 → 小级别买入信号降级
- 日线阶段（初中段 vs 末段）影响对小级别背驰的解读力度

#### 区间套精确定位

这是缠论中最精妙的操作技巧之一。当日线检测到背驰段时：
1. 在日线背驰段的时间窗口内，寻找 30 分钟的背驰
2. 在 30 分钟背驰段的时间窗口内，寻找 5 分钟的背驰/买卖点
3. 最小级别的信号就是"精确定位"的进出点

```
日线背驰段（宽泛区域）
  └→ 30分钟背驰（缩小区域）
       └→ 5分钟买卖点（精确定位）
```

**背后的本质**：多级别联立的核心思想是**层次化决策**。大级别定方向（战略），中级别出信号（战术），小级别精确进出（执行）。这对应了一个深刻的交易哲理：**用大级别控制方向风险，用小级别提高进出精度**。

区间套的本质是**确定性的层层递增**。日线背驰只告诉你"这个区域可能转折"，30分钟背驰缩小到"这几天可能转折"，5分钟买卖点精确到"今天下午2点可以买入"。每下钻一层，时间和价格的不确定性都大幅缩小。

## 十四、二买强弱分类 — 市场共识的量化

### 对应缠论概念

**二买强弱**（108课 §2.4）

### 实现

在 `find_buy_sell_points()` 中的 Type 2 逻辑，通过回抽价与中枢 ZG/ZD 和一买价的比较进行分级。

### 理论说明

| 强弱 | 条件 | 含义 |
|------|------|------|
| 最强（二买三买合一） | 回抽价 > 中枢 ZG | 回抽都不进中枢，极强势 |
| 强势 | 回抽价 > 一买价 | 回调幅度比一买时还小 |

**背后的本质**：二买强弱分类衡量的是**市场对趋势转折的认可程度**。最强二买（回抽不进中枢）意味着卖方连中枢这个"安全区域"都推不回去——买方共识极其强烈，往往对应大行情的起点。

## 十五、MACD 高级诊断 — 四维辅助判定

引擎在完成标准缠论分析流水线后，额外运行四项 MACD 高级诊断，结果存储于 `AnalysisResult.macd_diagnostics` 字典中。

### 15.1 面积×2预估（`estimate_area_2x()`）

**理论依据**：土匪注解提到，当 c 段（趋势中最后一段）的 MACD 面积尚未走完时，可以用已有面积乘以 2 来**估算最终面积**，如果估算值仍然小于 a 段面积，则背驰概率很高。

**实现逻辑**：
1. 对每个中枢，从其后方的笔中取出最后 3 笔作为 a-b-c 段
2. 计算 `estimated_c = c_area × 2`（假设 c 段才走了约一半）
3. 若 `estimated_c < a_area`，输出预警：未走完已经比 a 段弱

**本质**：这是一种**保守估计法**。如果翻倍后仍不及 a 段，说明即使剩下的走势维持当前力度，总动能也不够——背驰几乎确定。这在实盘中提供了**提前布局的窗口**。

**输出键**：`macd_diagnostics['area_2x_warnings']`

### 15.2 均线面积互证（`compute_ma_area_divergence()`）

**理论依据**：MACD 本质上是 EMA12 与 EMA26 的差值。均线面积互证换一个角度——用 MA5 与 MA10 的面积差来衡量短期动能。两套指标的背驰结论**相互印证**时，可靠度大增。

**实现逻辑**：
1. 先调用 `compute_ma()` 在 `RawBar` 上计算 MA5、MA10
2. 对中枢前后的 a 段和 c 段，分别计算 MA5 与 MA10 之间的面积（逐 bar 差值之和）
3. 若 c 段均线面积 < a 段均线面积，则均线面积也在缩减——与 MACD 背驰形成**双重验证**

**本质**：MACD 用 12/26 周期，均线面积用 5/10 周期——两者的时间尺度不同。如果**不同尺度都指向动能衰减**，说明这不是单一参数偶然造成的假信号，而是市场力量在结构性地减弱。

**输出键**：`macd_diagnostics['ma_area_divergence']`

### 15.3 MACD 参数调倍（`compute_doubled_macd_area()`）

**理论依据**：土匪注解提到，当标准 (12,26,9) 参数下柱状图**红绿交替频繁**（一笔内出现多次变色），导致面积计算不准时，可以将参数翻倍为 (24,52,18) 重新计算。加长周期后柱状图更连续，面积对比更清晰。

**实现逻辑**：
1. 调用 `compute_macd_alt(bars, 24, 52, 18)` 用大参数重算 MACD（不影响原始 bar 数据）
2. 对中枢前后的 a 段和 c 段，分别用新参数计算柱状图面积
3. 输出两组参数下的面积对比：`std_a_area / std_c_area` vs `alt_a_area / alt_c_area`
4. 当标准参数显示 c > a（不背驰）但调倍参数显示 c < a（背驰），或反之时，特别标注差异

**本质**：参数翻倍等于**降低分析的"分辨率"**——看不清细节时退后一步看全局。这类似于缠论中"看高一级别"的思想：当低级别信号模糊时，向上看一级以获得更确定的判断。

**输出键**：`macd_diagnostics['doubled_macd_comparison']`

### 15.4 双次拉回0轴检测（`detect_double_pullback_zero()`）

**理论依据**：缠论中，DIF 在 0 轴下方两次接近 0 轴但都无法上穿，说明多头反复尝试夺回控制权但都失败——后续很可能出现类三卖（加速下跌）。反之，0 轴上方两次回抽未破则可能触发类三买。

**实现逻辑**：
1. 扫描全部 bar 的 DIF 序列
2. 识别"接近 0 轴"的区间（`|DIF| < threshold`，threshold 取所有 DIF 绝对值中位数 × 0.3）
3. 在每个接近区间中检查 DIF 是否成功穿越 0 轴
4. 如果在同一侧出现两个"接近但未穿越"的区间，且间距 ≥ 5 bars，输出警告

**本质**：0 轴是多空的**分水岭**。两次冲击未果 = **市场给出了明确的否决信号**。这是一种"价格行为 + 指标共振"的高级模式识别，对应缠论中"第三类买卖点"的辅助确认。

**输出键**：`macd_diagnostics['double_pullback_warnings']`

### 四项诊断的协同关系

```
标准流水线分析                 高级 MACD 诊断
                            ┌─────────────────────┐
 笔 → 线段 → 中枢 → 背驰 ──→│ 面积×2预估   (提前预警) │
                            │ 均线面积互证 (双重验证) │
                            │ 参数调倍     (全局视角) │
                            │ 双次拉回0轴  (模式识别) │
                            └─────────────────────┘
                                      ↓
                            增强 buy_sell_points 的
                            置信度判断
```

面积×2预估提供**时间优势**（未完成就判断），均线面积互证提供**维度优势**（不同指标共振），参数调倍提供**尺度优势**（更宏观的视角），双次拉回提供**模式优势**（特殊形态识别）。四者从不同角度为标准分析结论提供辅助验证。

## 总结：引擎设计的核心原则

1. **递归分解**：从最小单元（K线）到最大结构（走势类型），每一步都在上一步的基础上构建，严格遵循缠论的递归定义
2. **完全分类**：走势非盘整即趋势，买卖点只有三类——引擎的分类逻辑覆盖了所有可能性
3. **形态 + 动力双轮驱动**：结构分析（分型→笔→线段→中枢）定位"在哪里"，MACD 动力分析判断"会不会变"
4. **多级别立体分析**：三级联立从方向→信号→精度逐层深入，用确定性递增的方式降低交易风险
5. **机械化操作**：所有判断条件都是可编程的数学逻辑，消除主观情绪干扰

缠论引擎的终极目标不是"预测涨跌"，而是**构建一套完全分类的操作体系**：在任何市场状态下，你都知道自己在哪里（走势类型 + 中枢位置），应该做什么（买卖点 + 仓位建议），以及何时做（区间套精确定位）。
