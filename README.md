# 缠论交易系统

基于缠中说禅技术分析理论的A股宽基指数轮动分析系统。

## 功能

- **6大宽基指数**实时缠论多级别分析（日线 + 30分钟）
- **纯缠论五维度评分**轮动排名
- **交互式K线图**（Canvas渲染，含笔、中枢、MACD、买卖点标注）
- **自包含HTML报告**（可独立发送到手机查看）
- **买卖点信号跟踪**与历史记录

## 快速使用

```bash
cd scripts
python3 index_trading_system.py                          # 数据+分析+评分+报告
python3 build_standalone_html.py $(date +%Y%m%d)         # 构建自包含HTML
```

产出文件在 `indices/reports/YYYYMMDD/` 目录下。

## 技术栈

- **数据源**：新浪财经API
- **分析引擎**：Python（缠论算法：K线包含→分型→笔→中枢→走势→背驰→买卖点）
- **可视化**：HTML5 Canvas（自包含，零依赖）
- **评分体系**：纯缠论五维度（走势·信号·MACD·中枢·共振）
